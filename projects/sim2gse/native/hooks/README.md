# 阶段1最终连接链

兼容锁只应用此目录中的最终差异，从固定原版归档直接生成产品源码；旧历史补丁保持在patches目录作为历史资料，不再进入锁中的应用链。

- 010：基础按钮查询转接、原位导入查询及初始化连接、物品代理观察。查询仍在原生动作建立阶段、初始化前创建；无查询沿用原路径。
- 020：共用角色报告与伤害归属连接。基准保留完整动作目录。
- 030：共用源码编译登记。
- 040-control-connections：基准到受控的最终连接，包含受控报告目录开关，并保持受控原本不启用导入查询的行为。输入、动作步进、排队反馈、连续施法及其状态已经集中controller源码；原生文件保留选招、执行入口/拒绝/中断、输入来源捕获、资格探测、初始化和重置连接。原生事件中仍保存已捕获的输入来源，以保留排队动作归属。旧040-temporary-legacy-controller只作历史资料，锁不再应用。
- 050：现有死亡骑士保护，升级时核对是否仍需要。

基准依次应用010、020、030；受控再应用040、050。独立源码仍与原生引擎共同编译。恢复旧提交的完整锁、源码和匹配产物即可回退，不删除历史成绩。
