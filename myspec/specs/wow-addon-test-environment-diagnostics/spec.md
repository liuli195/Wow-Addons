# 魔兽世界插件测试工具环境诊断

## Purpose

让用户保存完整环境诊断结果，并依据准确提示配置现有脚本运行后端。

## Requirements

### Requirement: 魔兽世界插件测试工具保存完整环境诊断结果

魔兽世界插件测试工具 MUST 在环境诊断时按用户指定的输出文件保存完整结果；控制台摘要裁剪不影响文件内容，未指定输出文件时不额外保存文件。后端可用时退出状态为零，不可用时为二；输出文件不可写时必须明确失败并返回退出状态二，不能报告已成功保存。

#### Scenario: The user requests a complete diagnostic file

- **WHEN** 用户运行环境诊断并指定输出文件
- **THEN** 文件包含未被控制台摘要裁剪的完整诊断；后端可用与不可用的退出行为保持不变。

#### Scenario: No output file is requested or the requested file cannot be written

- **WHEN** 用户未指定输出文件，或指定文件无法写入
- **THEN** 未指定时不额外保存文件；无法写入时明确报告工具错误并失败。
### Requirement: 魔兽世界插件测试工具准确说明 Lua 运行程序的配置

魔兽世界插件测试工具 MUST 在未显式指定 Lua（脚本语言）程序、使用默认自动探测仍未找到可用后端时，说明显式程序设置仅接受 Lua 可执行程序，不将共享库描述为可显式指定的程序。未指定程序且使用默认探测时仍可自动发现本机共享库。显式程序优先、显式指定程序不存在时的专门错误，以及明确选择 Lupa（Python 与 Lua 集成运行库）但未安装时的专门错误保持不变，不因此增加新的后端配置能力。

#### Scenario: No usable script backend is found

- **WHEN** 用户未显式指定 Lua 程序，环境诊断使用默认自动探测仍未找到可用脚本后端
- **THEN** 提示用户配置 Lua 可执行程序或使用既有后端，并说明未指定程序时可以自动发现本机共享库，不提示将共享库作为可执行程序设置。
