# Sim2GSE Seed Training

## Purpose

让用户人工清洗一次外部材料后长期复用，人工启动独立训练，从同一共享数据中心提炼可供正常搜索使用的起点。

## Requirements

### Requirement: Sim2GSE registers cleaned seed materials in the existing shared store

系统 MUST 将人工清洗件及其来源、原件或引用、作者用法、清洗说明、结构家族、核心片段与可模拟程序保存在既有项目共享数据中心；用户不必维护另一份材料库，登记与训练不得改写用户技能安装内容。清洗由人或代理逐项完成，登记入口不自动猜测原宏。人工来源的修订或停用 MUST 使用明确稳定身份，不凭标题或网址猜测更新关系；来源停用不自动撤回已有入选代表。

训练与准备入口 MUST 自动将适用历史最佳程序同步到同一来源库，后续共用整理与评价流程。历史运行身份确定来源，程序、引用或明确有效状态变化作为修订，无变化不重复写入。已完成历史具有一致候选引用和可恢复程序即可作为当前重新评分材料；旧搜索只有一个样本、零分或缺少分数不得单独使程序失去入源资格，旧分数仅保留出处，不直接用于当前排名，也不证明完整独立训练。运行中、失败、引用缺失或不一致、不可表达材料保留原因；临时读取失败 MUST 明确报错，不伪装成来源删除或缩小本批输入。

#### Scenario: A cleaned external material is registered

- **WHEN** 用户登记合法清洗件并指定已接入共享数据存储的项目
- **THEN** 同一中心保存程序及其可追溯来源，后续可重复读取和训练，登记不启动网络采集或原宏解释。

#### Scenario: A completed historical program has only a weak or absent old score

- **WHEN** 已完成历史有一致候选引用和可恢复程序，但旧搜索只有一个样本、零分或缺少分数
- **THEN** 程序自动进入统一来源库并接受当前合法性检查及独立评价；旧分数不冒充当前成绩，误因旧评分质量停用的派生来源恢复活动并清除过时原因。

#### Scenario: A historical source is revised or temporarily unreadable

- **WHEN** 同一历史来源的最佳程序、引用或明确状态改变，或读取该来源暂时失败
- **THEN** 明确修订按同一来源更新并保留出处；暂时失败报错且保留先前可靠记录，不当作删除，也不继续发布缩小后的输入范围。
### Requirement: Sim2GSE retains seed sources and semantic boundaries

系统 MUST 区分语义保留、明确改写和当前不可表达材料，保留原件及逐项变化；待筛选来源、已处理、已入选和不可表达记录均可查询，未入选材料不得删除。已处理来源仍在可复用来源库中，不得将来源库列表冒称本轮未处理材料。成功施放日志不得被冒称原按键、等待指令或完整可循环宏；存在明确使用限制的材料必须保留限制和暂存原因。

#### Scenario: A material cannot currently be used as a program

- **WHEN** 用户登记没有可用程序的材料及其不可表达或使用限制原因
- **THEN** 来源和原因仍可查询，该材料不进入训练，不产生伤害成绩，也不被静默改写为支持状态。
### Requirement: Sim2GSE runs one manual training batch from a fixed input snapshot

系统 MUST 从现有人工入口运行独立预训练并在处理后退出，不要求常驻服务，不保留旧逐材料局部搜索训练模式。材料和实际评价条件在启动时冻结；按专精、真实英雄天赋及目标类型三条件形成独立组，当前受支持邪恶专精死亡骑士范围为双英雄×单目标／5目标四组，不跨组混合种群或成绩。训练期间新增材料及配置变更只影响下一新任务；显式材料编号只限定本批活动输入，无效、未知或已修订编号在计算前明确拒绝。

预训练 MUST 默认允许4组并发、每组最多5个单线程引擎。外层允许1至10，组内允许1至16，乘积不超过20；本次显式值优先，非法组合在准备或模拟前拒绝，不自动降参。初评、繁殖评分、必要准备／反馈及独立复测共用本组额度，不额外各开一份。训练并发配置不控制正式搜索，二者分别配置并按各自约束执行。

粗评请求迭代默认32，独立复测默认每场景3批、每批请求128，连续完整代无改善默认2，历史早停比较与最终入围共用的候选上限默认8且至少4，每次候选竞争参与数默认3，交叉和变异概率分别默认0.8。上述已支持配置 MUST 实际生效并随任务冻结，正整数拒绝布尔值，概率须有限且各在0至1内，不要求概率之和不超过1；恢复沿用原算法、评价和种子参数，不热更新。固定输出四条、四种扰动、180秒场景、单引擎一线程、非法额外重生10次、模拟失败重试1次不新增通用配置入口。

#### Scenario: Pretraining freezes four independent scopes

- **WHEN** 用户启动受支持邪恶专精死亡骑士预训练，且没有普通搜索正在运行
- **THEN** 系统冻结本批输入及配置，分别建立双英雄×单目标／群体四组，完成或保存暂停状态后退出，不后台重复启动。

#### Scenario: The configured concurrency is invalid

- **WHEN** 有效外层或组内值超出允许范围、不是整数或乘积超过20
- **THEN** 系统在实际准备或模拟前明确拒绝，不静默缩小并发，也不改变普通搜索配置。

#### Scenario: Configuration changes after a task starts

- **WHEN** 用户修改训练配置后恢复同一个未完成任务
- **THEN** 恢复使用任务原冻结参数及原种子，仅下一新任务使用新算法配置。
### Requirement: Sim2GSE deduplicates seed training without losing source relationships

系统 MUST 复用现有材料整理、角色适配、合法性与完整点击行为去重能力，保留全部来源、原程序、改写和归属。每组全部合法且行为不同的输入形成初始候选群体，规模等于该组有效输入数，不按粗分截断、不复制凑数，各组候选数可不同；没有有效输入时明确报材料不足并仅停止该组，仅有一个有效输入时仍可尝试变异。合法重复后代不改变该组规模；同一完整评价同时被多次需要时只计算一次，并可复用可靠成功结果，不把复用算成额外独立样本。

缓存复用 MUST 核验程序行为、冻结角色／引擎／模拟及爆发配置、输入轨迹、种子与统计身份；来源名称或行为相同不能替代完整条件核验。历史材料可重新适配和评分，旧角色或旧算法成绩不得冒充当前成绩。旧完整任务、报告及受支持版本1成果继续只读验真，不重写其身份或迁移成新遗传算法完成证明；身份不兼容的旧未完成任务明确拒绝恢复。暂时读写故障明确报错，不伪装成材料非法或空库。

#### Scenario: All valid distinct inputs form the population

- **WHEN** 某组存在适配后合法且行为不同的材料
- **THEN** 全部有效材料进入初始候选群体，保留出处；材料不因粗分、来源顺序或不足四个被截断或复制。

#### Scenario: Repeated candidates require the same evaluation

- **WHEN** 同组多个合法候选对应同一完整评价请求
- **THEN** 候选数量保持，但可靠成绩仅按相同完整身份复用，同请求在途计算合并且不虚增独立样本。

#### Scenario: A historical unfinished task has an incompatible identity

- **WHEN** 旧未完成任务的算法或完整评价身份与当前预训练不兼容
- **THEN** 明确拒绝恢复，保留旧来源与可靠完整成果，不改写历史身份制造兼容。
### Requirement: Sim2GSE trains seeds with the locked standard character profile

系统 MUST 默认使用当前已核验引擎配套的完整标准角色，以受检上游的实际双英雄模板及可核验英雄身份形成支持范围内各组；不得用单英雄模板仅循环目标数冒充双英雄四组，不要求用户另行登记现有标准模板。明确指定其他模板时如实标明，所需模板缺失须在计算前报错。训练与页面模拟采用一致的角色合法性、独立爆发兼容及导出限制，各自保留实际角色与算法条件；原普通循环及独立爆发时点行为保持，不借本次预训练或清理修改时点解析或强制迁移旧计划。

#### Scenario: The required hero template is missing

- **WHEN** 当前受检构建缺少某个必需标准英雄模板或不能核验真实英雄身份
- **THEN** 系统在模拟前明确失败，不静默使用另一英雄或旧引擎模板。

#### Scenario: A material comes from another character

- **WHEN** 材料来自不同角色或引擎
- **THEN** 系统按当前组冻结角色与条件重新适配、核验及评分，保留原出处，不沿用来源旧分。
### Requirement: Sim2GSE gives each training path independent complete rounds

独立预训练 MUST 按组进行与有效输入数相等的固定容量完整代换代：初始及繁殖评价统一使用冻结粗评请求数；每代候选数量保持不变，用户选择的竞争参与数、交叉和变异概率须实际影响候选产生，完整按键动作块及其顺序语义保持；尝试变化不保证行为一定改变。不得回填历史冠军、轮转原始结构、择优保留父代或使种群逐代膨胀。

非法子代 MUST 在初次失败后额外至多重生10次：既有成功候选不重复计算，处理规则与随机条件在任务开始后保持不变。耗尽则保存并暂停该组、明确报错。合法候选模拟失败及独立复测失败只对原候选、原条件和原种子重试1次，可靠成功批不重跑；已耗重试与重生次数随恢复保留。取消、结构非法、运行失败及共享故障须区分，不吞错或以父本副本兜底。

全部本代候选成功评价后 MUST 才记作完成一代。每完整代按全程成功粗评且行为不同的候选在冻结入围上限内的领先榜更新无改善计数：任一排名每秒伤害严格提高，或未达到入围上限时新增行为补入，计数清零；仅同分标识换位不算改善。默认连续2完整代无改善后自然停止；半代、取消及失败不计完整代，不套用旧600秒、固定五轮或32／128／256晋级链，不承诺有限总收敛时间。正式搜索同样按完整代和既定停止条件运行遗传算法，只做正常场景复测并输出一个冠军；不保留旧局部链、预算封顶或分档晋级。

#### Scenario: A full generation improves the historical leading candidates

- **WHEN** 完整代使历史入围上限内任一排名严格提高或补入未达到入围上限的新行为
- **THEN** 无改善计数清零，继续同规模繁殖；仅同分换位不清零。

#### Scenario: A generation is interrupted

- **WHEN** 当前代尚未完成全部本代候选评价即取消或故障
- **THEN** 保存暂停及可靠进度，不提交半代、不增加早停计数，也不自动进入复测或发布。

#### Scenario: An invalid candidate exhausts regeneration

- **WHEN** 某个候选初次产生结果非法，且额外10次尝试仍失败
- **THEN** 该组明确暂停并保留错误和已耗次数，不替换为父本或历史冠军，独立其他组可继续。
### Requirement: Sim2GSE selects retested performance and structural seed representatives

系统 MUST 对既有版本1或无成果契约版本的四代表保留其原来源、结构家族／核心与独立复测凭据的只读核验，不能因旧成绩较高或来源标签存在而宣称它是新遗传算法的正常每秒伤害冠军或稳定代表。历史来源／程序／报告不因新训练执行替换而删除或改写。

新预训练 MUST 不再执行旧逐材料初始／最终三批配对挑战、95%区间替换或来源家族四代表筛选；新版本2四条按本能力的五场景独立复测与正常每秒伤害／稳定性规则产生。旧完整成果可读不代表旧未完成任务可绕过身份检查恢复。

#### Scenario: An old family representative is read

- **WHEN** 正式搜索读取一个可核验版本1结构家族代表
- **THEN** 按历史证据核验并以当前角色适配和重新评分，不重启旧训练，也不将其标为版本2稳定代表。
### Requirement: Sim2GSE publishes seed snapshots automatically and preserves the old library on failure

系统 MUST 在每组自然早停、全部冻结入围者五场景独立复测与资格核验完成且选出四个不同行为后，先验证完整快照再替换同专精、英雄天赋及目标类型三条件的当前四条。成功前旧快照保持；缺条、缺批、取消、暂停、存储故障或未完成不得发布部分新库。各组三条件独立发布，一组失败不回滚其他成功组；不把部分组成功说成所有组同时成功，不增加新旧八条对决、额外历史库或单调胜旧保证。

恢复 MUST 沿用原冻结配置、候选、种子、原代／原复测阶段及已耗次数，仅补可靠凭据缺失的请求或保存步骤；已核验可靠成功结果不重算。手动取消停止新派发、可靠刷尾并保存暂停，不自动选优或发布。暂时不可读、损坏、模拟失败及发布失败须如实报告，不能静默置空或伪造成功；可靠完整成果已保存时允许恢复补发布。

#### Scenario: One independent group publishes while another pauses

- **WHEN** 某三条件组完整合格，另一组取消或失败
- **THEN** 成功组可先验后替换自己的当前四条，暂停组保留旧四条和可靠进度，不互相回滚。

#### Scenario: Retesting is interrupted

- **WHEN** 冻结入围名单后部分复测成功但任务中断
- **THEN** 恢复原名单、场景、种子及已耗重试，只补缺批，不重开粗评或重置进度。

#### Scenario: Publication fails after reliable results

- **WHEN** 完整合格成果已可靠保存但快照发布失败
- **THEN** 旧快照保持，恢复可核验后补发布，不重复可靠完成的计算。
### Requirement: Sim2GSE reads selected seeds once without running training in normal search

系统 MUST 在正常搜索初始化消费既有四个训练代表时，只读取同专精、同英雄天赋及同目标类型的小快照；目标类型区分单目标与群体目标。共享范围不因角色模板或引擎不同而重新分组，但来源证据仍须按其原条件核验，候选须按当前角色合法性和编译限制检查、去重并重新评分，在原四类起点后追加最多四个代表；不更改用户角色配置、不扫描全历史、不现场启动预训练；正式遗传算法仍按本任务冻结计划完成正常独立复测。快照固定到当前任务，恢复时沿用原快照，中途不刷新。空库沿用原搜索；身份不适用的候选跳过，读取异常不得掩盖为空库。历史记录只有在可核验来源证明上述三条件及完整成果时才可复用；信息不足时明确跳过并保留原因，不猜测共享范围，不依赖已退役的当前职业规则库来获得已有共享身份。

新任务 MUST 为身份适用的入选程序派生当前角色副本，仅删除当前引擎明确证明角色不具备使用资格的已知动作；同名当前可用按钮优先保留。证据缺失、尚未完成资格检查、未知名字、饰品不可用说明、仅未执行、冷却或资源不足不得成为删除依据。派生后仍按真实当前角色能力、固定爆发排除和导出限制检查，重新规范化、按行为去重并以当前角色评分；旧训练成绩不得冒充当前成绩。原来源、训练程序、处理记录、入选快照和旧成绩 MUST 保持，不因角色适配重新训练已完成路径；不保证仅追加四个代表后存在八个不同起点，也不虚增有效起点数量或改变遗传算法完整代停止门槛。

裁剪 MUST 保留剩余动作及动作块顺序、顺序循环的重复次数和空点击等待。空动作块、空循环和零成员施法序列可删除，但原程序的结构及合计展开上限错误不得通过删除洗成合法；原映射动作块及战前块合计不得超过128，总展开按键不得超过4096。施法序列 MUST 在删除前核验原成员及重置定义；剩两个及以上成员保持顺序和重置，剩一个成员明确拒绝，不改为普通动作、复制成员或伪造重置。未知动作、不支持语法、无效原定义、无可执行动作或只有空点击的候选独立拒绝并保留原因，不静默删掉未知部分后采用。

任务 MUST 冻结实际起点及适配决定，并通过既有任务读取入口返回原候选身份、原程序、派生程序、删除位置与动作及原因、采用／重复／拒绝结果和可核验的行为身份。同版本同条件恢复继续使用冻结程序、成绩及遗传算法进度，不因入选库后来变化重新适配或补入起点；已有软件版本和评价条件的兼容检查不放宽。这项适配仅用于新搜索消费训练起点，不放宽通用动作选择、显式程序或导入检查，不要求用户增加操作步骤或另行维护一份材料库。

#### Scenario: A normal task starts with a usable library

- **WHEN** 用户启动正常搜索，且存在身份适用的入选快照
- **THEN** 任务读取一次快照，将合法且不重复的代表追加到原起点后，并通过当前正式遗传算法继续评价和修改；搜索及归档不触发训练反馈计算。

#### Scenario: A trained seed contains actions unavailable to the current character

- **WHEN** 新任务的入选程序同一块含当前角色原生静态资格不可用的狂暴与可用的自动攻击，并另有仅含不可用灵魂收割的块
- **THEN** 副本仅移除狂暴并保留自动攻击，删除灵魂收割空块，其余顺序保持，经当前角色重新检查、去重和评分；原来源及训练成绩不改，不重新训练。

#### Scenario: A seed has transient failures or lacks static unavailability proof

- **WHEN** 动作只是冷却中、资源不足或未执行，或缺少已完成资格检查且确实不可用的证明，或当前角色已有同名可用按钮
- **THEN** 该动作不因这些条件被删除；未知名字或仍不符合当前合法性条件的候选明确拒绝并记录原因，不放宽通用校验。

#### Scenario: Pruning would hide an invalid original control structure

- **WHEN** 原程序超出128个合计映射动作块或4096次总展开按键，或施法序列原成员／重置无效，或裁剪后仅剩一个施法序列成员
- **THEN** 候选明确拒绝，不通过删空洗白结构，也不把单成员施法序列转为普通动作；合法剩余循环保持次数及顺序，空点击等待保持，只有空点击仍拒绝。

#### Scenario: Adapted seeds coincide or the library changes after initialization

- **WHEN** 多个起点适配后行为相同，或同条件恢复时入选库已经更新
- **THEN** 新任务只保留实际合法且行为不同的起点，通过任务读取入口可追溯各适配决定；恢复沿用原冻结程序、成绩及遗传算法进度，不刷新入选库，不借旧成绩或重复起点虚增路径。

成果契约版本 MUST 决定冠军来源：版本2四条已包含正常每秒伤害冠军与稳定代表，仅再独立消费原契约角色正式冠军，最多4＋4＋1；版本1或无版本保留旧四代表、独立最终训练冠军及角色正式冠军，最多4＋4＋2。未知或混合版本明确拒绝，不从训练语义版本或来源标签猜测。冠军来源不占四代表名额，行为去重后可少于上述上限，不复制凑数。

#### Scenario: A verified seed comes from another character or engine

- **WHEN** 已完成成果与当前任务的专精、英雄天赋和目标类型一致，来源条件可核验，但角色模板或引擎不同
- **THEN** 可作为候选来源按当前条件适配、去重和重新评分；保留原证据，不沿用旧成绩、不现场重训，也不依赖当前职业规则库来识别该来源。
### Requirement: Sim2GSE prioritizes normal search over manual seed training

系统 MUST 让普通搜索不等待训练：训练开始前发现普通搜索则退出；训练中普通搜索启动时，通过现有取消能力停止补派并取消本批全部所属路径和模拟，保存可靠成果及旧快照，不按进程名终止其他任务。训练活动在全部所属计算收尾后释放，取消或保存失败不得留下继续补派的路径。允许短暂取消收尾窗口，不承诺物理零重叠；本批各三条件组由同一批次活动管理并遵守冻结并发上限，不再要求两个目标场景顺序运行。

#### Scenario: A normal search starts during concurrent training

- **WHEN** 多条训练路径正在模拟而用户启动普通搜索
- **THEN** 普通搜索立即继续，训练停止补派、取消并等待全部自身所属计算收尾，保留可靠证据及旧库，其他进程不被终止。
### Requirement: Sim2GSE distinguishes batch seed evidence from original macro and game equivalence

系统 MUST 区分来源数、原程序数、各组适配后有效行为数、种群规模、成功粗评记录、冻结入围者、完成代数、独立复测及正式四条；保留出处、实际请求、有效样本、可靠缓存及真实新增模拟证据。不把重复候选、缓存命中或请求迭代数算作独立有效样本。标准角色改写件可运行不等于原宏完整复现、游戏验收、全材料规模收敛或正常搜索收益。

数量级估算 MUST 分开32粗评与128复测的新请求耗时，说明工作量、缓存、并发、准备／保存／收尾及缺测项目，未知代数只作条件化假设。配置4×5和并行运行活动提示不能冒称可靠峰值20测量；报告保存次数及软件内部计时不能冒称物理输入/输出次数或硬盘时延。不同配置的性能结论须有同输入、同评价条件及同工作量证据，不能借缓存优势声称线性倍速；未运行的全部70个材料、大规模种群、完整统计对照或游戏验证不得报通过。

#### Scenario: A small isolated acceptance finishes

- **WHEN** 少量真实材料的小型单组和四组冒烟自然结束并发布
- **THEN** 只报告该输入、算法及证据实际覆盖的功能与量级，不外推为全70材料或统计策略胜出。

#### Scenario: Concurrency or storage measurements are incomplete

- **WHEN** 仅取得4×5配置、运行活动提示和逻辑写入计时而无可靠进程峰值或物理输入/输出观测
- **THEN** 明确标注缺测，不用配置值、逻辑组数或计时标签伪装实测。
### Requirement: Sim2GSE accepts long castsequences as searchable seed programs within macro limits

系统 MUST 在搜索起点入口接受含2至32个成员的受支持原生施法序列，同时遵守255字节宏文本、合法动作、重置、展开与导出一致性限制；不得仅因超过旧的短成员上限而拒绝。多个独立施法序列按各自成功施放推进状态处理，不能为接入而展平为不同推进规则。该能力不扩展其他原宏条件或高级控制结构。

#### Scenario: A cleaned seed contains more than four castsequence members

- **WHEN** 清洗起点含5至32成员的施法序列，且宏文本及其他编译模拟条件均合法
- **THEN** 起点可进入现有评分和搜索，不被旧短成员限制拦截；超过32成员或255字节时明确拒绝，不绕过限制。
### Requirement: Sim2GSE incrementally prepares and freezes the complete unique seed queue

系统 MUST 为训练与人工准备入口提供同一持久整理流程；人工准备不搜索或独立复测，用户也不必先手动准备才能训练。准备快照保存在既有共享数据中心并可查询；无变化不重复共用参考、逐来源整理、行为归一化或输入编译，新来源及修订只处理受影响项。明确展示元数据只更新关系，结构家族和核心变化只重新核对相应归属，不单独废弃可靠成绩。影响用法、角色、场景、爆发、引擎或准备语义的变化 MUST 重新核验受影响配置；缺失、确定损坏或未知版本的派生缓存重建，临时环境、存储或取消故障不得冒称材料非法或空库。

系统 MUST 在首次训练派发前可靠发布包含全部来源、原因、改写及行为分组的完整唯一快照；按实际完整点击行为识别重复，保留顺序、空点击、施法序列及重置语义。代表材料的实际起点程序不因标签、读取顺序或代表来源停用随机更换，只要该表示仍合法且该组仍有活动来源。明确限定材料时，本批采用所选活动材料的实际程序，不用未选择的其他程序替代。训练期间新增来源留待下次；准备失败不以部分材料开始训练，无活动合法输入不清空旧入选库。

同次准备 MUST 只读取一次完整登记材料清单，历史同步、显式材料选择与各场景准备复用其可靠更新结果；非法、未知或已修订的旧材料编号仍明确拒绝，重复编号沿用既有去重，不因复用快照放宽来源及身份核验。

#### Scenario: Unchanged or revised sources are prepared

- **WHEN** 用户再次准备或直接训练相同配置，或只新增／修订一个来源
- **THEN** 无变化复用持久准备；变化只整理受影响项，仍保留全部出处及稳定起点程序，可靠训练成绩按独立身份规则核验。

#### Scenario: Equivalent source forms or inactive representatives are encountered

- **WHEN** 原程序重复、去爆发后重复或相同行为的不同程序写法同组，或原代表来源停用但组内仍有活动来源
- **THEN** 训练前固定完整且不重复的材料范围，逐来源保留原件、核心和改写关系，不随机改变仍合法的稳定起点程序；明确限定材料时实际起点程序来自指定活动材料。

#### Scenario: Preparation fails or no active legal input remains

- **WHEN** 准备快照未能可靠发布，或当前范围没有活动合法输入
- **THEN** 未完成准备不启动训练，也不使用部分快照；无输入如实报告且旧入选库保持，不伪造删除或成功。

#### Scenario: Multiple selected materials are prepared for both scenes

- **WHEN** 同次入口指定多个登记材料或重复编号，并准备两个场景
- **THEN** 登记材料读取一次，历史同步后的同一快照用于选择和各场景准备；合法重复编号按原规则处理，未知及已修订旧编号仍拒绝，不用第二次登记读取重新选取材料。
### Requirement: Sim2GSE preserves shared batch evidence across concurrent seed paths

系统 MUST 可靠保存多路径并发的共享成功请求、报告和所属路径成果，不能因并发写冲突丢失有效结果或静默最后写入覆盖不一致成绩；临时读写失败明确报告，并沿用原成功结果核验及恢复边界。新预训练同组同时需要的相同完整评价 MUST 只计算一次并保持全部候选数量；跨独立组仍按实际条件与请求身份隔离，不把缓存复用增加为独立样本。请求与缓存命中统计仅在启用相应诊断采集时记录；关闭时明确未采集，不以0或成功批次数伪装总请求/命中数；必要成功凭据及原生启动记录保持既有行为。

按当前诊断规则保存的轨迹 MUST 保留实际生成路径及请求出处；两个路径各自实际执行时分别保留来源，缓存命中引用原轨迹出处，不重算仅为制造新轨迹，也不把旧轨迹冒标为当前路径新生成。已可靠完成路径的原成果记录保持，新执行变化另记。

#### Scenario: Concurrent paths execute or reuse the same request

- **WHEN** 新预训练同组多个候选同时需要同一完整评价，或后续请求命中可靠成功凭据
- **THEN** 同组同时需要的相同评价只计算一次且候选数量不减少；启用相应诊断采集时，请求与缓存命中准确计数，关闭时明确未采集，不以0或成功批次数伪装总请求/命中数；必要成功凭据及原生启动记录保持既有行为，共享报告可靠保存；引用原证据不伪造当前候选或任务新执行。

#### Scenario: A shared report conflicts or cannot be saved

- **WHEN** 同请求的待保存成绩与已有可靠报告不一致，或共享报告暂时无法读写
- **THEN** 明确报告失败，保留可靠原成果和旧入选库，不以静默覆盖、空记录或部分新快照隐藏故障。
### Requirement: Sim2GSE independently selects the completed final training champion

系统 MUST 仅在消费版本1或无成果契约版本的历史四代表时，在同专精、同英雄天赋及同目标类型的共享范围内，从全部可核验已完成成果的最终程序中选择最终三次独立复测平均伤害最高者；每份来源按其自身角色模板及完整训练条件核验，包括引擎、模拟选项、语义版本、种子、样本规则、按键节奏和爆发内容，不要求来源模板或引擎与当前角色相同。初始程序与初始成绩不参选，最终程序与初始结构相同或未保留来源核心不构成排除；同分按稳定程序及来源身份选择，不受家族或四代表名额限制。三份最终报告与程序、条件、角色、种子和有效样本必须可核验；缺失或确定不符记录保留排除原因，临时存储异常不得冒称空库。已支持的历史版本成果在三条件及三份最终复测证据完整可核验时继续可读可选，不改写来源记录，也不将旧训练冒称新搜索规则的验收；历史成果可读不代表旧未完成任务可绕过身份检查恢复。

系统 MUST 对版本2不另取独立训练冠军，其正常每秒伤害冠军已在四条内；对版本1仅只读已有训练成果，不因选择冠军启动准备、训练、复测或写回训练排行。最高者按当前角色严格适配、导出检查和重新评分；不能适配时该来源缺席，不将第二名冒称最高者。原最终程序、模板成绩及来源证据与当前适配程序和成绩分别可追溯。初始化冻结一次，同条件恢复沿用原快照，不因训练库后来变化重新选择。

#### Scenario: The final champion is outside the four family representatives

- **WHEN** 同共享范围内可核验有效最终均值最高者不在四个代表内，或未保留原来源核心
- **THEN** 该程序仍成为独立训练冠军；四个代表不变，初始更高成绩不影响最终排名，另一目标场景的成绩不混入。

#### Scenario: The top final program cannot be used by the current character

- **WHEN** 已选最高者在当前角色下不能合法适配，或没有可核验的最终成果
- **THEN** 该冠军来源缺席并显示原因，不补第二名凑数；读写环境故障明确报告，不伪装成无冠军。

#### Scenario: Training records change after a formal task has initialized

- **WHEN** 任务初始化后出现新的训练成果，随后恢复同条件任务
- **THEN** 沿用开始时冻结的冠军及当前成绩，不重新选择或写回训练成果。

#### Scenario: A supported historical champion remains verifiable

- **WHEN** 既有历史成果能证明同一共享三条件及其自身完整的三次最终复测，但来源角色、引擎或已支持历史版本不同于当前任务
- **THEN** 该成果仍可参与来源冠军选择，再按当前角色重新评分；保留旧证据，不重新训练、不静默迁移旧任务，也不放宽必要证明。
### Requirement: Sim2GSE selects four pretraining representatives from five retest scenarios

系统 MUST 在某组自然早停后，从本次该组全程合法、成功完成粗评且凭据可核验的不同行为按粗评均分降序取不超过配置上限的入围者，默认上限为8，同分按稳定行为身份；不限末代、不跨组借分、不额外引入旧训练冠军。冻结名单后，每候选分别完成正常与四种独立扰动场景，默认各3批×请求128，场景均180秒。

四扰动 MUST 只影响普通循环，原独立爆发绝对计划不变：抖动间隔为基准间隔的九成至十一成，各端点取最接近的整数毫秒，恰在两个整数正中时取偶数，再在闭区间内等概率选择整数间隔；暂停场景省略第60秒至第62秒前及第120秒至第122秒前的普通点击，后续仍沿原绝对时间表；变慢场景将间隔改为基准的三分之四并取最接近的整数毫秒；相位场景先等待基准间隔的一半并向下取整到整数毫秒，再按基准间隔循环。场景互不叠加，不补发漏按、不增加全按钮五秒暂停。新复测种子与粗评隔离，同批候选共用种子／轨迹，批间不同并随任务冻结。

各场景每秒伤害 MUST 采用完整有效批的均值，等样本时算术平均，经核验允许样本差异时才按有效样本加权；不混粗分、失败批或不同条件。正常只计算一次并作为四种损失共同分母，各扰动损失为（正常均分－扰动均分）／正常均分，保留负值，最坏扰动损失越小越稳，不取最坏单批。

四条 MUST 包含正常每秒伤害冠军及最坏扰动损失最小的稳定代表，重合只占一席，余席按正常每秒伤害补齐不同行为；稳定同分依次按正常每秒伤害和稳定行为身份排序。不设冠军95%门槛或第五训练冠军，只称已定场景下估计最稳。可靠扰动每秒伤害为0按100%损失处理；正常均分不大于0明确不合格，不伪造损失、重试求非零或暗中补入原入围范围外的候选。所有冻结入围者完成必要评估并有明确资格结果、至少四条合格后才可发布。请求迭代与实际有效样本必须分别记录，不把128请求称128有效样本。

#### Scenario: Champion and stable representative coincide

- **WHEN** 正常每秒伤害最高者同时具有最小最坏扰动损失
- **THEN** 该行为仅占一席，其余席位按正常每秒伤害补足四个不同行为，不重复或补第五冠军。

#### Scenario: A stress score is zero but valid

- **WHEN** 完整有效扰动复测的每秒伤害为0且正常均分大于0
- **THEN** 该扰动损失为100%，不以运行失败重试；正常均分不大于0时明确不合格。

#### Scenario: Fewer than four finalists qualify

- **WHEN** 全部冻结入围者完成必要评估后只有不足四条合格行为
- **THEN** 保留可靠进度及原因，不从入围范围外临时补人，也不覆盖旧四条。
### Requirement: Sim2GSE limits pretraining observation to basic logs and time DPS curves

独立预训练 MUST 仅支持基础性能日志与时间每秒伤害曲线，两者默认关闭；恢复时日志采集使用本次调用选择，不改变原冻结算法、评分、材料、种子或评价身份。已生成时间曲线可离线比较，不为补曲线或日志重新评分。明确请求完整诊断、未知诊断档位或非关闭过程观测时须清晰拒绝，不静默降级，不提供预训练战斗伤害分布曲线。

系统 MUST 可靠保存成功结果及其独立证据，每十二份完成报告保存为一组，正常结束、取消及完整代边界仍须保存不足十二份的已完成结果；仅复用已有成功结果时不反复保存完整任务历史。突然退出后，尚未可靠保存或尚在计算的部分允许补算，不承诺零重算，也不能把一次保存的报告数量当作重算上限。该预训练观测边界不得删除或降级正式遗传算法既有完整诊断、过程观测及伤害曲线能力。

#### Scenario: Unsupported pretraining observation is requested

- **WHEN** 用户明确要求预训练完整诊断或非关闭的过程观测
- **THEN** 计算前清晰拒绝，不静默生成降级结果，也不影响正式搜索原有观测能力。

#### Scenario: Logging is toggled on resume

- **WHEN** 同一预训练任务以不同基础日志开关恢复
- **THEN** 只改变本次日志采集，沿原候选、种子及评分身份，已有曲线可离线比较而不补跑评分。

#### Scenario: The process stops before a report tail is registered

- **WHEN** 硬退出发生在尚未可靠登记的尾组或在途请求期间
- **THEN** 恢复核验并复用已可靠保存结果，允许补算尚未登记部分，不把一次保存的报告数量当作重算上限。
### Requirement: Sim2GSE accepts only effective training runtime settings

独立训练 MUST 在计算前拒绝未支持或不会实际消费的运行输入，不能接受后静默忽略，也不能将正式搜索配置当作训练计算配置。训练的参考准备仍按原100次请求执行，训练随机条件仍独立生成并随组冻结；不得把正式搜索的参考次数或随机种子偷偷带入训练。评分并发和分组并发使用各自训练配置入口，重复权威来源明确报错。

训练支持的按键间隔、重置事件、基础诊断日志及时间曲线 MUST 按实际有效选择执行。未提供按键间隔时，独立爆发训练仍默认200毫秒，非爆发训练仍默认300毫秒；明确指定的受支持间隔不得被默认值覆盖。新训练仅开启日志总开关时仍提供基础摘要；明确关闭细分程度不被强制改成摘要。完整诊断事件和搜索过程观测仍不属于训练支持范围，明确请求时拒绝。

训练仅保留既有共享曲线文件选项的兼容读取，本次明确选择优先；不新增从正式配置读取其他训练日志或计算设置。恢复沿用原冻结计算清单，合法文件变化不热改旧组，本次明确计算冲突须新建任务；本次明确观测选择优先，省略细分时沿用保存值，不猜测或升级已保存的关闭选择。当前配置文件本身非法时仍明确报错，不因恢复而静默忽略错误。

#### Scenario: An unsupported formal setting is sent to training

- **WHEN** 调用者将正式参考次数、正式随机种子或错误来源的评分并发传入训练运行设置
- **THEN** 在原生计算前明确拒绝，说明应使用支持的训练入口，不接受后忽略。

#### Scenario: Explicit training runtime choices are effective

- **WHEN** 用户为训练明确指定受支持的按键间隔、重置事件或基础观测选择
- **THEN** 实际执行使用这些值，训练原粗评、五场景复测及连续无提升规则不因此改变。

#### Scenario: A training group resumes with its frozen conditions

- **WHEN** 已有未完成组恢复，当前合法配置与原清单不同
- **THEN** 该组沿用原冻结计算条件；本次明确计算冲突拒绝，本次明确观测选择生效，未指定时保留保存值。
