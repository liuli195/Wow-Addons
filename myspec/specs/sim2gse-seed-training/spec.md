# Sim2GSE Seed Training

## Purpose

让用户人工清洗一次外部材料后长期复用，人工启动独立训练，从同一共享数据中心提炼可供正常搜索使用的起点。

## Requirements

### Requirement: Sim2GSE registers cleaned seed materials in the existing shared store

系统 MUST 将人工清洗件及其来源、原件或引用、作者用法、清洗说明、结构家族、核心片段与可模拟程序保存在既有项目共享数据中心；不得为本流程建立第二套业务存储或向用户技能链接安装测试文件。清洗由人或代理逐项完成，登记入口不自动猜测原宏。人工来源的修订或停用 MUST 使用明确稳定身份，不凭标题或网址猜测更新关系；来源停用不自动撤回已有入选代表。

训练与准备入口 MUST 自动将适用历史最佳程序同步到同一来源库，后续共用整理与评价流程。历史运行身份确定来源，程序、引用或明确有效状态变化作为修订，无变化不重复写入。已完成历史具有一致候选引用和可恢复程序即可作为当前重新评分材料；旧搜索只有一个样本、零分或缺少分数不得单独使程序失去入源资格，旧分数仅保留出处，不直接用于当前排名，也不证明完整独立训练。运行中、失败、引用缺失或不一致、不可表达材料保留原因；临时读取失败 MUST 明确报错，不伪装成来源删除或缩小本批输入。

#### Scenario: A cleaned external material is registered

- **WHEN** 用户登记合法清洗件并指定已接入共享数据存储的项目
- **THEN** 同一中心保存程序及其可追溯来源，后续可重复读取和训练，登记不启动网络采集或原宏解释。

#### Scenario: A completed historical program has only a weak or absent old score

- **WHEN** 已完成历史有一致候选引用和可恢复程序，但旧搜索只有一个样本、零分或缺少分数
- **THEN** 程序自动进入统一来源库并接受当前合法性检查及独立评价；旧分数不冒充当前成绩，误因旧评分质量停用的派生来源恢复活动并清除过时原因。

#### Scenario: A historical source is revised or temporarily unreadable

- **WHEN** 同一历史来源的最佳程序、引用或明确状态改变，或读取该来源暂时失败
- **THEN** 明确修订按同一来源更新并保留出处；暂时失败报错且保留先前可靠记录，不当作删除，也不继续发布缩小后的输入队列。
### Requirement: Sim2GSE retains seed sources and semantic boundaries

系统 MUST 区分语义保留、明确改写和当前不可表达材料，保留原件及逐项变化；待筛选来源、已处理、已入选和不可表达记录均可查询，未入选材料不得删除。已处理来源仍在可复用来源库中，不得将来源库列表冒称本轮未处理队列。成功施放日志不得被冒称原按键、等待指令或完整可循环宏；存在明确使用限制的材料必须保留限制和暂存原因。

#### Scenario: A material cannot currently be used as a program

- **WHEN** 用户登记没有可用程序的材料及其不可表达或使用限制原因
- **THEN** 来源和原因仍可查询，该材料不进入训练，不产生伤害成绩，也不被静默改写为支持状态。
### Requirement: Sim2GSE runs one manual training batch from a fixed input snapshot

系统 MUST 提供人工启动的一次处理入口，默认读取批次开始时的新清洗材料及同专精历史搜索最佳程序，处理后退出；不要求常驻服务。用户可明确限定已登记材料编号，仅处理该范围，不自动混入全库或历史成果。错误、非唯一编号、不适用或非活动材料及不支持的职业专精在计算前拒绝。训练期间新增材料不混入当前批次；历史来源可以跨角色，旧角色成绩不得直接用于标准角色下的排名。

独立路径并发 MUST 从既有内部训练配置读取，外层缺省2、范围1至3，单路径同层评分缺省2、范围1至16，乘积不得超过16；本次明确命令行值优先，启动后固定，不在运行中热更新。非法或超限组合须在任何计算前拒绝，不静默降参；内层16必须配外层1。每个引擎仍为单线程，默认2×2与可选3×2的本批引擎峰值分别不得超过4与6。系统 MUST 在一条路径完整结果可靠保存后才补派下一条，最终比较与记录顺序遵循冻结队列，不由完成先后决定。普通模拟读取不受训练区域的值或键影响，普通搜索默认及显式上限仍为2；场景继续顺序处理，同一路径的搜索与独立复测不重叠。

#### Scenario: The user starts a training batch

- **WHEN** 用户启动训练且没有普通搜索正在运行
- **THEN** 系统先完成本批唯一输入快照，再按固定范围有界处理并保存状态后退出，不自行持续轮询或再次启动。

#### Scenario: The user restricts the material scope

- **WHEN** 用户明确指定少量已登记材料，或提供无效编号
- **THEN** 合法编号只采用指定活动材料的实际初始程序表示与身份，保持正式收敛和独立复测标准；无效输入在实际计算前明确拒绝，不借全库其他表示替换或扩大训练范围。

#### Scenario: The user changes or explicitly overrides training concurrency

- **WHEN** 用户选择合法内部并发，或明确提供合法本次覆盖值
- **THEN** 本次覆盖优先，批次固定有效的外层与内层组合；多个路径真实交错执行但不超过乘积上限，完成结果可靠保存后补派，原预算、停止、复测及普通搜索权限保持。

#### Scenario: The combined training concurrency is invalid

- **WHEN** 外层或内层不是允许范围内的整数，或有效组合的乘积超过16
- **THEN** 在任何参考、整理或训练计算前明确拒绝，不自动缩小并发，也不修改普通模拟配置。
### Requirement: Sim2GSE deduplicates seed training without losing source relationships

系统 MUST 在相关语义条件不变时复用可靠完成的训练及复测成果，保留各来源关系，不因重启或仅调整外层、同层评分并发重复计算。完整路径复用还须核对实际初始程序表示；相同行为的不同程序树不得仅因行为相同就冒充同一完整搜索路径。A的最终赢家等于B起点不代表从B独立完成训练，B仍须补足缺少的完整路径；旧动态最终赢家免训记录不得冒称B已完成，其余可靠成果保持。训练运行、预检查和查询默认使用同一独立爆发模式；历史无爆发模式须明确选择。标准角色、引擎、场景、爆发内容、按法、种子、样本、评分或停止规则改变后，旧成绩不得当作当前成绩，材料须重新评价；真实训练、搜索、统计及程序行为变化须由相应的既有语义版本区分。源码摘要继续保留出处，不将纯调度或日志字节变化直接当作成绩身份变化。

旧批次 MUST 先严格核对完整原输入、规则来源、原条件、相关检查点及处理／入选记录，只有能证明相同语义的受核验旧来源才可继续使用原记录与缓存命名空间。入选的程序及成绩须对应同条件完成记录的初始或最终一组；未知、缺失、篡改或不一致凭据不得复用。仅对已审核固定来源范围内的源码换行差异，受控导入须现场读取原文件，原字节摘要匹配原输入且规范化内容匹配固定基线后，才保存绑定原输入与基线的出处核验结论；后续使用须核对结论及当前规范化内容，原完整输入和条件不得替换，未知范围或真正内容变化仍拒绝。该出处结论沿用受控导入器及既有账本信任边界，不声明对任意恶意重写整个账本的认证保证。未完成任务须保留随机进度、已用预算及可靠成功批次，另外记录实际并发和执行来源；不得改写旧成绩冒充新成绩或全库迁移。发布失败可恢复，不覆盖旧成果；升级后核验遵循同一身份契约，原评分批次验真不放宽。

#### Scenario: The same complete initial path is encountered again

- **WHEN** 用户在条件未变时重复训练，或新来源提供与已核验完整路径实际初始表示一致的材料
- **THEN** 系统关联来源而不重复可靠搜索和复测，原成绩与记录保持；只有缺少完整独立路径的起点继续处理。

#### Scenario: Another path finishes at an untrained initial program

- **WHEN** A可靠完成后的最终赢家等于尚未完整训练的B起点
- **THEN** A原可靠成果保留，B仍以自身实际初始表示完成独立搜索及初始、最终各三批复测，不按旧动态最终赢家政策免训。

#### Scenario: Equivalent behaviors have different program trees

- **WHEN** 明确选中的活动材料与全库代表行为相同但实际程序树不同
- **THEN** 本批使用所选材料的实际初始表示；全库另一程序树的完整路径不能替代它，来源关系与可靠其他成果继续保留。

#### Scenario: Training and query use the same default mode

- **WHEN** 用户未明确选择历史无爆发模式而运行、预检查或查询训练
- **THEN** 三个入口均使用独立爆发模式及其条件和记录；明确选择历史模式时只读取对应范围，不混入其他模式成绩。

#### Scenario: Concurrency changes without changing evaluation semantics

- **WHEN** 用户仅改变有效的外层或同层评分并发，或在未完成搜索中以新并发继续
- **THEN** 完整成果不重训和复测；未完成搜索沿用原随机进度、已用预算及成功请求，实际执行变化另行记录，原完整成绩与命名空间保持。墙钟截止可能改变随后完成范围，不承诺整个限时搜索赢家相同。

#### Scenario: An existing batch has a verified original identity

- **WHEN** 旧批完整原输入可复算到原条件，相关检查点、处理及入选程序／成绩一致，并能严格证明当前语义兼容
- **THEN** 训练和升级核验认可原记录及缓存命名空间，保留原来源，已完成项不重训，旧成果继续参与同批入选；没有完整证明或实际语义改变时拒绝复用，不伪称新源码完整哈希等于旧值。

#### Scenario: A verified old source differs only in physical line endings

- **WHEN** 已审核固定来源范围的原文件与当前文件只存在换行差异
- **THEN** 受控导入现场核对原字节与完整旧输入、规范化内容与固定基线，保留可核对出处结论而不替换旧输入或条件；训练和升级核验还须确认当前规范化内容未变，缺少证明、未知来源范围或真正内容变化时拒绝复用。

#### Scenario: A retest report has a different condition or program

- **WHEN** 升级核验遇到引擎、条件、程序或独立复测规模不匹配的评分批次
- **THEN** 即使训练记录的旧语义身份已被核验，也拒绝该批成绩，不用身份兼容绕过原评分批次校验。
### Requirement: Sim2GSE trains seeds with the locked standard character profile

系统 MUST 默认使用当前已核验引擎配套的完整标准角色进行训练，不使用旧版或私人角色冒充标准角色；明确指定其他模板时如实标明。所需模板缺失须在计算前报错。训练与页面模拟采用一致的角色检查、爆发兼容及动作限制，各自保留实际角色和训练或搜索规则。单目标与群体场景分别处理，不混用不同条件的成绩。

#### Scenario: A seed from another character is assessed

- **WHEN** 来源角色不同于本批标准角色
- **THEN** 系统在本批完整标准配置及实际参数下重新评价该程序，保留输入身份，不把来源旧成绩作为当前成绩。

#### Scenario: The engine changes or the standard template is missing

- **WHEN** 当前受检构建改变，或所需标准模板缺失
- **THEN** 默认训练定位当前构建配套模板；模板缺失则在模拟前失败，不能静默退回旧版本目录。
### Requirement: Sim2GSE gives each training path independent complete rounds

系统 MUST 为每个候选独立搜索至连续两个完整轮次没有确认改善后停止，确认改善全局最佳即清零，不设置固定五轮封顶。起点评分不算搜索轮次；不足一轮候选数量的轮次不增加无改善计数，但确认改善仍清零。每轮最多16候选，单条路径累计搜索上限600秒，候选总上限保持。沿用现有评分、动作空间、选择概率与缓存。现有生成机制无法提出新合法候选时也可正常结束；预算、候选上限或取消提前结束不得冒称收敛或发布新库。参考模拟与独立复测单独记录，不能把多候选整批冒称一次600秒普通搜索。新训练规则与旧固定五轮记录分开，旧成绩保留且不得冒称新规则验收。

#### Scenario: A training path has two complete unimproved rounds

- **WHEN** 一条候选路径连续两个完整轮次未确认改善
- **THEN** 该路径结束搜索，记录实际轮次、耗时、缓存和新增模拟量，完成独立复测后按既有规则筛选；其他候选独立处理。

#### Scenario: An improvement arrives after an unimproved round

- **WHEN** 已有无改善计数的路径确认找到更好的全局最佳，包括不足一轮候选数量的轮次
- **THEN** 无改善计数清零，继续搜索，持续改善时可以超过五轮；预算和其他上限仍有效。

#### Scenario: Training reaches a budget or candidate limit before convergence

- **WHEN** 训练尚未达到连续无改善或无新合法候选条件就耗尽预算、达到候选上限或被取消
- **THEN** 保存实际进度并报告未完成，旧入选库保持，不以旧五轮条件或部分结果冒称训练完成。
### Requirement: Sim2GSE selects retested performance and structural seed representatives

系统 MUST 在未参与搜索的三个固定随机条件下分别复测初始、优化后及现有代表，复用既有配对比较；成绩替换要求95%区间下限大于零，样本不足不得用于替换。另可保留少量合法、完整评分且可继续修改的不同结构家族代表；结构核心必须仍存在于被选程序中，来源标签不得盲目继承给已丢失核心的优化结果。后者可作为普通历史成果。每场景新增代表最多四个，不按作者或来源凑数量。

#### Scenario: Search improves damage but removes the registered core

- **WHEN** 优化后程序不再包含来源核心片段
- **THEN** 系统不将其当作该结构家族的保留证据；可将优化结果作为历史成果，并另行评价仍保留核心的初始结构代表。
### Requirement: Sim2GSE publishes seed snapshots automatically and preserves the old library on failure

系统 MUST 自动以同一逻辑键原子写入完整小型入选快照，不要求逐个确认入库，也不生成日常复测报告。成功前旧快照保持可用；本批冻结且仍必需的实际初始路径有未完成、取消、预算不足、复测不全或可靠保存失败时，不发布部分新库。已停用或不再属于本批必需路径的旧失败记录 MUST 保留证据，但不得永久阻挡本批合法完整成果发布；是否完整按实际初始表示及可靠归属核验，不只按来源活动编号判断。发布失败允许基于可靠已完成结果重试。暂时不可读、明确损坏或模拟失败应如实报告，不能静默置空库、伪造成功或把多键写入称为事务。

恢复 MUST 延续正确阶段：搜索已正式结束但独立复测中断时不重开搜索或重置已用预算，精确核验后只补缺少的复测批次；完整结果尚未汇入本批记录时可补保存，不重搜或重测可靠成果。成功评分在取消收尾前可靠保存，统计及缓存请求身份继续严格核验，不借恢复放宽六批复测或完整停止标准。

#### Scenario: Publication fails after training

- **WHEN** 训练结果已经可靠保存，但新快照写入失败
- **THEN** 旧入选库不变，入口报告失败，重新启动可继续发布而不重复可靠完成的计算。

#### Scenario: Retesting or final result handoff is interrupted

- **WHEN** 搜索正式结束后部分独立复测成功但中断，或完整结果已可靠保存但尚未汇入本批记录
- **THEN** 恢复只补缺少的可靠成果或保存步骤，不重开搜索、不重复有效复测，也不重置原已耗搜索预算；完成前旧库保持。

#### Scenario: An inactive historical failure is outside the required queue

- **WHEN** 旧失败路径不再属于本批冻结且仍必需的实际初始路径，而本批全部必需路径已有可靠完整归属
- **THEN** 旧失败证据原样保留，本批完整成果可发布或零计算重试发布；若仍必需的实际初始路径有缺口，旧库继续保持。
### Requirement: Sim2GSE reads selected seeds once without running training in normal search

系统 MUST 在正常搜索初始化时只读取对应职业、专精、场景及引擎身份的小快照，按当前角色合法性和编译限制检查并去重，在原四类起点后追加最多四个代表；不更改用户角色配置、不扫描全历史、不启动训练或复测。快照固定到当前任务，恢复时沿用原快照，中途不刷新。空库沿用原搜索；身份不适用的候选跳过，读取异常不得掩盖为空库。

#### Scenario: A normal task starts with a usable library

- **WHEN** 用户启动正常搜索，且存在身份适用的入选快照
- **THEN** 任务读取一次快照，将合法且不重复的代表追加到原起点后，并通过原搜索继续评价和修改；搜索及归档不触发训练反馈计算。
### Requirement: Sim2GSE prioritizes normal search over manual seed training

系统 MUST 让普通搜索不等待训练：训练开始前发现普通搜索则退出；训练中普通搜索启动时，通过现有取消能力停止补派并取消本批全部所属路径和模拟，保存可靠成果及旧快照，不按进程名终止其他任务。训练活动在全部所属计算收尾后释放，取消或保存失败不得留下继续补派的路径。允许短暂取消收尾窗口，不承诺物理零重叠；两个训练场景应由同一批次活动管理且继续顺序运行。

#### Scenario: A normal search starts during concurrent training

- **WHEN** 多条训练路径正在模拟而用户启动普通搜索
- **THEN** 普通搜索立即继续，训练停止补派、取消并等待全部自身所属计算收尾，保留可靠证据及旧库，其他进程不被终止。
### Requirement: Sim2GSE distinguishes batch seed evidence from original macro and game equivalence

系统 MUST 分别记录来源方案、成员、来源版本、清洗程序、原程序唯一数、当前唯一输入、实际初始路径、完整／待补／恢复／失败路径及入选代表，保留全部出处、初始与最终程序、逐来源核心保留、缓存和真实新增模拟证据。当前唯一工作量须来自训练前完整冻结队列，不把来源数或动态免训冒称完整路径数。循环检查必须关注回绕及后期执行；请求迭代数与有效统计样本应区分。固定标准角色的改写件可运行不等于原宏完整复现、游戏验收或正常600秒搜索收益。

不同并发设置的性能比较 MUST 使用相同输入、受检引擎与评价条件、随机条件、缓存起点及工作量，覆盖准备、搜索、独立复测、归档和返回，另记实际请求、命中、原生启动、完成量、收敛、CPU／内存及所属进程峰值。新增起点评分成本应单独说明；缓存优势不得全部归因于起点，不承诺倍速。旧引擎条件的完整／待补数量不得冒称新引擎条件的复用或完成；未完成目标系统、私人语料、性能或游戏验证不得报为通过。

#### Scenario: ABC and the existing full corpus are accepted

- **WHEN** ABC及已有社区、日志和插件材料完成清洗、批测与集中评审
- **THEN** 用户可核对实际来源、程序与当前唯一队列数量、改写、去重、核心保留和入选原因；未通过或有使用限制的材料保留，不将其报成全数支持或全网穷尽，不将未测游戏与正常搜索收益报成通过。

#### Scenario: Training concurrency or the controlled engine is compared

- **WHEN** 用户比较1×4、2×2、3×2等合法设置，或受检引擎身份已改变
- **THEN** 并发收益按同条件同工作量真实证据报告，身份改变时重新核算适用的完整／待补路径，旧条件成绩与未运行检查另列，不借准备计数声称新条件训练完成。
### Requirement: Sim2GSE accepts long castsequences as searchable seed programs within macro limits

系统 MUST 在搜索起点入口接受含2至32个成员的受支持原生施法序列，同时遵守255字节宏文本、合法动作、重置、展开与导出一致性限制；不得仅因超过旧的短成员上限而拒绝。多个独立施法序列按各自成功施放推进状态处理，不能为接入而展平为不同推进规则。该能力不扩展其他原宏条件或高级控制结构。

#### Scenario: A cleaned seed contains more than four castsequence members

- **WHEN** 清洗起点含5至32成员的施法序列，且宏文本及其他编译模拟条件均合法
- **THEN** 起点可进入现有评分和搜索，不被旧短成员限制拦截；超过32成员或255字节时明确拒绝，不绕过限制。
### Requirement: Sim2GSE incrementally prepares and freezes the complete unique seed queue

系统 MUST 为训练与人工准备入口提供同一持久整理流程；人工准备不搜索或独立复测，用户也不必先手动准备才能训练。准备快照保存在既有共享数据中心并可查询；无变化不重复共用参考、逐来源整理、行为归一化或输入编译，新来源及修订只处理受影响项。明确展示元数据只更新关系，结构家族和核心变化只重新核对相应归属，不单独废弃可靠成绩。影响用法、角色、场景、爆发、引擎或准备语义的变化 MUST 重新核验受影响配置；缺失、确定损坏或未知版本的派生缓存重建，临时环境、存储或取消故障不得冒称材料非法或空库。

系统 MUST 在首次训练派发前可靠发布包含全部来源、原因、改写及行为分组的完整唯一快照；按实际完整点击行为识别重复，保留顺序、空点击、施法序列及重置语义。稳定代表的实际初始表示不因标签、读取顺序或代表来源停用随机更换，只要该表示仍合法且该组仍有活动来源。显式限定材料时，本批采用所选活动材料的实际初始表示，不拿全库另一程序树替换。训练期间新增来源留待下次；准备失败不派发半队列，无活动合法输入不清空旧入选库。

同次准备 MUST 在既有锁内只读取一次登记材料快照，历史同步、显式材料选择与各场景准备复用其可靠更新结果；非法、未知或已修订的旧材料编号仍明确拒绝，重复编号沿用既有去重，不因复用快照放宽来源及身份核验。

#### Scenario: Unchanged or revised sources are prepared

- **WHEN** 用户再次准备或直接训练相同配置，或只新增／修订一个来源
- **THEN** 无变化复用持久准备；变化只整理受影响项，仍保留全部出处及稳定表示，可靠训练成绩按独立身份规则核验。

#### Scenario: Equivalent source forms or inactive representatives are encountered

- **WHEN** 原程序重复、去爆发后重复或相同行为的不同程序树同组，或原代表来源停用但组内仍有活动来源
- **THEN** 训练前固定完整唯一队列，逐来源保留原件、核心和改写关系，不随机改变仍合法的稳定实际表示；明确限定材料时实际初始表示来自指定活动材料。

#### Scenario: Preparation fails or no active legal input remains

- **WHEN** 准备快照未能可靠发布，或当前范围没有活动合法输入
- **THEN** 未完成准备不启动训练，也不使用部分快照；无输入如实报告且旧入选库保持，不伪造删除或成功。

#### Scenario: Multiple selected materials are prepared for both scenes

- **WHEN** 同次入口指定多个登记材料或重复编号，并准备两个场景
- **THEN** 登记材料读取一次，历史同步后的同一快照用于选择和各场景准备；合法重复编号按原规则处理，未知及已修订旧编号仍拒绝，不用第二次登记读取重新选取材料。
### Requirement: Sim2GSE preserves shared batch evidence across concurrent seed paths

系统 MUST 可靠保存多路径并发的共享成功请求、报告和所属路径成果，不能因并发写冲突丢失有效结果或静默最后写入覆盖不一致成绩；临时读写失败明确报告，并沿用原成功结果核验及恢复边界。同请求跨路径并发未命中允许实际重复启动，但请求、缓存命中与原生启动次数必须如实记录，不伪称重复计算已去除，也不把缓存复用增加为独立样本。

按当前诊断规则保存的轨迹 MUST 保留实际生成路径及请求出处；两个路径各自实际执行时分别保留来源，缓存命中引用原轨迹出处，不重算仅为制造新轨迹，也不把旧轨迹冒标为当前路径新生成。已可靠完成路径的原账本保持，新执行变化另记。

#### Scenario: Concurrent paths execute or reuse the same request

- **WHEN** 不同独立路径同时未命中同请求，或后续路径命中已有可靠成功请求
- **THEN** 实际重复启动及命中准确计数，共享报告可靠保存；保存轨迹时各自执行来源可追溯，命中保留原轨迹引用而不伪造当前路径执行。

#### Scenario: A shared report conflicts or cannot be saved

- **WHEN** 同请求的待保存成绩与已有可靠报告不一致，或共享报告暂时无法读写
- **THEN** 明确报告失败，保留可靠原成果和旧入选库，不以静默覆盖、空记录或部分新快照隐藏故障。
