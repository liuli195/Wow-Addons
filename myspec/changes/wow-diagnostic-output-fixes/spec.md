# 网页任务诊断选择与魔兽插件测试诊断输出

## Problem Statement

角色按键序列优化器原有网页只展示启动命令指定的诊断状态，不能为本次任务更改。用户现明确要求网页选择覆盖本次任务；这是对原有启动值权威契约的新需求，不把原行为归为缺陷。仓库维护的魔兽插件测试工具承诺保存完整环境诊断结果，但该命令未保存；缺少可用后端时的提示还错误地把共享库列为可显式指定的程序。

## Solution

1. 网页性能诊断日志可勾选或取消，初始值继承当前服务启动设置。创建单场、双场、第三方序列导入模拟及继续未完成双场任务时，本次明确选择优先；未提供选择的调用者继承当前服务默认，非布尔选择明确拒绝。
2. 选择只影响本次任务及后续恢复运行的诊断输出，不修改服务默认、其他任务或已经运行的计算。两场及相关导出沿用本次选择。关闭恢复后不新增被关闭的诊断记录，已存历史记录保留。恢复不补历史日志、不重复已完成场景，原身份与恢复资格不放宽。
3. 魔兽插件测试工具在用户指定输出文件时保存完整环境诊断结果；未指定时不额外写文件。控制台裁剪与完整文件独立；后端可用与不可用的既有退出行为不变，写入失败明确失败。
4. 缺后端提示说明显式设置仅接受 Lua 可执行程序；未指定程序时仍可按原顺序自动发现 Lua 共享库。不新增后端或共享库显式配置能力。

## User Stories

1. 用户打开网页时看到与当前服务启动设置一致的初始诊断选择。
2. 用户可为主搜索开启或关闭日志，不重启服务。
3. 用户可为第三方导入模拟使用同一个诊断选择。
4. 调用者省略选择时继续使用服务默认；明确关闭也能覆盖默认开启。
5. 用户继续未完成双场任务时可更改本次日志选择，完成场与有效结果仍保留。
6. 用户在运行期间调整网页选择，不会改变已经启动的任务。
7. 用户取得完整环境诊断文件，即使控制台摘要被裁剪。
8. 用户在后端不可用或输出文件不可写时得到原有明确失败结果。
9. 用户依据错误提示设置可执行程序，而不会误把共享库交给程序路径设置。

## Implementation Decisions

复用现有任务选项、诊断运行时、后端探测与完整结果写入能力，不建立新配置层。日志选项继续排除在算法身份外，不改变评分、缓存、报告来源、曲线及其他恢复资格。沿用各入口既有日志等级选择规则：网页主搜索在开启时选择完整搜索过程记录；恢复开启时原先关闭的诊断模式使用摘要。不给其他入口新增等级联动，不强制所有日志使用最高级别。集合包整理与独立导出一致继承本次诊断选择。

## Testing Decisions

从真实网页点击和请求处理入口验证创建、导入、恢复与非法选择；复用已存在的计算和持久输入替身，不运行原生搜索或游戏。覆盖服务默认开关、选择省略及显式双向覆盖，确认两任务互不串值、默认不变。必要编排测试观察子场和导出的实际诊断运行时或输出，不只比较请求字典。命令行入口验证完整文件、无文件、后端可用与不可用、写入失败，以及未配置程序时的共享库自动发现。

## Out of Scope

不修改技能源仓库、用户下载副本、构建验证工具、第三方界面插件、原生引擎、算法或一千二百秒问题。不运行大规模模拟，不合并主干、不清理其他分支，不影响正在退役收尾的工作树与正式规格预览。正式规格仅在独立受控预览及门禁二确认后应用。

## Further Notes

用户已明确批准三项工作及独立云端工作区域、功能分支；门禁一的完整展示与确认记录另行核对。预计总投入一小时三十分至三小时，增量证据不超过三十兆字节。范围外长操作或磁盘扩大先停止并请求批准。
