**What to build:** 用户通过网页可操作的诊断复选框为主搜索、导入模拟和恢复设置本次选择；服务启动设置仅作为初始默认。

**Blocked by:** None（可独立开始；在第二票后串行实施）

**Status:** verified（整合树本机验收及完整第二门禁已通过，待拉取请求交付）

- [x] 服务默认开或关时，省略选择继承默认，明确开或关覆盖本次任务；非布尔选择拒绝。
- [x] 网页主搜索、导入和恢复均发送明确选择，初始复选状态与服务一致。
- [x] 两任务互不串值、服务默认不变、已运行任务不受网页后续勾选影响。
