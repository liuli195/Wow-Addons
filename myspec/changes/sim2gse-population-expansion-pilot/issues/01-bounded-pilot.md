**Blocked by**（阻塞任务）：无。

## 交付内容

## 验收条件

- [ ] 用户可通过最高命令入口运行隔离验证，默认一个标准角色、实际单目标。
- [ ] 原材料、参考、角色/英雄/目标数、四项关闭语法、爆发及引擎身份可核验，旧不兼容凭据不作当前成绩。
- [ ] 新起点按已定50/50配方生成；对照直接复用生产三概率繁殖、反馈和合法性处理，相关抽取不改变生产行为。
- [ ] 双方提案有界、重复口径透明；各四条在独立复评前锁定，确认不足不判优。
- [ ] 1800秒、256次引擎启动、6000次请求迭代任一上限达到即停止，准备/反馈/重试纳入；只回收自身进程树。
- [ ] 生产数据只读，验证数据在隔离项目共用根，完整请求与报告可追溯；不发布正式种子或冠军。
- [ ] 真实命令层测试覆盖阶段闭环、独立确认、故障和限额，相关检查接入统一验证并通过独立审查。
- [ ] 运行一次获准的小额真实探路，输出可复核报告；缺材料、缺依赖或预算不足如实报告，不启动完整训练。
