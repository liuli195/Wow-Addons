# 01: 搜索并评价顺序循环候选

**What to build:** 自动搜索实际生成、评价和导出最小顺序循环及其重复次数，模拟使用 GSE 编译出的同一点击计划。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 公开自动搜索入口产生并评价至少一个顺序循环候选，而不是经第三方导入入口注入。
- [ ] 不同 Repeat Count 具有不同候选身份；GSE 编译后的顺序、次数、来源与原生评价一致。
- [ ] 超限或无法忠实编译的候选在原生评价前拒绝；普通动作候选仍能搜索、导出和评价。
- [ ] 评分、选优、预算和复测规则未改动。
