# 02：新繁殖贯通材料到训练四代表

**What to build（交付行为）:** 用户从现有训练入口提交材料，各模板／英雄／目标数组按对应参考生成候选，完成原五场景复测并发布四个合格代表，暂停后可沿原路径恢复。

**Blocked by（阻塞任务）:** 01：从真实执行到可核验成功摘要。

**Status（状态）:** ready-for-agent

## 验收条件

- [ ] 原材料准入、来源保留、语法和独立爆发排除保持；各组独立冻结参考、三概率、策略版本与随机状态。
- [ ] 共用合法基础操作；随机路径选择合法操作、位置及必要技能，先排除明确无效操作并计入固定战前前缀容量，复杂编辑能力保留。
- [ ] 频率和相邻关系各至多一条建议，去重合并依据；两维平级，一次目标只做一个操作，无建议跳过而不强制随机。
- [ ] 已有技能成功不足时只在增加一处／移动已有一处中选择：两种合法各50%，只有一种选它，均不行跳过；不依据成功率、不回到2.1／2.2、不额外评分两版。
- [ ] 训练采用目标→随机→交叉三个独立门，移除外层总变异与旧反馈门，保留框架包、父本保护、原选择、交叉力度、合法重复和完整换代。
- [ ] 同一配置文件训练段的新概率实际生效；旧总变异参数明确退役，非法值模拟前拒绝；在票03接入前正式入口继续原版本策略，不产生半接入状态。
- [ ] 复用粗评成功摘要；现有位置反馈按完整条件复用，错误不吞，无逐建议或中间状态评分；计数区分触发、变化、启动、完成与复用。
- [ ] 从真实训练公开入口的确定性测试贯通材料、初代、至少一完整繁殖代、停止、正常加四扰动复测及四代表发布重读；不足四条和失败保留旧库。
- [ ] 取消恢复重放同一随机路径、待处理子代及重试次数；旧未完成任务不换策略续跑，正式规格不提前改。
- [ ] 频率／时序按设计整数比值及三类判定表处理，零分母未知，无隔开见证不伪称找到阻隔原因；相同操作位置去重，排序及随机重放可复现。
- [ ] 随机移动保留连续1～4项及原约束，目标移动只改源结构一处；复杂结构不展开后修改一个副本，不能定位时跳过该建议。
- [ ] 同行为不同源结构复用成绩时重新绑定当前位置；覆盖反馈中、目标后／随机前、随机后／交叉前、非法重生及评分完成未提交整代的恢复，可确定性重放未可靠保存部分。
- [ ] 训练仍仅基础日志／时间曲线：业务摘要及恢复状态始终有，纯诊断关闭为未采集，不增加双父本／切点完整历史；每票结束正式原入口不退化。
