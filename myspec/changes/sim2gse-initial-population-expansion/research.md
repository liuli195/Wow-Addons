## 研究问题

## 方法比较

以下官方资料说明的是采样或初始化方法，不是本项目每秒伤害提升证据；“适用性”列是基于本仓库约束的研究判断。

| 方法 | 官方资料确认的能力 | 在本项目的适用性与限制 |
| --- | --- | --- |
| 标准库随机抽取与打乱 | `shuffle`（原地打乱）重排已有列表；`sample`（不放回抽取）抽取输入位置，输入若有重复，结果仍可能有相同值；独立随机对象可保存和恢复状态。见 [Python官方文档](https://docs.python.org/3.12/library/random.html#random.sample)。 | 可复用现有能力作基线；必须先按真实行为去重。无约束随机不能保证长度、动作组合或相邻关系都分散。 |
| 分层分配后桶内随机 | 可用上述标准库抽取完成每类候选的选择；分层定义与分配规则需本项目另定。见 [Python官方文档](https://docs.python.org/3.12/library/random.html#random.shuffle)。 | 能直接表示长度、动作覆盖、结构等离散差别；桶不能只看名称，还要防止不同桶映射成同一行为。空桶如何补位、各桶多少均待确认。 |
| LatinHypercube（拉丁超立方采样：每个数字维度分层各取一点） | 在单位数字空间中，每个单维小区间恰有一点；普通形式可取300。更强的二阶形式要求样本数为质数平方。见 [SciPy官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.qmc.LatinHypercube.html)。 | 适合已明确数字维度的候选参数；变长程序、离散动作映射、合法性过滤和行为合并后，原来的分层性质不自动保留。不能称为“300个合法程序均匀分布”。 |
| Sobol（索博尔采样：减少数字空间空洞的一种采样序列） | 官方保证均衡的安全入口取2的整数次幂个点；非该数量、跳点或抽稀会失去均衡性质。见 [SciPy官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.qmc.Sobol.html)。 | 300不是2的整数次幂；先取更多再截成300、过滤非法项或合并重复项，不能沿用原均衡保证。引入它仍需解决程序映射。 |
| DEAP（进化计算工具库）的初始化入口 | `initRepeat`（反复调用生成函数）仅调用指定次数；`initIterate`（接收自定义生成器的结果）只把结果装入容器。见 [官方源码](https://deap.readthedocs.io/en/master/_modules/deap/tools/init.html)。 | 仓库已经使用该库，可接入自定义准备步骤；这两个入口本身不提供合法性、行为去重、覆盖或300个不同程序的保证。 |
| 有限候选池中挑差别较大的程序 | 这是待核对的项目设计方向，不是上述库自动提供的保证。现有行为身份可排除完全重复，见 [program.py](../../../projects/sim2gse/program.py)：396起。 | 先生成有限池，再按长度、动作占比、相邻关系等选择，可检查留下的候选实际覆盖；“差别”定义、计算量与池耗尽处理仍需确定，不能声称全空间均匀。 |

## 待交叉核对的组合方向

以下仅供主代理与布丁比较，尚未选定：保留现有合法材料，按若干可解释差别分层，桶内随机，再从有限候选池挑选差别较大的程序。生成过程应参考当前角色实际成功动作汇总，同时留出探索不同组合的机会。

- 成功比例只作软引导。仓库已明确区分“尝试频率”和“成功执行频率”，不能把原生成功次数比例直接写成按键频率硬规则。见 [领域词汇](../../../docs/CONTEXT.md)：术语“尝试频率”；[breeding.py](../../../projects/sim2gse/breeding.py)：1、13–14。
- 合法但参考成功次数很低或为零的可按动作，不能仅凭这一项被永久排除；是否进入程序仍须遵守角色资格、爆发排除、语法与编译限制。这是探索方向，不是放松合法性。
- “尽量分散”应看经过映射、过滤和去重后实际留下的候选，不看生成前数字点有多整齐。可以比较动作覆盖、长度分布、动作占比与相邻关系覆盖；具体分层和差别算法尚未决定。

## 工程影响与边界

1. 扩充应在新任务初代冻结前形成可核验结果，并保留原材料来源与新增候选来源；恢复任务不能悄悄更换初代。现有冻结与恢复检查见 [population_training.py](../../../projects/sim2gse/population_training.py)：548–593。
   - 待核对的保存方式：原材料来源清单继续保存原队列，扩充后的初代和生成出处另外写入任务初始化清单。生成程序不能伪装成人工材料来源，否则会改变恢复时的材料重建；依据同文件498–499、550行。
   - 报告应区分原材料去重数量、新增有效数量与初代总数；仅准备入口也需采用一致口径。依据同文件526–529、626行。
2. 原生参考摘要、角色动作范围、语法和实际目标数须来自同组条件。已存在摘要并不意味着无材料初始化路径已经可用；该缺口要单独处理。
3. 增加300个候选会影响初评、完整换代、检查点保存与失败恢复；不能只估初代成本。当前每代容量逻辑见事实表。此处没有运行证据，不能报耗时或收益。
4. 可优先复用标准库、现有进化工具库及行为检查；仓库依赖清单当前没有 SciPy（科学计算工具库）。采用新的采样库前，仍需证明它对受约束程序有实际帮助。见 [requirements.txt](../../../projects/sim2gse/requirements.txt)：1–4。
5. 研究范围只涉及训练初始种群；不自动更改正式搜索起点来源、五场景复测、最终四代表、并发额度或语法开关。

## 主代理独立建议（交叉审核前）

采用“分层分配、类内随机、有限候选池内选择较分散者”。不更改遗传算法工具库，不新增科学计算依赖。以下均为工程建议，尚无本项目采样对照或伤害收益数据。

1. 每个独立训练组以300为目标下限：保留原有效材料，缺多少补多少；原材料超过300时保留全部，报告实际数量。300是可配置目标，不是跨组总数。独立训练评分失败保持原有重试后报错，不自动跳过补位；不能借用正式搜索复用分支的拒绝与容量规则。
2. 候选必须是一键一技能的完整循环列表，复用现有角色映射、爆发排除、四项语法开关、合法性检查与行为去重。战前固定前缀不参与随机生成；普通列表最大长度为128减去固定前缀长度。
3. 长度分短、中、长；技能次数分布分参考附近、参考定向偏移、广泛探索；排列分参考相邻关系引导与自由随机。三类长度覆盖全部合法长度，不能因经验判断先砍去极短或极长列表。是否采用全部18个交叉类别以及长度分界，待与布丁比较后简化。
4. 参考附近只代表成功动作比例附近的初始化偏好，不承诺尝试比例正确。定向偏移让不同技能轮流增减；广泛探索允许参考中零成功但角色合法的普通技能，不要求短列表装下全部技能。次数取整后总和必须等于目标长度；排列不能改变已确定的次数。
5. 先产生有限小池，再在每类中挑选与已保留程序差别较大者，防止只获得同一起点的微调。可比较长度、技能占比、相邻技能组合与首技能。该方法借鉴[最远优先选点原论文](https://sites.cs.ucsb.edu/~teo/papers/TCS-ktmm.pdf)，但这里使用受约束的程序描述，不能继承论文针对特定距离问题的近似保证，更不能推导伤害提升。
6. 原始材料继续进入原来源清单，新增候选另记生成出处；只在新任务初代冻结前扩充。冻结生成版本、配置、种子、参考身份及最终列表；恢复时读取同一份列表，不重新抽样。原任务不静默扩充。
7. 首版保留无有效材料报错。纯角色参考初始化是独立缺口，不以这次扩充顺便改变。达到尝试限额须报告“未补足”与实际数量；只有有依据时才能称空间不足，不复制凑数，不无限重试。
8. 扩充只改变训练初代。其后继续现有繁殖、评分与复测流程，保持最终四代表及正式搜索现有起点来源。后续每代容量随可靠初评数量扩大；并发额度不随之提高。

## 后续验证建议（本次未执行）

- 在相同角色、目标数、语法、原材料、随机种子组及候选尝试预算下，比较普通参考加权随机、分层随机、分层加有限池挑选三种方法。必须计算被过滤、重复和落选候选的成本，不能给某一方法隐藏的额外预算。
- 报告实际不同程序数、各长度与技能搭配类别覆盖、合法技能与相邻组合覆盖、最近相似程度分布、生成耗时；原材料与新增候选分别统计，并补充全体统计。保留偏科原材料时，不能保证全体平均。
- 用两个技能、合法长度1至4的极小条件检查“仅30种列表却请求300”的处理；要求如实报告短缺。另覆盖参考零值、无法映射、固定前缀占满、原材料超过300和恢复不重抽等边界。
- 覆盖指标只能验证是否分散。伤害收益须在另获授权后，用相同总模拟预算通过现有正式评分验证，不能用程序差别代替伤害，也不能仅凭初代多就声称更好。

### 具体生成规则

| 维度 | 推荐起始规则（工程假设，未证实最优） |
| --- | --- |
| 数量 | 每独立训练组目标300，原有效不同行为数为N，新增G=max(0,300−N)。N超过300全部保留，不按旧伤害截断。 |
| 长度 | 普通循环最大B=128−固定战前块数；分1–8、9–32、33–B三档，与1–B取交集。空档移除，其余档尽量等额，档内随机取长度。B小于1明确停止。 |
| 技能次数 | 约2/3名额参考引导，约1/3宽探索。参考引导将成功占比与合法技能等权占比按0、25%、50%的等权混合程度轮换，换算成整数次数并保持总和等于长度；宽探索轮换照顾较少覆盖的合法技能，其余次数随机分配。不会要求每条短列表包含全部技能。 |
| 排列 | 每类约一半自由打乱既定技能次数；一半参考相邻关系软引导。引导排列每一步同时保留按剩余次数随机选技能的机会，不能把参考中未出现的相邻对变成禁止。无可比较相邻信息时退回剩余次数随机。 |
| 首技能 | 在剩余次数允许时优先照顾新增集合中首位较少出现的技能，不能偷偷改变刚确定的技能次数。 |
| 名额 | 三长度×两次数策略×两排列策略，共最多12类；按上述权重分配新增G，整数余数稳定补齐，总和恰好G。G过小时不保证每类都有；重复或非法不占名额，有界重试后可转移缺口并记录实际偏差。 |
| 去重 | 按现有完整行为身份去重，不按名字；不把不同开头的循环擅自合并，也不新增子代强制去重规则。普通列表的尾首边可以描述循环结构，但不得声称它是参考中观测到的跨战斗相邻事件。 |
| 不足处理 | 可证明空间不足时报告原因；仅用完提案预算时报告“预算内未补足”。两者均在评分前停止并保存诊断，不复制凑数、不自动悄悄用较少初代开跑。预算值待低成本验证后确定。 |

12类分别有名额，不意味着12类等额；参考引导约2/3、宽探索约1/3是明确权重。以上长度分界、混合程度及比例都没有本项目伤害证据支持，允许后续通过同预算对照调整。成功比例仍只是软参考，最终伤害评分不改变。

### 完整链路及最小改动

1. 原材料准备：沿用现有语法过滤、角色适配、独立爆发排除、合法性与去重；不把被禁止的复杂材料悄悄拍平成新材料。首版仍要求至少一份有效材料。
2. 同组参考：复用已有成功摘要，按真实模板、英雄与实际目标数校验身份；缺失、损坏、身份不符明确报错。单技能零成功不删除该合法技能；全部参考成功为零时保持现有目标变异报错，不能只在初始化随机退回就宣称全链路可运行。
3. 初始化扩充：新建一个小型纯逻辑生成模块，在新训练任务冻结初代前调用；普通“仅准备材料”继续返回原材料数，扩充预览另报原材料数、目标数、新增数和实际总数，不把两者混称。
4. 冻结与恢复：清单保存生成版本、目标数、分层参数、独立生成种子、准备/参考身份、扩充列表与生成出处；生成不消耗后续繁殖随机流。原sources（材料来源）保持原语义。初始化进度独立保存，取消后继续未完成进度，已冻结列表恢复不重抽。旧未完成任务不自动扩充，不能兼容时明确要求新任务；旧完成结果仍可读。
5. 训练：扩充后走原初评、三道独立繁殖概率、评分与自然停止；独立训练评分失败保持重试后报错，不能自动跳过。每完整代随种群容量扩大，配置的并发不自动增加。每组300×32为名义9600次初评请求迭代，四组38400；缓存、重复、失败和重试都会影响实际成本，不报未经测量的耗时。
6. 输出：继续正常加四种扰动的五场景复测、最终四代表；训练成果继续以现有来源和身份进入正式搜索，经原评分与推荐导出最终GSE（按键序列插件）序列。不修改正式搜索的原起点生成，也不恢复旧的300收缩8再加4设想。
7. 配置与文档：在原共享配置的训练区增加一个目标数量项，推荐默认300；不另造配置文件，也不把大量内部比例都做成开关。更新初代容量正式约定、初始化清单版本与现有相关测试，保留其他功能。开发前按流程另行整理需求和票据。

### 覆盖报告与首轮验证取舍

首版报告原材料、新增、合并后三份：不同程序数、重复/非法率、长度档、技能及首技能覆盖、技能占比档、相邻组合覆盖和参考偏离程度。最近邻相似程度是可选诊断，不作生成门槛；距离计算办法未确认前不据此淘汰候选。

首轮低成本对照只需普通加权随机与推荐分层生成，固定相同提案预算及三个配对随机种子；统一长度安排的对照用于分离技能/排列策略影响，另报普通不分层基线用于观察整体改善。未取得相同有效数量时说明样本量差异。有限池择远仅在上述报告仍显示明显集中后再加入对照，不列为首版必做。验证不运行模拟，不能证明伤害；伤害收益另用现有评分及同总预算训练验证。本次均未执行。
