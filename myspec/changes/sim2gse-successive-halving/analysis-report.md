# 第三阶段逐级淘汰数据分析

日期：2026-10-01。只修改分析工具和需求文档，产品代码、搜索算法、模拟器及游戏目录均未修改。

后续用户要求补齐三种筛选条件比较，见[三种筛选条件的历史对比](screening-comparison.md)。后续数据支持优先研究“明显落后才淘汰”，本文件保留此前只评估排名保护时的初步结论，不把初步推荐当作最终方案。

## 结论

不建议直接实现每层机械保留一半。现有程序已经会在128次层停止大量候选；按32→128→512每层保留一半，固定候选的请求计算量反而增加22.36%。

数据支持进一步收敛为：只在第一层进行同轮筛选，保留前半及分数接近边界的候选，后面保留现有比较和晋级复核。历史回算显示有降本空间；预先固定规则的新评分也保住了三轮最高分候选。但这不是完整搜索收益证明，也不是一般配置下无损保证，开发方案仍需确认。

## 已执行内容

1. 复用第二阶段完成版三份搜索，合计792个候选、50轮；按真实路线访问记录和候选顺序还原轮次，不把全任务任意切成16人一组。
2. 复用旧扩大研究资料中普通固定节奏的训练成绩，核验2292份报告和候选程序，得到677对有完整成绩的历史挑战。未用旧保留样本选择参数。
3. 因历史资料缺少完整同轮高层成绩，补测原角色、改装备、改天赋及饰品三套条件，各随机抽一轮16个候选，共48个。抽取方法、主规则、条件和种子在启动前写入固定清单，运行后未更换规则或重试。
4. 补测按32、96、384次增量进行，共144批、24576次请求、24432个有效样本；最多两个单线程进程，总耗时79.516秒，所有报告完整并通过校验。

## 历史计算量与取舍

三份搜索原搜索评分共请求116352次，不包含初始化、路线诊断和搜索内晋级复核。

| 第一层保留方式 | 只加第一层筛选的历史请求量变化 | 两层都按该比例筛选的请求量变化 | 淘汰历史上曾确认胜出的候选 |
| --- | ---: | ---: | ---: |
| 前四分之一 | -48.51% | -41.91% | 5/56 |
| 前一半 | -32.43% | +22.36% | 4/56 |
| 前一半，另保护边界候选 | -21.86% | +56.35% | 1/56 |
| 前四分之三，另保护边界候选 | -10.31% | +145.79% | 0/56 |

第一层保护规则使用首批成绩的均值与标准误差：候选上界不低于保留边界下界时，额外保留。1.96倍标准误差仅为预设保护办法，不是整体误淘汰率的统计保证。两层比例列只对第一层保护，第二层仍按比例排名。

“只加第一层筛选”按被保留候选原来实际完成的后续批次回算；原搜索中谁晋级、谁继续计算仍来自历史，因此只是固定历史计算量代理，不能当新算法真实调用量或节省时间。两层比例列则假定通过第二层者全部达到512次，初始候选仍按原历史请求量计入；它也是固定候选计算预算，不是重新运行搜索。

56名历史确认胜出者并非56个独立样本，也不都必须保留才能得到同一个最终赢家。全部方案在本批数据均保住三份实际输出赢家，以及37个有新胜出者的轮次中最后确认胜出者；另外13轮没有新确认者，不纳入37轮分母。这些较好的结果不能掩盖中间候选被淘汰和后续搜索路径会改变的限制。

## 小样本排名风险

旧资料677对挑战中，用第一批100次成绩决定两者谁留下，与四批累计400次成绩的判断有41对不同，占6.06%；看两批时有23对不同，看三批时有16对不同。三套角色条件都出现过判断改变。

这些都是用于方案分析的旧训练资料，累计成绩含初期样本，也不是真实正确答案。候选原本来自已发生的挑战，存在筛选偏差。旧569轮均缺完整的全候选独立补测，不能拼成完整逐级淘汰验收；677对也不是互相独立的实验。

## 新样本固定候选核对

主规则在补测前固定：32次层先保留前一半，额外保护分数区间重叠者；存活候选充分计算后选优。主比例不是根据这次结果改选；四分之一及四分之三仅作为已预列的对照，不据其结果替换主规则。

| 条件 | 首层留下 | 是否保住本轮充分计算最高分 | 相对全候选充分计算的已选成绩变化 |
| --- | ---: | --- | ---: |
| 原角色 | 8/16 | 是 | 0% |
| 改装备 | 8/16 | 是 | 0% |
| 改天赋及饰品 | 9/16 | 是 | 0% |

把其他候选停止在32次、存活者都计算至512次，固定候选请求量为13536次，对照全员512次为24576次，相差44.92%。这是本轮固定候选预算的算术差异，未实际运行两种派发方案，不是比现有搜索快44.92%。现有搜索本来就会提前停止，因此不能把它与前述21.86%的历史代理结果当作同一收益。

三轮全部保住最高分，只说明本次48个候选的筛选；不能宣称错淘汰率为零、所有角色无损、整轮搜索提高或已达到第三阶段通过标准。

## 防止过度拟合与偷看未来

- 历史资料一律作为方案分析资料，不冒充未看过的验收集。
- 新样本启动前固定候选抽取方式、主规则、种子及计算配额；输出清单校验值一致。没有看到结果后换比例、反复调边界或重抽有利候选。
- 第一层选择只使用首批32次已完成成绩和该批误差；128/512次结果、历史确认胜出者及最终赢家只用于事后核对，不参与首层排名。
- 补测为查明被淘汰候选会不会反超，审计端继续计算所有候选；额外成绩不反馈给筛选决定。这不是生产搜索在预算内偷偷多算。
- 尚未实现完整搜索，因此不能使用原搜索未来生成的候选证明新搜索将生成同样候选。完整搜索会因父候选及晋级改变而改变后续路线。
- 开发规则确定后，仍须用其他预先固定的随机条件做真实完整任务对照。若用新对照结果重新选参数，该组数据改归方案分析，不能同时充当最终验收；本次不进行反复优化。

## 审查与核验

独立只读审查确认首层未使用未来成绩，提出样本身份校验和轮次分母两项问题；已补齐原报告散列、均值、样本数、编译后动作步序、原输入散列、配对候选编号与37轮分母。新补测另核验144份报告、固定清单及有效样本数。

修正后独立复核未发现新增可操作问题。审查者独立重算144份报告及三组保留名单，确认8、8、9人和三组最高分保留；核对22.36%、21.86%及44.92%均为请求量差异，未当作实测提速。该审查未重新运行模拟。

产品代码差异为空。游戏校准、上游升级、最终五节奏复测、不同节奏淘汰及第四阶段学习均未进行。
