# 02：改前改后完整搜索实测

Status（状态）: done
Blocked by（阻塞任务）: 无；01已验收。

## 交付行为

给出真实完整搜索的新旧对照，用户能看到实际快多少、是否只是省模拟次数，以及最终伤害有没有下降。

## 验收条件

- 依 spec.md 固定三套角色条件及每套三个新搜索种子，共九对；保存输入、引擎、版本、顺序、预算和原始报告，不看结果后改策略。
- 从现有真实产品任务路径执行，两版相同条件，独立目录，不共享任务成绩，交替顺序，公共构建预热，整搜索串行不争抢进程。
- 分别报告真实耗时、请求次数、有效样本、候选数量、停止原因和最终序列，给出逐对结果及配对中位数；耗满预算时明确转为比较相同预算下的搜索产出。
- 最终序列独立配对评分，种子与搜索不同，结果不反馈搜索；报告伤害差异与波动，不用各版搜索内不同样本量成绩直接判断无损。
- 所有失败、预算耗尽和无效结果保留，不能挑好看的结果或静默重跑；发现明确伤害下降时记录失败，不宣称成功。
- 产出简明中文实测报告及可复核原始记录，产品不增加统计必经步骤。

## Comments（讨论）

本实验不负责游戏校准，不升级模拟器，不运行游戏部署，不自动推送或合并。

实测已启动，清单在读取结果前冻结，共九对十八次。实现任务已验收，当前依赖已解除。网页模型独立审查认可计数名称修正，以及前三次无法准确追溯纯搜索耗时的明确限制；后续用只读观察器记录阶段时间区间。自动独立评分另检查九对身份和双侧结果全部齐全，先后顺序问题已修复并复审通过，无需停止或重跑搜索。阶段结果见[完整搜索实测记录](../full-search-results.md)，本任务在所有搜索及独立评分完成前保持未验收。

最终验收：十八次真实搜索及54次独立评分全部完成，未按结果调参重跑。配对中位数：总耗时减少29.91%，原始报告累计请求迭代数减少37.44%；独立伤害前八对相同，最后一对提高0.756%。最后一对两边均耗满预算，仅比较同预算下产出，未宣称省时。十八次条件、结果身份和保存散列一致，独立每次请求512次、有效511次。网页模型中等思考强度最终只读复核通过，无阻塞；全部数据和计数、计时限制保留。
