# 01：解锁位置跨重载保持

Triage（分拣）: ready-for-agent
Status（状态）: in-progress
Blocked by（前置事项）: None（可立即开始）

## What to build（要做出什么）

修正 MYui 准星 HUD 与 EUI 解锁模式之间的位置坐标契约，使玩家移动 HUD、退出解锁并重载界面后，HUD 保持在退出解锁时看到的位置。

## 验收条件

- [ ] 非默认 HUD 缩放和非零位置下，解锁结束前与重载恢复后的根框坐标一致。
- [ ] 位置保存和恢复继续使用插件自己的 SavedVariables（存档变量），不写入 EUI 配置档案。
- [ ] 连续重载不会产生累积漂移。
- [ ] 现有解锁尺寸、X/Y 输入、像素吸附和可见性契约测试继续通过。
- [ ] 用户在真实客户端复验同一场景后，位置不再变化。

## 测试接缝

扩展现有解锁元素完整装配测试，通过真实注册回调模拟保存、退出解锁和新会话恢复；不针对私有函数单独断言。

## Comments（讨论）

### 2026-09-20：红灯到绿灯

- 实际安装版 EUI 会把拖动中的 `TOPLEFT/TOPLEFT` 实时位置归一成 `UIParent` 单位的 `CENTER/CENTER` 坐标，再交给注册元素保存。
- 红灯：在 HUD 缩放 `0.8` 下保存实机样例 `88.610975477431/-44.533299763997`，恢复得到 `110.76371934679`，证明 MYui 又除了一次仅用于尺寸的缩放值。
- 最小修复：恢复位置直接使用 EUI 已归一的坐标；HUD 缩放继续只控制框体尺寸和内部纹理摆放。
- 绿灯：解锁契约测试 `2 passed`；MYUI 与 MYUI_CrosshairHUD 测试组 `43 passed`。
- 审查返工：回归测试改为把实机保存值作为上一会话的 SavedVariables 输入，在全新模块装配中执行 `Config.Load` 与正式启动恢复，并重复应用一次确认不会累积漂移；定向与全组测试仍分别为 `2 passed`、`43 passed`。
- 待办：统一构建验证、独立审查及真实客户端复验。
