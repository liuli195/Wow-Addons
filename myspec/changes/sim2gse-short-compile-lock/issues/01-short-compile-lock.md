# 01：训练与正式搜索编译期间减少共用锁等待

Status（状态）：ready-for-agent；门禁一已确认，实施及定向验证完成，统一验证和独立审查待完成。
Blocked by（阻塞任务）：无未完成前置票据；连续补位已通过拉取请求85交付。本票门禁一已确认。

## 交付

训练和正式搜索的内存任务在已有并发额度内执行编译；不同候选能够并发，编译期间进度仍可读取；同一候选共享通过核验的编译结果。评分前保留真实编译和行为一致检查，失败与取消不会留下永久等待。

## 验收

- [ ] 沿既有高层入口先取得失败检查：第一候选编译未结束时，第二候选能够开始编译，进度读取不被完整编译挡住。
- [ ] 同候选只建立一份在途编译；不同候选沿原线程执行，编译至模拟合计不越配置额度，不新增编译池。
- [ ] 所有编译、等待及归档调用位置均已核对，不在持任务总锁时进行耗时编译或等待。
- [ ] 编译通过且步骤一致才进入评分；相同候选的等待者共享结果或异常，计数及诊断准确。
- [ ] 编译失败、超时、取消和预算结束均释放占位、通知等待者；编译仍位于评分重试外，保留原失败额度、计数口径、所属进程清理及恢复规则，无新重试政策。
- [ ] 导出、步骤、请求、成绩、反馈、随机状态、代数和最终结果对照一致；旧磁盘方式、编译器、缓存条件、繁殖及保存结构保持。
- [ ] 通过统一差异验证和既有必要入口冒烟；不添加低收益大矩阵或测试专用产品框架。
- [ ] 在一百二十八批、每批三十二次请求和一百八十秒的性能对照额度内完成短真实观察，报告实际收益或无收益，不运行完整训练。
- [ ] 全部完成后由独立审查代理审查，修复有效发现，再整理门禁二；未确认交付门禁不合并。
