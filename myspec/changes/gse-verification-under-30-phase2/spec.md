# GSE 最小真实冒烟与快速完整验证

## Problem Statement

上一轮全仓检查全部通过，但 GSE 仍需 33.05 秒。原来的大量故障、恢复和原生边缘组合不符合用户当前对日常验证成本的取舍。用户已明确撤销“118 项契约全部保留”的要求，要求只保留最简单的真实冒烟，其余能低成本移入内存的迁移，边缘、重复或低收益检查可以删除。

## Solution

保留一条从用户输入到真实计算、导出和读取结果的完整正常通道，以及少量无法由它替代的核心边界。规则检查无外部副作用；不值得继续维护的边缘矩阵直接退出日常测试，而不是藏进另一套运行入口。产品行为和正式功能要求不变。

## User Stories

1. 作为使用者，我能通过真实页面输入角色，得到真实双场计算结果、三个可读取导出和集合，并能复制结果；改变输入后旧结果不再显示。
2. 作为维护者，我能确认原生基础战斗行为没有被未启用的控制逻辑改变。
3. 作为使用者，我能在隔离的新接入项目读写结果，不依赖旧用户安装位置。
4. 作为使用者，我结束一个计算进程的所有者时，该所有者的后代会退出，另一个所有者的工作不被误杀。
5. 作为维护者，我能快速验证会话选择、伤害对照与诊断开关等规则，不为这些检查创建目录、启动原生进程或访问网络。
6. 作为用户，我能看到本次明确删除了哪些边缘验证及其风险，而不是收到“覆盖完全不变”的错误承诺。
7. 作为用户，我的测试临时文件放在正式规格约定的仓内临时目录；每轮成功后清理本轮可重建临时文件，必要证据、历史记录和产品数据保留。

## Observable Requirements

- 正常全仓完整验证中，全部剩余检查实际执行并通过，无成功缓存跳过；GSE 严格低于 30 秒。
- 同条件全仓工具耗时不超过 51.1566279 秒，实际墙钟不超过 51.406 秒；其它检查仍正常并行，不靠停掉其它项目制造收益。
- 真实冒烟不得用预设成功结果替代实际依赖。普通检查不得发生外部写入、网络或原生子进程副作用。
- 删除范围、迁移后的实际节点与未继续覆盖的风险公开登记；不额外建设夜间重型套件或隐蔽入口。
- 所有剩余自动测试正常收集，普通与真实选择互补，无新增跳过、屏蔽或放宽守卫。
- 累计磁盘占用不超过已批准的 1.7 GB，超出前暂停报告；清理仅针对本轮明确归属的可重建临时产物。
- 在完整目标验收前保持进行中；一次通过不保证长期性能稳定，最终合并仍须完整交付确认。

## Testing Decisions

以官方全仓完整验证作为最终判定。单组、云端普通及原生审计适配器的定向通过只证明各自范围，不代替 Windows 真实依赖和全仓耗时验收。保留、迁移和删除清单见 coverage.md；实现和证据分别见票据与 verification.md。

## Out of Scope

改变产品算法、默认值、身份校验或正式功能规格；取消其它项目检查；继续 Lua 整体内存化；恢复原来的全部边缘矩阵；新增框架、隐藏重型档位；清理历史证据或正式数据；未验收即合并。

## Further Notes
