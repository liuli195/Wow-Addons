# Sim2GSE 第三方 GSE 序列导入与模拟

## Problem Statement

Sim2GSE（角色级按键序列优化器）目前只会生成简单动作块，不能把外部作者发布的 GSE（高级按键序列插件）导入字符串作为输入进行 DPS（每秒伤害）模拟。第三方序列可能包含多个版本、嵌套循环、定期重复、暂停、条件块、嵌入序列、变量及宏命令；如果只凭一条样本设计解析器，容易遗漏合法结构，且把未知含义静默略过会产生虚假的成绩。

## Solution

用户在本机界面提供角色资料和一条或一组 GSE 导入字符串，选择目标序列与版本后，系统完整解码并保留原始结构，展示名称、版本、语法清单及可模拟性。只有在序列已编译成可核对的逐次按键计划，且全部可按动作都能映射到当前角色并可由原生受控引擎表达时，才运行 DPS 模拟；其余情况返回具体位置和原因，不给出虚假的 DPS。

## User Stories

1. 作为本机用户，我希望粘贴第三方 GSE 导入字符串和角色资料，直接发起一次模拟，以便比较序列伤害。
2. 作为本机用户，我希望导入集合中多个序列和单序列的全部版本都能列出，并明确选择目标，以免模拟错误版本。
3. 作为本机用户，我希望 Action、Repeat、Loop、Pause、If、Embed 六类块和嵌套结构都被解析并显示，以便知道导入内容是否完整。
4. 作为本机用户，我希望常见的顺序、优先级、反向优先级与随机步进按 GSE 规则处理，以便按键顺序可信。
5. 作为本机用户，我希望定期重复和暂停占用正确的点击次数，以免 DPS 被错误放大。
6. 作为本机用户，我希望 If 条件和 Embed 引用能被保留、验证并在条件明确且依赖齐全时模拟，以免悄悄选错分支或漏掉子序列。
7. 作为本机用户，我希望宏、变量、修饰键和环境依赖不能准确求值时看到清楚的拒绝原因，以免误把估计结果当实机结果。
8. 作为本机用户，我希望同一角色的可按动作按角色能力核对，未知技能、物品或条件不会被静默删除。
9. 作为本机用户，我希望看到源字符串摘要、GSE 版本、目标序列与版本、编译结果和模拟输入条件，以便复核和复现。
10. 作为开发者，我希望多条公开真实导入样本覆盖主要语法及不同作者写法，以便验证解析和上游行为一致。
11. 作为开发者，我希望当前搜索生成的简单序列也走可复用的序列程序与编译边界，以便以后加入 Repeat、Loop、Pause，而本期不改变搜索空间和选择结果。
12. 作为结果使用者，我希望导入失败或不支持的语义在模拟前终止，原始角色输入与导入字符串仍可追溯。

## Implementation Decisions

- 以仓库锁定的客户端版本和固定 GSE 上游版本为兼容目标，先检查当前上游发行版和真实样本的格式差异；如需升级兼容锁，另行记录源版本与哈希。
- 样本优先收集适用于 12.1 正式服的邪恶死亡骑士公开导入字符串，再用其他职业覆盖语法缺口。记录来源、发布日期、声称适用版本、GSE 版本、散列和语法特征；只存测试所需的允许再分发内容，无法确认授权的原文放在被 Git 忽略的本机样本库，并保留可重取的链接与摘要。
- 导入采用严格的大小、层数、节点数、展开步数和引用环上限；区分无效编码、合法但不支持的版本、可解析但不可模拟、可模拟四种结果。
- 解码层保留原始字段、版本和块路径；统一的序列程序表示动作、空点击、控制节点及来源映射。编译层从程序生成逐次按键计划；搜索的现有简单动作块只作适配，搜索变异和选择策略不加高级语法。
- 使用固定上游 GSE 编译行为作对照，验证控制块展开、版本选择与字节协议；绝不执行第三方 Lua（脚本语言）代码。If 条件、变量、宏和嵌入依赖仅在可确定、可核对的语义下进入模拟；其他情况明确标记为不可模拟。
- 原生受控引擎继续承担伤害计算。逐次按键计划含空点击，来源位置和时序在评估前后核对；不把无法表达的控制语义近似成普通轮转。
- 页面增加独立导入评估入口，保留现有优化入口和默认搜索行为。任务结果分别展示导入状态、编译状态、模拟状态和错误位置。

## Testing Decisions

- 优先从公开任务入口和本机页面接口检查真实用户行为，辅以上游协议与编译的对照检查；测试预期独立于本机解析器的实现。
- 样本矩阵至少覆盖单序列、集合、多版本、六种块、嵌套、不同步进、重复间隔、点击与毫秒暂停、变量与宏命令、嵌入引用、畸形输入和资源限制；一条样本可覆盖多项，但不得以单条样本代替整个矩阵。
- 对可模拟样本核对导入字段、GSE 上游编译步骤、逐次输入、原生解析动作块和 DPS 报告；对不可模拟样本核对未启动原生受控评估且给出准确原因。
- 搜索回归比较固定基线下候选键、导出序列、编译步骤和选择结果；确保本期搜索不产生高级语法。
- 完成聚焦测试、仓库统一验证、独立审查和需要用户实机参与的游戏验收说明。

## Out of Scope

- 本期不把 Repeat、Loop、Pause、If 或 Embed 加入搜索生成、变异或选择。
- 不尝试在本机模拟任意第三方 Lua、游戏内实时插件状态、不可观测的修饰键/目标状态或不受控的随机性；这些条件无法确定时拒绝 DPS 模拟。
- 不修改角色伤害模型，不承诺本机模拟等于真实游戏结果。
- 不在未获得第二道交付门禁授权前更新正式规格、提交 PR（拉取请求）、合并或清理分支。
