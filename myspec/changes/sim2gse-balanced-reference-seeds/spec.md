# 双来源起点更新与一次正式训练

日期：2026-11-09。Status（状态）：ready-for-agent。用户已确认完整开发门禁一，现进入逐票实施；临时观察不增加固定功能。

## 问题

当前模拟参考起点偏少，插件起手资料需手动搬运且已过时。用户确认先用前两轮已运行的参考加权方法，按组补齐30条模拟来源，再更新插件资料；取消所有A/B/C及新旧收益对照，完成后仅运行一批正式训练，并记录真实训练时间与效率。

## 解决方案

沿用既有来源中心、角色适配、独立爆发、语法检查、行为去重及完整训练。手动准备模拟补齐和插件刷新两个阶段，四组成功后一次更新来源总表；普通训练只消费冻结来源。最终仅启动一次双英雄×单目标/实际五目标正式预训练，原五场景复测后每组发布4代表，读取核验共16条。

领域口径沿用现有词汇：来源是带出处的材料，同一程序可有多个来源；每组初始输入是角色适配与完整行为去重后的集合；参考加权合成不是成功轨迹；一次正式训练指一个批次内的四个独立组，不是四次独立收益试验。正式搜索属于用户角色后续使用，本轮只保护消费契约，不实际运行。

## 实施决定

- 生成：小幅提取试验脚本已有共享核心，旧32/352、旧排除集和随机输入下输出/顺序/随机状态一致。新补齐按模拟类别组内去重，与其他来源重复保留出处，联合初代再去重。
- 数量：每组适配编译后模拟不同行为数S，补max(0,30-S)，超过不删。旧人工规则按历史兼容及实际适配计数，原作者说明与旧系统准入差异在预览列明，不凭名称改范围。整组无有效原材料仍拒绝，不引入冷启动。
- 配方：50%同组参考成功占比加50%合法动作等权，合法长度随机；成功比例不是尝试比例。零参考但合法技能保留机会，参考无效则失败。新增n条最多11n提案，保存独立随机状态和累计次数，不足停止发布。
- 范围：新增记录必须有明确允许训练组与实际目标数，原生成条件另存模板、装备、英雄、引擎、参考、种子和策略版本。仅明确旧版缺范围兼容旧共享行为；范围在缓存与去重前核验，纳入来源修订、准备及恢复身份。
- 配置：原训练区新增生成模式及目标数量，本任务启用目标30，旧配置默认保留旧行为。50/50随策略版本冻结，不增调参面板；四项复杂语法关闭、独立爆发保留。
- 刷新入口：扩展现有材料命令，提供只读计划、隔离验证、应用指定计划；不另建材料库、后台服务或页面。正式提交与一次训练作为本任务获准后的实施动作，代码/正式规格/远端交付另守交付门禁。
- 插件读取：冻结已知数据文件，只导出支持字段。资料运行环境不暴露文件、网络、模块、进程和系统环境访问；指令/时间、输入、输出和条目数有界，拒绝未知格式或动态入口，不运行整个插件。已有有界进程管理仅保证超时和进程所有权，不宣称完整系统安全沙箱；具体限制必须有失败测试。
- 发布：先模拟补齐隔离结果，再加插件刷新；四组准备成功、模拟目标已满足且各有合法新版插件来源，才核对基线并一次替换来源总表。四组准备缓存分别核验源集身份，不宣称跨键同时原子。发布响应丢失先读实际源集身份，不能只看完成标记。
- 准备预算：两个阶段、四组、失败重试和恢复共同累计300秒/1000请求迭代；达到停止线不发布，报告未完成。此为材料正确性检查，不做候选伤害优劣对照。
- 正式训练：最终来源一次冻结，新的任务目录承载一批四组；原粗评32、连续两完整代无改善、最多8名入围、五场景各3批128请求、每组4代表。默认4组并发、每组5个单线程引擎，总上限20，不加总时长/代数限制，不承诺有限总耗时。取消或故障恢复同一批进度，不另起一批。
- 下游：代表继续符合现有正式搜索消费契约；正式搜索将来按当前角色重新取参考和评分。本轮不额外执行真实正式搜索或导出收益验收，既有接口用正常回归保护。
- 本次临时观察：用户明确不开发固定计时、效率统计或报表功能。不修改产品计时入口、报告结构、配置或恢复状态，也不为观察新增产品测试。仅在本次运行外部记录起止时间，读取既有日志/诊断/时间曲线中实际可得的代数、模拟量、缓存与阶段信息，人工整理交付。原工具已有的临时日志开关可按本次需要使用，不改变默认配置，不新增开关或维护脚本。
- 观察口径：更新准备与正式训练分开；整批实际经过时间不由并行组耗时相加得出，暂停另列。仅根据已有可靠计数计算可取得的速度，缓存/暖场不冒充新增有效样本，缺数标明未采集，不为补齐指标改产品代码或额外跑训练。

## 测试决定

最高公开接缝为同一材料刷新命令的计划/隔离验证/应用，再通过既有正式训练入口。已有来源准备、训练恢复、试验入口和正式成果消费测试优先复用。开发先写行为测试再实施；新普通测试接入统一发现，涉及物理来源写入、脚本解释器及进程的必要检查按现有真实检查角色运行。

重点覆盖：旧生成等价；0/不足/已满/超过30；无效参考和空材料；目标/英雄隔离及旧兼容；重复/损坏/空批/并发/响应丢失；恢复不重抽与预算不重置；精确旧28与受保护人工2。统一验证使用固定基线快速模式，保留现有预算，不用完整训练代替回归，也不把定向通过冒充全仓验收。本次临时效率观察不作为新增产品测试范围。

真实验收仅一批正式训练及成果读取，记录四组完成、代数、停止原因、代表成绩与时间效率；部分失败如实报告，禁止重复训练挑好结果。
