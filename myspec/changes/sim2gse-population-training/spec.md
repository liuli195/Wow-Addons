## 实验机制与后续提案的差异

以下区分已运行事实、已确认原则和仍未批准的后续提案；不能把后续参数混写为“按实验原样迁移”。

1. **池和子代**：MVP 繁殖池至多 8，每代至多 16 个唯一合法新子代，名义子代／池为 2:1；先前 `N 池 + N 子代`（如 70/70）的 1:1 改法未获批准。下一轮拟讨论 `P=max(8,N)`、每代至多 `2P` 个唯一合法子代，N=70 时为池 70／子代 140；这仍是新提案，不是 U5 已批准参数。[C2:152–208；Q1、U5]
2. **父本筛选**：MVP 从全部档案按首 32 档粗分取前 2 精英，加两份按代轮转的原始完整结构，再按粗分补池；U5 已同意保留该机制、撤回“已核验冠军 + 粗分第 1”的额外繁殖精英改法。实际池规模和扩大输入后的轮转参数仍待确认。[C2:137–163；Q1、U5]
3. **繁殖操作**：MVP 使用 DEAP（进化算法库）`varAnd`，完整动作块同位置单切点交叉，交叉／变异概率各 0.8，复用原 `mutate`（变异），至多尝试 20 遍收集唯一子代；不含异长双切点或新结构距离框架。推广到实际 N 后轮转、奇数父本及不足整代的行为须明确，不默认为已验证。[C2:165–220；E2:13]
4. **评分和晋级**：MVP 繁殖适应度取首 32 档，搜索仍走累计 32/128/256、4 批独立晋级核验等既有流程；“4 组 × 5（20）评分”是后续提案，组与次数的具体含义、成本和必要性均待确认，不能与四个训练场景混称。[C2:143–147；C5:377–400]
5. **代与停止**：现有接缝仅完整轮次无改善才累加计数，确认改善全局或非初始化路径均清零；训练配置为 2 轮。后续“两完整代仅看全局冠军改善”改变改善定义。MVP 全部限时退出，尚无自然收敛证据。[C1:2533–2569、2884–2919；C6:705–739；E1:26]
6. **终评与输出**：MVP 每个 arm（实验臂）先固定唯一原优化器赢家，再做 4 × 128 独立 endpoint（终点评估），端点不回流选优。最终输出前四的目标已确认，但“保留已核验运行中最佳，再按粗分补足 7 个不同入围行为，共最多 8 个，各做 3 × 128 独立复测后选前四”只是下一轮拟提案，尚未批准；这是有限复测选拔，不是修改繁殖精英，也不是 MVP endpoint 的简单复用。[C5:409–440；E2:29–31；Q1、U5]
7. **预算**：MVP 每臂搜索 175 秒、含可靠保存与收尾总 180 秒，A 四路径共享搜索窗口；不等于新正式预训练的预算或四组都适用的耗时承诺。[C5:301–345；E2:25–31]

#### Problem Statement（问题）

用户需要用同一公平、可负担的小实验比较现定制策略与两个 DEAP 官方流程；已有八配对只比较旧训练基线与定制 GA，不能回答三流程何者更适合，继续凭讨论切换推荐也不能替代证据。

#### Solution（方案）

1. **共用输入与条件**：冻结现有四原始材料，每条用固定种子作一次不经 DPS 选优的轻扰动，取得合法、行为不同的八个真实初始程序并提前冻结供三组共用；不取旧 C 赢家、不从本机取料。条件沿用专精252、天启骑士32、群体5目标、200ms、既有独立爆发与真实引擎／标准角色。
2. **三固定配置**：C 保池8、最多16个唯一新子代、只对原四材料保留两条轮转及 varAnd 0.8／0.8，但抽出 JointPopulation 用独立循环，不沿旧分档／CI（置信区间）晋级；A 用官方 eaSimple＋锦标赛3＋varAnd 0.8／0.8、种群8；B 用官方 eaMuPlusLambda＋selBest、μ=8／λ=16、varOr 0.5／0.5（复制概率0）。这是同评分层的三配置策略比较，不是纯单因素比较，也不是旧完整 C 原样重跑。[C2、R1、R3]
3. **共用评价而不抹平换代**：统一首32档真实评分、共同变异反馈规则及 cache（缓存）／存储能力，每臂缓存隔离且规则一致；每臂独立 worker（工作进程）隔离官方随机源，统一搜索种子。A／B 保留重复种群名额，不能套用 C 的 seen（已见行为）去重；不得只换供应器名称仍让旧 optimize（优化器）控制 A／B 换代。仅实验入口及最小共用评价接缝允许在未来获准范围内修改。
4. **选优与独立终点**：每臂取首32档粗分最高的两个不同行为，各做2×128选优种子复测后固定唯一赢家；再用全新种子做4×128独立终点，终点不回流。首32档曲线仅为搜索代理粗分曲线，不冒称独立 DPS；任一所需复测缺失即不合规，不参与排名。
5. **重复与预算**：12个独立搜索种子块，各含三臂，ABC／BCA／CAB各4次串行，共36臂。每臂至多2个原生进程，累计200秒含100秒初始化与搜索、45秒共同选优、45秒终点、10秒可靠保存；36臂120分钟，整批130分钟包含共同准备及汇总。复测窗口不足必须如实标缺口，不补跑、不降门槛或重置预算。
6. **统计结论与证据**：预登记A-C、B-C、A-B三个配对比较，使用双侧精确符号检验及Holm校正p≤0.05；检验方向性胜率而非平均DPS。平局保守留在总n=12且不算任方赢，p=min(1,2×Binomial(n,0.5)上尾(max(胜,负)))。报告逐块差、胜负平、原始及校正p；仅某策略对另外两策略均显著且有利时称统计赢家。任一确认臂缺测、不合规或总预算违反时统计排名未完成，保留描述性结果，不删块凑完整样本；没有显著赢家也不追显著或自动扩样。旧8配对不混入，旧约1.5GB原证据不动，新摘要仅引用必要评分及恢复证据。该计划不是正式训练、发布或游戏验收。

#### Implementation Decisions（实施决定）

- 只扩展隔离实验入口与最小共用评价接缝，复用真实合法性、评分、缓存和存储；不扩展生产架构或新增第二套业务库。
- 三策略独立控制各自换代，官方 A／B 不套用 C 的唯一行为槽和旧分档晋级；共享的是物理条件、评价与反馈规则，不是生存选择逻辑。
- 最小评价接缝在既有编译／批次／存储能力建立后、旧搜索循环之前完整分流；选优及终点显式读取冻结种子计划，不能沿用带任务随机偏移的 final 种子。普通搜索默认不变，不新增策略基类、注册框架或配置层。

- 真实实验只在最高层预算及独立审查通过后运行一次；全部36个预登记臂始终保留，完整成功成果不因其他臂失败丢弃，失败不自动补跑。
