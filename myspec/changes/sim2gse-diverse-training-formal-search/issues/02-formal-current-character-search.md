## Acceptance criteria

- [ ] 用户从正式页面开始任务，读取适用快照的实际全部程序，再按当前角色适配、精确去重和成功初评得到真实初始人数。
- [ ] 原生来源数取实际有效程序，训练来源不固定截断八条或按当前训练配置裁旧快照，历史来源最多一个正式冠军；所有新任务不额外读取旧独立训练冠军。
- [ ] 正式使用锦标赛选父默认3；后代挑战窗口中最近者，窗口内无放回抽样，严格质量改善才替换，完整代后提交；相等保留原候选。
- [ ] 窗口比例默认66%，窗口取真实初始人数乘比例向上取整并限制在1至人数之间；人数9、10、13、15分别得到6、7、9、10；任务启动后冻结容量与窗口。
- [ ] 正式概率、参考、粗评、复测、并发、早停和行为权重独立冻结；训练终评上限改10不改变正式终评上限8。
- [ ] 正式按质量取自己的终评名单，正常独立复测后输出最高每秒伤害答案；不以多样代表替代质量榜或早停依据。
- [ ] 页面继续沿用原快照与冻结计划；只补缺失有效凭据，不重跑已完成场景，不把半代记为已完成。
- [ ] 页面开始、继续和结果读取的公开接线以及真实任务编排可观察来源、数量、窗口、配置隔离和恢复结果；替换旧来源规则断言而非复制旁路。
