# 01: 减少引用扫描与压缩开销并保留归档安全

**What to build:** 操作者经既有数据CLI安全初始化或更新目标查询索引后，原归档及恢复流程保留相同保护和兼容性；用一个代表样本选择固定gzip等级，降低批量处理开销。

**Blocked by:** None（可从已批准的a8f5610开始本票；合入主干顺序在历史占位核实交付之后，不阻塞该交付）。

**Status:** ready-for-agent

- [x] 新根具有目标引用索引；旧根经既有预览/批准、根锁、事务及实际空间准入完成按需更新，重复执行不重建。
- [x] 占用、空间不足及失败均不改用户载荷或留下半成品索引；只读动作不建索引，真实保护继续生效。
- [x] 一个真实已封口代表样本完成6/9级纯压缩耗时和大小比较，并确认往返字节一致。
- [x] 按结果在原写入处固定6级，不增加配置框架，并保留原恢复与完整性校验。
- [x] 新旧归档均可经现有恢复入口通过原完整性检查，不删除重复验证或修改正在运行的批次。
- [ ] 复用公开CLI的最小红绿/往返检查、固定基线fast及限定独立审查；CI按实际记录。
