# 01 正式搜索复用遗传训练链并交付自然结果对照

**What to build:** 用户从原正式页面或CLI提交真实角色后，使用一次冻结的正式起点池，通过共享遗传训练链自然早停和正常场景复测得到一个可读取/导出的冠军；取消、恢复、诊断及旧历史验真保持可信。开发后以同输入运行旧版和新版各自完整默认流程，交付真实耗时和自然DPS曲线，不统一中间参数或添加共同独立评分。

**Blocked by:** None（无前置票据）；实施必须等待本次完整门禁一确认及目标验证工具可用性核验。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 门禁一确认后，从固定main新建已确认功能分支；不继承旧AB实验业务代码，不改写既有实验结果。
- [ ] 现有HTTP双场任务生命周期主路可从真实角色输出两场各一名有效冠军及既有导出，CLI与页面使用同一自然停止政策。
- [ ] 按原契约一次冻结来源：v2最多4＋4＋1；受支持v1或无版本保留独立旧训练冠军，最多4＋4＋2；行为去重后N可减少，未知或混合版本拒绝。适配、合法性、缺席冠军和拒绝原因可读，恢复不刷新外部来源或凑数；仅保持旧训练冠军兼容，不新增成果功能。
- [ ] 共享现有遗传繁殖、真实32粗评、反馈、成功批次缓存、完整代无改善早停及正常3×128复测；正式不叠旧阶梯或4×100 CI，不因单冠军输出要求四个合格候选。
- [ ] 新正式主体无600秒或新总时间截止/配额；明确自然停止版本，运行时无限不泄入标准JSON；原材料准备、单次故障超时、取消和错误处理仍有效。
- [ ] 页面显示真实阶段/代数/实际耗时与未完成状态，不再用elapsed/600冒充自然结束的百分比；保留诊断开关和原数据读取/导出契约。
- [ ] 半代取消、复测失败、暂时存储故障和最终保存失败不能变成完成或发布冠军；恢复沿用原输入、候选、随机计划、成功收据和已耗重试，发布失败只补保存/发布。
- [ ] 新正式冠军/恢复凭据版本明确并核验完整条件和正常复测；不伪造旧CI链、不放宽旧验证；旧完整历史只读验真，旧程序仅重新评分后使用，旧未完成不兼容任务拒绝混接。
- [ ] 训练原五场景复测、四条成果、自然停止和资源约束保持；正式保留原单场资源/实际按键条件，不带入训练多组资源拓扑或标准角色。
- [ ] 行为变更经既有最高公开入口TDD和必要小范围回归、统一验证及独立审查；真实与构造边界、缺依赖/失败/跳过和游戏未验收分别报告。
- [ ] 同角色、同引擎/物理输入及一次冻结外部起点源，隔离新旧结果/缓存/发布后，各按自己完整默认运行；保留各自参数、停止理由、自然结果和时间曲线，不统一预算、早停或评分，不追加共同端点评分。
- [ ] 交付对照报告明确各自然分数的阶段、迭代/实际样本与精度差别；不把高DPS自动等同统计显著，也不拿此前统一120秒实验代替本次验收。
- [ ] 正式规格冲突仅在后续最新MySpec受控预览/确认阶段处理；本票不自带合并、正式发布或游戏部署授权。
