# 预训练动态收敛停止

## Problem Statement
预训练被600秒搜索总预算或1000候选总量截断，不能按已有连续两轮无改善规则完成。

## Solution
仅训练搜索取消总时长和总候选上限；每轮候选数量及连续完整两轮无改善停止保持，真实空间耗尽也正常结束。普通搜索预算、单次原生调用超时和取消不变。

## User Stories
1. 训练有进展时可以超过600秒继续，不因累计候选数被迫终止。
2. 已完成路径复用，不重训；已验证的未完成路径可以继续搜索或复测。
3. 原身份、来源、选择学习回执保留，不伪造历史，也不重复学习。

## Implementation Decisions
复用当前training模式、TaskRuntime及执行记录，不加用户配置入口。准备及初始/最终复测单阶段预算不属于搜索总预算，本票不变。独审确认仅执行停止策略变化，不改评分、选择算法、行为或收敛定义；保留原版本及condition/config，当前执行段与任务state明确标记training_stop_policy，原执行历史不回写。既有done凭据验真后，仅deadline/candidate_limit恢复search；保留全部回执，已结算无奖励的旧选择继续评分时不重复学习。

## Testing Decisions
沿现有公开训练run/list及普通task入口：超过600秒继续、总候选上限不截断训练、完整两轮自然结束；完整成功不重算、失败/取消恢复；普通搜索预算、取消与单次调用保护回归。

## Out of Scope
不做新调度器、迁移框架或训练数据清理，不改变评分、规则池、选择模型或共享范围。
