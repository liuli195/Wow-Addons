# 01：复测未完成时导出锁定候选

Label（标签）: change:task
Triage（分拣）: ready-for-agent
Status（状态）: in-progress

## What to build

当搜索已经锁定候选、但最终复测因预算未完成时，任务入口导出锁定候选并保留证据不足提示；最终复测完整但未证明改善时仍导出初始序列。

## Blocked by

无，可立即实施。

## Acceptance criteria

- [ ] 公开任务入口的失败检查能够复现复测未完成时错误导出初始序列。
- [ ] 修复后同一检查导出锁定候选，且状态仍为复测不完整、不能视为验证通过。
- [ ] 完整复测未证明改善时仍保留初始序列。
- [ ] 使用原始角色输入和默认 SimulationCraft 参数完成一次正式重跑，万奥宝典字段保持不变。
