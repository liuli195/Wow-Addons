# 起点训练八路径最小试跑

**Status（状态）：** ready-for-agent

## Problem Statement

用户要求同时完整训练8条唯一起点，每条内部2路评分；现有外层上限3阻止8×2启动。

## Solution

仅将外层允许范围由1至3扩为1至8，命令行选择及帮助同步。默认2×2、内层1至16及乘积不超过16不变，复用现有有界执行器与可靠保存后补位。

## User Stories

1. 作为维护者，我希望选择8×2，同时训练8条独立完整路径。
2. 作为维护者，我希望9×1和8×3在计算前拒绝，避免越界资源使用。
3. 作为现有使用者，我希望未指定时仍为2×2，普通搜索与训练语义不变。
4. 作为维护者，我希望完成记录可靠保存后再补位，冻结队列和独立复测保持。

## Implementation Decisions

- 只扩已有配置校验及公开命令范围，不重写执行器，不加调度器、锁框架或新开关。
- 原每路径600秒搜索、完整轮次停止、身份、复测及发布逻辑不变。
- 使用同一云端工作树及功能分支，固定正式验证基线为5d7165b798d8a7555a74006a1206bd60d8db4331。

## Testing Decisions

- 最高公开接缝为现有人工训练命令入口；复用真实整理、训练、保存与查询链，仅外部引擎事实使用现有构造边界。
- 先红后绿；至少9个唯一构造材料检查峰值8路径、评分不超过16及保存后补位。
- 定向配置检查覆盖8×2通过、9×1和8×3拒绝、默认2×2；公开命令非法值在计算前拒绝。
- 本机真实试跑固定同条件8条材料及8×2，使用隔离数据中心；保持完整600+600+600阶段额度，失败如实报告且不自动重跑，不称全库或正式游戏验收。
