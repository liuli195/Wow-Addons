## What to build（要做出什么）

19 项配置全部能改、能存、能即时生效，页面挂在 EUI 的配置界面里。

- **配置数据模型与默认值**（19 项）：常规 4 项（总开关、缩放、**位置**、框架层级）；血弧／符能弧／符文格各 4 项（启用、填充色、背景色、透明度）；准星 3 项（启用、填充色、透明度，**没有背景色**）。
- **填充色是"职业配色 / 自定义颜色"二选一的复合控件**；**背景色只有自定义**。
- 默认颜色取设计稿采样值，且**每个元素的背景色各自独立**——设计稿里三条资源各不相同的深色背景要原样还原。
- **位置直接用 EUI 现成的位置控件**（锚点下拉 + X/Y 小滑块），不自建。
- **总开关关掉时四个子开关置灰不可点**，用控件工厂原生的禁用回调实现。
- 控件全部复用 EUI 标准界面元素。页面构建函数要满足四条契约（返回内容总高度、离屏安全、控件工厂判空、构建期不注册长生命周期监听）。
- SavedVariables 由本插件自己持有（独立存储），需要自己的默认值补齐。

## 验收条件

- [ ] 19 项都能改、能即时生效（验收 4、5 的配置部分）
- [ ] 总开关 + 4 个子开关都生效；总开关关掉时子开关置灰不可点（验收 4）
- [ ] 缩放滑块两端（0.5 与 2.0）都正常：不糊、不跑位（验收 5）
- [ ] 填充色能在职业配色与自定义之间切换；背景色只有自定义
- [ ] 每个元素的颜色互相独立
- [ ] 改几条配置后重载界面，设置仍然保留（验收 10）
- [ ] 页面构建函数在离屏、控件工厂为空的状态下也能安全跑完
