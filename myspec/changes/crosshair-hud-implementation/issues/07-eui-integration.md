## What to build（要做出什么）

配置页出现在 EUI 的侧边栏里，拖动与图层都能用。

- **侧边栏挂载**：新建绿字分组 `MYUI`，其下 `CrosshairHUD` 一行。先尝试官方注册函数、失败则直接写表；**不设"始终视为已加载"标志**（要保留行右边的电源按钮）。**注入必须早于用户首次打开 EUI 面板**。
- **点行打开配置页**。
- **位置控件与解锁拖动**：按票据 06 的结论定义解锁元素（含位置保存/加载/清除/应用四件套与像素吸附）。
- **图层配置项**生效（默认 `MEDIUM`，与 EUI 自家资源条、单位框体同层；设置窗口与下拉菜单在其上）。
- **"是否隐藏"回调正确报告**：主开关关闭后不能在屏幕中心残留可拖动的空框。
- **响应界面缩放变化**：重新对齐与像素吸附。
- **不启用鼠标**，HUD 永不拦截点击。

## 验收条件

- [ ] EUI 侧边栏 `MYUI` 分组下出现 `CrosshairHUD` 一行，点它能打开页面（验收 9）
- [ ] 行右边的电源按钮能真的禁用本插件（验收 9）
- [ ] 打开暴雪设置窗口、打开任意下拉菜单 → HUD 都在其下方（验收 6）
- [ ] 默认出现在屏幕正中；进 EUI 解锁模式 → 出现拖动框、能拖、退出后位置保持（验收 7）
- [ ] **拖动框的尺寸与位置正确**（缩放父框下不跑偏）（验收 14）
- [ ] **改界面缩放后 HUD 不偏移、不发糊**（验收 15）
- [ ] **主开关关掉后屏幕中心不残留可拖动的空框**（验收 16）
- [ ] 打开 EUI 的全局搜索并输入关键字 → 不报错（验收 11）
- [ ] 点击穿透：HUD 不拦截鼠标点击
