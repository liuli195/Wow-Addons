## What to build（要做出什么）

把插件里唯一有复杂度的三块纯计算抽成可测模块，并用离线测试把它们钉住。

- **弧线填充换算**：填充比例 → 遮罩旋转角。它同时编码遮罩镜像方向与魔兽的逆时针弧度约定。
- **符文充能计算**：由起始时间、时长、就绪标志与当前时间算出比例与状态。**形参可空**；**状态是唯一权威**，空转时剩余时间返回空值而不是无穷大。
- **符文排序**：状态数组 → 槽位顺序。**三个排序键缺一不可**（就绪在前 → 充能中按剩余升序 → 索引决胜）。
- **几何常量**（起始角与跨度表）作为纯数据放这里，渲染侧引用。

模块**加载时不得触碰任何魔兽接口**——这是它能被仓库测试环境加载的唯一前提。导出必须是全局表形式（测试以零参数加载被测文件）。

**测试必须覆盖两条实机测不到的分支**：

1. **秘密值降级**（用户无法在游戏里按需让血量接口返回秘密值）
2. **符文空转降级**（实机只能靠"一次花掉 4 个以上符文"碰运气触发）

弧线换算的测试**不得写成对公式的自证**，必须用独立几何判据（点是否落在弧上 ∧ 是否位于不透明半平面内），从而把"遮罩镜像约定"与公式钉在同一个文件里。

> **一处按代码真实归属作出的更正**：本票原文要求"秘密值降级**与**空转降级"都由离线测试覆盖。但秘密值降级住在 `Core`（它需要 `issecretvalue`，是魔兽接口），而 `Core` 要到票据 04 才写。**硬把它塞进 `Logic` 只会为了测试而多造一层抽象**，与"小插件不要搞重"的原则相悖。因此秘密值降级的离线测试**移到票据 04**，与本票的空转降级各自落在代码所在的层。**本票不声称覆盖它。**

## Comments（讨论）

### 2026-09-16 完成，本票关闭

**产出**：

- `Logic.lua`：几何常量（圆环、两条弧的起止角与跨度、6 个符文格的起点/步长/跨度/数量）、弧线填充换算、符文充能计算、符文排序。加载时不触碰任何魔兽接口，导出走全局表。
- `tests/addons/MYUI_CrosshairHUD/test_logic.py`：Python 驱动本机 Lua 5.1，形状照 `Sim2GSEProbe` 先例。
- 验证登记：`verify.crosshairhud-luals` / `-luacheck` / `-toc` / `-logic` 四条，均用 `paths` 限定命中范围。

**弧线换算的核对方式**（本票的重点）：测试**不断言公式的返回值等于某个数**（那是对公式自证），而是用一套**独立的几何判据**逐点核对——把公式算出的旋转角喂给"遮罩如何工作"的独立模型，看它给出的可见性与"该点是否应被填充"是否处处一致。覆盖 **8 条弧 × 101 个填充值 × 399 个弧上采样点**。

这套判据 + 素材校验脚本对遮罩**图像方向**的断言，合起来才把「遮罩约定 ↔ 换算公式」这一对钉死；只测其中一边都锁不住。

**故意改错测试（四项全部拦住）**：

| 注入的错误 | 结果 |
| --- | --- |
| 遮罩旋转角常数 `-90` 改成 `+90`（旋转约定错） | 拦住 ✓ |
| 删掉就绪短路（顺序错，就绪时会拿 `start=0` 做除法） | 拦住 ✓ |
| 去掉索引决胜键（非稳定排序会让槽位换位） | 拦住 ✓ |
| 空转返回 `math.huge` 而不是 `nil` | 拦住 ✓ |

最后一项尤其值得记：`math.huge` 会顺着排序键流进任何比较里，而**单看功能完全正常**——只有这项测试能拦住它。
