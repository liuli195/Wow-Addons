## What to build（交付）

用户在现有单 JSON 中查看和编辑指南默认起手、优先级、条件及修改细则，校验保存后由下一次生成/新任务冻结配置，结合真实角色参数生成合法 GSE，并看到每个源步骤如何落到实际序列。

指南仅是默认来源，最终配置是运行权威。人工可根据结果调整，不强制永久与指南一致；已有底层能力内免重编 SimC。保留最小来源版本/适用范围/修改说明，不新增来源管理系统或完整新 schema（数据结构）。general（通用）区域如保留，只复用参数化表达/编辑能力，不含八条目标策略。

复用现有加载/校验/保存/摘要/快照→起点组合→初始化→程序编译导出的完整链路，替换且只替换目录均匀起点；其余三个基础来源、训练代表和两类冠军保持。保留 GSE 及原生硬合法性、行为去重、缓存、预算和身份机制。

## Required change（不可只换数据）

当前 bind 强制 funding（指定生成动作供资）和唯一目标消费按钮，generate 强制供资及两层骨架。它们必须按本版有序起手契约替换，不能只换 JSON 并留下旧业务校验或回退。

删除八条通用策略、细粒度 APL 条件作为初始化指导的要求；取消消费一次、供资额度、预消费、CD各一次、周期收尾及二层填充等隐式骨架约束。若人工明确把具体选择写入新配置才生效，不将旧断言批量迁移为新验收。原生资源、冷却、替换、天赋和伤害机制继续生效；APL 可作模拟基准。

## Acceptance criteria（验收条件）

- [ ] 默认指南版本、单体/群体及英雄天赋分支逐条核对；动态分支尚未可靠核实时不宣称默认配置选定。每项保留简短来源/适用范围和人工差异，不复制全文。
- [ ] 最终配置可编辑有序起手、优先级、条件及修改细则；已有操作内无需重编引擎。程序按结构化表达执行，无按技能名、业务类别或规则 ID（标识）分派的隐藏策略。
- [ ] 旧 funding/唯一消费按钮及两层骨架耦合退出，合法配置无需含消费动作或旧八规则。初始化只按实际配置产生结果，不自动补供资/消费/CD示范或周期收尾。
- [ ] 保留起手源顺序与重复步骤，按真实有效 GCD（公共冷却时间）、动作属性和输入节奏估计间隔；替换形态映射同一按钮，派生效果不变成可按动作，尝试不等于成功施放。
- [ ] 起手是可被后续搜索修改的循环候选，不保证最优，不新增一次性起手执行引擎；不可表达及未知说明清楚，不暗改为另一种语义。
- [ ] 源起手包含 Army、Dark Transformation 或 Blightfall 时，保留源步骤并显示只读爆发锚点映射；固定3/48/93/138秒与普通循环排除保护不改。顺序冲突列明待讨论，不静默删步骤或改时点，未定方案不冒称完整可用。
- [ ] 单体枯萎凋零、腐化替代爆发维护疾病、灵魂收割普通CD示范按已批准人工差异沿用待逐条核对，显示与指南的差别；不自动取消、不冒称指南、不扩为通用CD策略。
- [ ] 只替换目录均匀起点，其他起点及4＋4＋2上限、既有合法性/行为去重不变。相同输入和配置产生可复核结果。
- [ ] 保存、摘要冲突/坏文件、一次加载及完整冻结快照复用现有能力；新生成/新任务读新配置，运行不热更新，双场用父快照。暂停恢复遇规则变化或身份缺失拒绝并提示新建，旧输出仍可读。
- [ ] 配置摘要进入生成/搜索/训练语义身份，改变配置不命中旧规则成绩、不改变原生构建身份；一致重命名和第二份独立构造专精证明无技能/规则ID硬编码。
- [ ] 缺必需事实、非法动作、无效引用/类型/单位/版本、冲突或不可表达空点击/结构超限明确报告；未知不填0/false，坏保存不替换有效配置，不回退旧骨架。
- [ ] 输出中文逐节点动作尝试、随后 WaitClicks（空点击数）、估计时刻、参数/指南来源、人工差异、未知/近似和语义损失，附完整 GSE 与源步骤→节点→编译输入映射。
- [ ] 结束时复用既有真实角色 ST1/AOE5 私有输入重新生成两份完整序列交用户审阅，不能用构造例或旧序列代替；未获用户最终验收不标完成。

## Public seams and validation（公开接缝与验证）

复用 POST /api/tasks、GET /api/tasks/{id}?details=rule_initialization、既有 task.run/start/read/resume 及 dual_task；配置复用 task.py rules-check 与 rules-save --expected-digest。测试先沿 test_rule_initialization 的公开 run_task、synthetic spec（独立构造专精）和 test_search 的 _apl_task_boundary（外部引擎数据边界）；本版具体接缝尚待用户审阅，不新建私有演示框架。

保留原生机制、缓存、恢复、身份、保存冲突、坏文件及编译点击映射回归，按新需求替换旧八规则/供资骨架业务断言。只改配置证明生效、同名重命名证明无硬编码；02/03的诊断/选择执行不在本票实施。

云端完成开发和可用验证；确实依赖本机的正式引擎、Windows/Lua或私有安装数据验证另列具体动作、入口、仓库内路径及总限时。沿用构建超时1200秒、整套本机正式验证≤60秒口径，不把单项上限当整套预算。真实输入不外发，本机仓库外创建/删除须事先明确授权；78项预存无关修改不动，不绕过干净工作树要求。

## Boundaries and stop conditions（边界）

新底层事实/操作、固定爆发冲突处置、已有表示不支持的起手语义或预算变化须另议。不得因“指南默认”越过硬合法性，也不得凭静态近似宣称真实条件满足。本轮不运行测试、构建或模拟，不取得新门禁就不编码。
