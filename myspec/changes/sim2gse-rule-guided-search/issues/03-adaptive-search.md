## What to build（交付）

原有多起点调度先确定当前候选；将该候选同一配置的全部适用诊断和全部合法单步选项交给Coba现成LinUCB（线性置信上界选择器），每次只选一个具体操作，复用既有共同模拟批次的相对DPS（每秒伤害）反馈学习。跨角色、专精、任务积累兼容通用经验，可靠保存/恢复，最后新旧各600秒比较输出DPS。

只替换原随机算子、固定启发式及搜索洗牌兜底的操作选择，不改起点轮转、当前路径/生成父选择、批次、缓存、预算、评分晋级和冠军机制。普通搜索及新启动的既有训练共用此机制，随机初始化保留；旧任务不原地换算法、不自动重训。

复用现有pending（待处理批次）、TaskStore（任务存储）、检查点和结果中心；直接使用Coba的predict/learn（选择/学习）及必要薄适配，不自写学习算法，不建新数据库、服务或每任务副本归并。

## Acceptance criteria（验收条件）

- [ ] 原多起点轮转、当前候选/父选择及停止/预算不改；选择器仅选该候选上的操作，不做“起点＋操作”联合选择。
- [ ] 当前候选全部诊断（含unknown，未知）和配置边界内全部合法具体单步选项一起输入一个LinUCB；不人工预选规则、不按规则/技能拆学习器，无随机或固定启发式兜底。
- [ ] 一次predict只选一个操作，准确映射对象/位置/改量及选择时快照；同特征的不同具体选项不误去重。一轮多次选择仍产生同父独立单步候选，不叠成组合，不假称已入队选项实时重排。
- [ ] 无合法选项沿既有路径停滞/跳过机制处理，其他路径继续；不回退旧随机搜索，不改变原停止口径。
- [ ] 使用跨角色/专精含义稳定的通用数值特征与未知有效性标记，不把技能/规则ID（标识）当连续数值或隐藏策略权重；特征维数、单位、编码与反馈语义版本可核验。
- [ ] 配置变化但特征/反馈语义兼容时继续共享经验，不为每配置自动分模型；不兼容旧模型/待反馈明确拒绝并报告，不能静默混学或以临时重置掩盖。
- [ ] 生成父与候选已有共同search（搜索）批次按实际samples（样本数）加权求DPS，reward＝(候选均值－父均值)/父均值；匹配场景、种子/输入及执行条件，正升负降，无人工规则分或额外模拟。
- [ ] 没有可比共同批次或分母无效不learn；正常早筛已有完成共同批次可学习，取消、错误和未完成结果不造0。学习对象始终是生成父，不偷换处理时全局最佳。
- [ ] 每个有效反馈只学一次，去重和决策快照不依赖可选日志；重复读取、取消/恢复、保存失败及崩溃边界有可复核证据。
- [ ] 同宿主复用共享原生learner（学习器），必要短锁不持锁模拟；复用TaskStore等存储能力保存模型、随机进度、兼容版本与反馈去重，恢复旧任务不能回滚其他任务的新经验。
- [ ] Coba发行依赖/版本锁、序列化和精确随机恢复实际验证；原研究不能当已支持证据。需要超出现有存储/同宿主能力时先报告，不自动建服务或数据库。
- [ ] 所有现有起点及新训练统一用同一操作选择机制，入口/调用者不藏随机兜底；4＋4＋2起点框架、训练原入口和评价口径保持。旧结果保留，新任务按当前条件重新评价兼容程序。
- [ ] 配置摘要保留在任务、缓存及训练语义身份；任务固定启动快照，运行不热更新；实际爆发输入计划纳入快照、缓存和恢复身份，避免不同t0混用。01按起手估计首次t0、随后t0＋45k秒已确认，独立宏内容/窗口/按法不变；建议后续搜索沿用初始化冻结的任务计划，具体口径待门禁审阅，不自行联合优化t0、逐候选重对齐或改为成功事件触发。暂停恢复遇规则变化、输入计划不一致或身份缺失拒绝并提示新建，旧结果可读，规则兼容也不能回滚全局新经验。
- [ ] 贯通01实际初始化、02同次诊断/单步编辑、一次选择及共同批次反馈，展示真实修改和评分；固定爆发保护、原生机制及编译输入映射保持，经独立审查后才标交付。
- [ ] 最终同条件旧方案和新方案各600秒，直接比较输出DPS；不追加复测、消融组、统计门槛、最低提升或额外收益指标，既有内部晋级继续保留。

## Public seams and budget（公开接缝与预算）

复用现有任务API、task运行/启动/读取/恢复、dual_task及既有训练入口，沿01/02已确认公开接缝验证全入口，不另建演示、实验或存储框架。优先构造小例覆盖反馈/共享/恢复失败路径，再用实际开发产物贯通；具体接缝须随本票门禁先审阅。

生成、诊断、选择、学习、保存和锁等待均计入现有搜索/训练预算，不因日志开关暂停算法计时。云端完成可完成的工作；确依赖本机的引擎、Windows/Lua或私有安装数据验证另列具体授权动作、路径及总限时，沿用构建1200秒上限、整套本机正式验证≤60秒口径，不将单项上限当整套预算。

## Boundaries and stop conditions（边界）

共享经验不承诺正迁移，仍由原模拟评分和晋级判定结果。不同宿主/进程共享若超出现有能力先讨论；不扩为常驻学习服务、多算法实验、起点联合选择或组合搜索。发现超出已确认首次对齐＋45秒间隔的受保护爆发变化、未知伪装、非法编辑、重复学习、旧任务回滚经验、恢复不一致、预算超限或需新增架构时暂停相关动作并报告。
