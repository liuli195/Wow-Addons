## What to build

把所有起点及新启动的既有训练接入Coba现成LinUCB，统一选择具体合法单操作、复用已有共同批次反馈、共享原生模型并可靠保存恢复，完成整体贯通和最终新旧DPS对比。

范围：读取01/02冻结的两库快照及数据声明的features/候选关系，跨专精稳定数值编码和候选身份映射，直接predict/learn，生成父共同批次相对DPS反馈，全入口替换随机/固定启发式/搜索洗牌兜底，同宿主共享learner、短锁及最小持久化去重。随机初始化和既有模拟/缓存/晋级/预算/冠军保留。

格式、映射、保存、摘要与unknown统一依[总规格2节](../spec.md#2-两个可编辑规则库与通用执行机制)，不增加第三份业务策略库。Coba只选择候选，不能按技能名/规则ID暗配优先或奖励；特征列含义固定，未知带有效性标记，编码含义变化须版本化检查共享模型兼容。

复用optimize现有pending批次、TaskStore和结果中心；无任务模型副本归并、第二数据库、常驻学习服务或额外算法。

## Acceptance criteria

- [ ] 全八条诊断含unknown及所有合法具体操作进入统一选择；不按规则切学习器，不新增组合生成。
- [ ] 模型输出准确映射对象/位置/改量；同特征不同候选不误去重，当前批次仍为同父独立候选。
- [ ] 父子已有共同search批次按实际samples计算相对DPS反馈，正升负降，不额外模拟/人工加权；缺共同证据不learn。
- [ ] 正常早筛结果可学习；取消、错误和未完成结果不造0；有效反馈只学一次，不依赖可选日志。
- [ ] 同宿主跨角色/专精/任务复用原生learner；保存随机进度及必要状态，规则未变且兼容时恢复旧任务不回滚其他任务经验，规则变化则拒绝恢复并提示新建任务；并发与崩溃边界有证据。
- [ ] 所有起点及新训练同机制，旧任务不原地换算法或自动重训；无旧随机兜底藏在训练或调用者。
- [ ] 用开发产物贯通初始化、诊断修改和选择器的真实证据；相关失败和恢复检查完成独立审查。
- [ ] 同条件新旧各600秒直接比较输出DPS，不追加复测、消融组、统计门槛或其他收益验收指标。

- [ ] rule_config_digest明确保留在训练semantic_condition与搜索身份；两库快照同版、旧结果可追溯，配置更新不重编原生引擎，暂停恢复时规则变化即拒绝并提示新建任务，不沿旧配置跨版本续跑。
- [ ] 按总规格10.1逐条review全部规则：从①存储②初始化映射③生成顺序/次数/停止一路核到④同次诊断、候选、固定特征、一次predict和已有共同DPS反馈；身份重命名不改变业务，不把旧目标确认当新表达验收。
- [ ] 旧AOE强制链已被通用骨架来源目标替代；该目标不成为搜索硬约束或第9规则，候选按8规则可改变原骨架且不强制补回额度。也不能增加已取消的跨规则变化旧快照恢复路径；未实现/未验证分别保留状态。

## Validation and budget

复用既有公开入口、自动发现及统一验证。云端开发，确依赖本机引擎/Windows/Lua/真实数据中心安装副本的正式验证另列获准动作。现有构建超时1200秒、整套正式验证预算60秒；单项检查上限不等于整套预算，未测耗时不作承诺。具体入口、真实输入及运行总上限在该动作开始前明确，不借本草案运行。

## Boundaries and stop conditions

Coba发行版、序列化和随机恢复需实际核验。不同宿主进程共享若确有需要且现能力不足，先报告，不自动引入服务。共享经验不承诺一定正迁移，现有评分晋级不改。

发现受保护爆发变化、未知值被伪造、硬合法性越界、恢复不一致、超过获准预算或需要额外架构时停止相关动作并报告。不得把未运行验收勾选为完成。
