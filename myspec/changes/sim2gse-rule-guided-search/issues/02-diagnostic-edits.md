## What to build（交付）

任意当前候选使用现有真实模拟后，按同一配置的全部适用条件产生诊断及全部合法具体单步选项；应用其中一个操作后，通过现有编译和真实模拟取得可追溯评分。用户能看清每项证据、未知，以及修改的对象、位置和改量。

复用同次控制器事件、sequence.evaluate（序列模拟）、已有编辑体、program/codec/burst（合法性/导出/爆发保护）、缓存与评分。业务条件和编辑细则来自可编辑配置，通用程序只求值、轻量聚合及调用已有操作，不按技能/规则ID（标识）选诊断回调，不新增八类规则框架。

## Facts before implementation（实施前事实盘点）

先针对逐条确认的配置列出所需事实、现有输出及缺口。controller::write_trace 已有时间、输入/动作来源、部分GCD（公共冷却时间）、主资源及当前动作CD（冷却）等，不具备全部指南状态；静态参数也不能替代实时充能、Buff（增益）、疾病、双资源或动态窗口。

仅按实际需要复用已有报告和原生取值补轻量同次采集/聚合，明确对象与采样时点；源码可取不等于已经导出或诊断已实现。枯萎凋零已按用户决定取消位置/停留条件及对应采集需求：保留原优先位置，按冷却、实际尝试/成功、原生技能/天赋/资源/GCD合法性及高位让位判断可用机会；候选只用现有移动/次数/等待，不能改冷却机制，减腐化CD效果依实际角色原生机制而非通用常数。其他缺证继续标明未知，不为补齐证明新增诊断完整模拟、全量追踪或100种子实验；超出现有底层能力的新增事实/操作另议。

## Acceptance criteria（验收条件）

- [ ] 任意当前合法候选均可诊断，不要求来自指南初始化；同一冻结配置的全部适用条件被评估、一起输出，不先人为挑一条规则或只检查触发项。
- [ ] 诊断包含配置/候选身份、适用性、场景/时间/源位置、结论及原因、证据/缺口和有界摘要；区分不适用、未知、符合、违反及有证据的合理让位，不可用本身不证明整条通过或违反。
- [ ] 只使用当前候选同次真实模拟事实，教师、其他候选、另一场或初始化静态估计不补学生缺口。无对应事实时明确unknown（未知），不填0/false或猜测违规。
- [ ] 所需事实/已有/缺口逐条可核对，替换形态与基础按钮对应正确，采集对象及时点明确；必要小例证明观察不改变原生执行、随机过程和伤害，不额外调用有副作用的ready（就绪检查）或每点击扫描全APL。
- [ ] 配置范围内全部合法具体单步选项一起形成有限候选池；每项写明生成父、对象、位置、改前改后/改量、理由及影响范围，一候选只做一个操作，不生成组合、不另加旧八规则约束。
- [ ] 复用现有插入/删除/移动/交换/替换、块内命令、Loop（循环）/次数、WaitClicks（空点击数）及CastSequence（施法序列）/重置中配置允许的能力；未支持操作明确报告，不为覆盖而扩语法。
- [ ] Loop修改说明全部重复受影响；CastSequence成功推进/重置、普通动作失败推进、off-GCD（不占公共冷却）及等待语义不混同。既有硬合法性、行为去重、固定爆发保护通过，源位置能映射实际程序对象。
- [ ] 应用单操作后重新取得真实评分/动态证据，不能把改前状态套到改后；诊断改善不直接晋级，既有模拟评分和晋级机制保持。
- [ ] 取得“当前候选同次证据→全部诊断/选项→一个明确操作→合法程序→真实评分”的可追溯演示，保留必要未知、不可表达及失败例，并诚实报告成本。
- [ ] 只改配置条件/编辑范围即可在公开入口看到对应变化；一致重命名及独立构造配置证明无硬编码，热路径不重读配置，不新增模拟批次。
- [ ] 快照、配置摘要、缓存、恢复及身份沿01契约；规则变化拒绝恢复并提示新建任务，旧输出可读。实际爆发输入计划纳入任务/缓存/恢复身份，防止不同t0混用；受保护爆发及三项人工差异按实际配置报告，不静默更改。独立宏首次时点由01起手估计t0、后续为t0＋45k秒，宏内容/窗口/按法不变；建议本任务诊断/编辑沿用初始化冻结的计划，具体口径待门禁审阅，不自行逐候选重对齐或以成功事件触发。
- [ ] 本票完成只交付诊断/单步修改接缝，不宣称旧搜索策略已全部替换；自动操作选择与全入口贯通由03完成。

## Public seams and budget（公开接缝与预算）

优先沿既有任务API、task运行/读取/恢复及02演示所需的现有模拟接缝暴露结果，不另建一次性框架。复用既有run_task与外部引擎边界构造例，端到端验证保存配置→当前候选诊断/编辑→真实结果，不能仅测私有谓词替代。具体接缝随本票门禁先审阅。

云端完成能完成的工作；确依赖本机引擎、Windows/Lua或私有安装数据的验证另列授权动作、路径和总限时，沿用构建1200秒上限及整套本机正式验证≤60秒口径。采集、诊断、编译、保存和真实评分计入原预算，未测耗时不作达标承诺，不追加收益实验。

## Boundaries and stop conditions（边界）

配置只是表达已支持能力，不保证每个指南条件已可取值或可编辑。缺证保留未知，不增加全APL解释器、状态重建模拟器或通用事实平台。发现超出已确认首次对齐＋45秒间隔的爆发变化、未知伪装已知、硬合法性越界、恢复不一致、预算超限或需新底层能力时暂停相关动作，报告精确缺口并讨论。
