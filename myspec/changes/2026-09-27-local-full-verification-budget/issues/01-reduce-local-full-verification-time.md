# 01：将本机构建与完整验证合计压到 60 秒以内

**What to build（交付结果）：** 优化仓库现有 Build and Verify（构建与验证）构建与检查调度，使本机连续执行构建及完整验证，保留全部 37 项检查和 Sim2GSE 测试，并在合计 60 秒内完成。

**Blocked by（前置任务）：** None（无，可立即开始）。

**Status（状态）：** ready-for-agent

- [ ] 在同一台本机记录规范构建、完整验证和两段合计耗时，确定当前代码基线。
- [ ] 首轮将 Sim2GSE 长检查提前，并将并行上限从 2 调至 3；若合计未达标，依据实测继续优化已证实瓶颈，不减少覆盖。
- [ ] 本机连续三轮构建和完整验证均功能通过，37 项检查全部运行，Sim2GSE 自动发现测试和模拟次数未减少。
- [ ] 固定源码、补丁、编译器和产物身份校验继续有效；身份变化或损坏不能被快速路径误判为通过。
- [ ] 三轮合计耗时最慢一次不超过 60 秒；若机器波动导致未达标，继续优化并保留可复核证据。
- [ ] 文档或规格中的现行并行设置与最终配置一致，既有历史基线和结论不被改写。
