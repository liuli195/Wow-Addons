# Sim2GSE 停止日常构建 TC 对照引擎

**Status:** ready-for-agent

## Problem Statement

日常构建与 PR（拉取请求）验证目前准备三套 SimC（战斗模拟器）引擎。TC（社区服务端队列对照）只用于显式研究，不参与角色 SimC 的日常 GSE（高级按键序列插件）训练，却仍增加构建和验证成本。

## Solution

日常构建和 PR 验证只准备基准引擎与 GSE 受控引擎。TC 对照的源码补丁、兼容锁、调用入口、专属测试、历史实验和本机现有产物保持原样，留待将来显式恢复研究。

## User Stories

1. 作为日常使用者，我希望构建和验证只准备训练必需的两套引擎，减少等待和维护范围。
2. 作为维护者，我希望干净的 PR 环境不构建或运行 TC 专属测试，仍完整验证日常训练路径。
3. 作为研究者，我希望保留当前 TC 实现、测试与历史证据，以便将来决定是否重新启用。
4. 作为本机使用者，我希望现有 TC 可执行文件与构建记录不会被此次变更删除或覆盖。

## Implementation Decisions

- 只调整日常构建目标和默认验证选择；保留 TC 模式、补丁、兼容锁及正式规格中的可选对照能力。
- 现有 TC 专属测试退出 PR 默认测试选择，仍可在本机具备对应 TC 引擎时显式运行；其余 Sim2GSE 测试保持在统一验证中。
- 不自动清理已忽略的 TC 源码、可执行文件、构建记录或实验结果。
- 恢复 TC 构建或将 TC 测试重新纳入 PR，须以后另行明确决定。

## Testing Decisions

- 以统一构建入口检查默认只构建基准与受控引擎，且本机 TC 可执行文件和构建记录的摘要保持不变。
- 以 PR 使用的统一验证入口检查 TC 专属测试未执行、其他 Sim2GSE 测试正常运行，并在干净远端环境核对构建与验证结果。
- 在具备本机 TC 产物时保留显式运行 TC 专属测试的命令，证明测试本身未删除。

## Out of Scope

- 删除或改写 TC 实现、补丁、兼容锁、正式规格、历史实验和本机产物。
- 更改基准、受控引擎的模拟行为、GSE 搜索算法或游戏验收结论。
- 本次重新构建 TC 或承诺其未来兼容性。

## Further Notes

现有双场对照未显示 TC 时序优于默认受控策略，但这不足以证明 TC 长期无人维护；本次只退出日常维护与 PR 验证。
