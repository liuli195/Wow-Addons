# 模拟参考起点扩至约30条：讨论结论

日期：2026-11-09。状态：方向已明确，尚未整理开发门禁或实施。

最新用户指令已与插件刷新合并为[双来源整体方案](../sim2gse-balanced-reference-seeds/proposal.md)，本轮指定布丁使用GPT-6 Astra审核。当前采用前两轮试验的50/50参考加权合成，先按每组补齐30、旧适用人工材料计入，再更新插件；替代此前按插件有效量决定目标和原生切片建议。下文保留原始讨论过程，旧意见不冒充对新版的审核结论，过程见[布丁交叉复核](../sim2gse-balanced-reference-seeds/cross-review.md)。

## 用户确定的目标

用户希望战斗日志整理材料与模拟参考材料的数量大致均衡，不做300规模扩张。用户随后要求先核实插件资料按专精、英雄及目标如何计数，再对齐模拟参考起点，不能把“约30条”未经核实解释成四组只合计30条。

已只读核实：插件邪恶专精合计28种原始起手，其中8个团本首领各3条合计24条、大秘境群体2条、单体2条；另外默认团本栏的3条是重复引用。插件没有为天启骑士/萨莱因与单/五目标分别各提供28条。现有四组训练则复用同一批旧插件材料，每组实际都有28条插件起点。

因此数量对齐采用“每个训练条件下实际可用起点数”：建议模拟参考也让四组各有约28至30条，并按对应英雄和目标取材、适配和评价。跨组可共用来源与程序，但评价条件和成绩不混用；物理独立来源总数取决于实际去重，不能直接承诺总计30或120条。已有两条在适用组继续保留并计入该组数量，不强制另加30。

当前2条是萨莱因单目标、五目标的模拟器规则人工固定序列，不能冒称由实际模拟成功施放轨迹自动提取。后续材料应区分原始模拟记录、频率/短时序参考，以及据此构造的候选序列。

## 复用与范围

复用已有的参考指导候选生成、合法性检查、行为去重、原材料对照和锁定后独立复评能力，缩小候选规模。旧试验只测试过参考加权随机扩充，没有证明它稳定优于正常繁殖；不因本次数量更小就宣称已有质量收益，也不把旧方法说成已验证的真实轨迹提取器。

取材覆盖双英雄、单目标/五目标四种条件；撤回此前“四组合计约30，每组7至8条”的分配，因为它没有对齐现有每组28条插件材料的数量。优先利用同条件模拟实际成功施放顺序中的不同片段；若需频率或短时序构造候选，应明确记录来源与构造过程。最终仍是一键一技能的普通列表，独立爆发及复杂语法关闭规则沿用。

不复制重复程序凑数量；合法、不同的候选不足时报告实际数量及原因。来源数与各训练组适配、行为去重后的初始种群规模分别统计。

## 与参考库刷新任务的关系

插件参考库负责日志来源，模拟器负责模拟参考来源。保留已确认的插件刷新规则：新版成功接替受管旧版，旧证据和既有成果保留。用户本次没有要求删除其他社区、人工日志或历史搜索材料；不据“两个来源大致均衡”自动清退其他来源，也不将整个初始种群固定为60条。

现有参考库刷新门禁仍未取得展示后的开发确认；本次记录不代替该门禁，也不授权运行扩大实验。新增模拟来源的具体方案、验证预算和开发范围需与刷新方案衔接后展示，不自行恢复旧300实验。
