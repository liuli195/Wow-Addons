## Question（问题）

在前三阶段已经稳定后，Adaptive Mutation（自适应变异）、Warm Start（热启动）和可选预训练能否在未见配置上可靠减少达到目标 DPS 所需的搜索预算，而不是记住已有配置、降低探索多样性或绕过前三阶段门禁？

## 调查或讨论范围

- 自适应变异按算子合法率、粗筛通过率、晋级率、改善率和停滞轮次调整概率的边界。
- 每个算子的最低探索概率、随机重启比例及概率震荡保护。
- 标准形式优秀候选的职业、专精、能力集合、装备、天赋、输入模型、场景、客户端、引擎和模拟语义身份。
- 冷启动起点必须保留的比例，以及历史候选版本不匹配时的失效规则。
- 留一配置验证和训练、调参、验证、测试配置隔离。
- 预训练只学习起点排序、算子优先级和候选提案概率，不替代 SimC 评分。
- 第四阶段内部三个子门禁：先自适应变异，再静态热启动，最后才可考虑预训练。
- 每个子阶段收益不稳定时立即停在上一层的条件。

## 关闭条件

- 自适应变异相对固定策略的停滞率、达到阈值成本、最终 DPS 和多随机种子分布门槛明确。
- Warm Start 在未参与训练的配置上通过泛化验收，或有明确证据停止扩大候选库。
- 预训练只有在静态 Warm Start 通过后才允许评估，并有独立额外收益门槛。
- 用户确认任一子阶段失败时保留上一层方案，不以增加模型复杂度作为默认方向。
