## 唯一配置入口

在现有TOML（配置文件格式）增加一节，共享语法范围：

```toml
[syntax]
multi_command_blocks = false
loop = false
wait_clicks = false
castsequence = false
```

四键只接受布尔值。缺节或缺键补true以兼容既有配置；上例显式四false启用单技能范围，不静默修改用户本机config.toml。解析器原有simulation/training/search节保留；syntax是明确增加的唯一共享节。未知字段、错误类型、双重权威来源明确报错。

公共调用可接收同名syntax_config参数。新建任务先分别校验文件与显式参数的原始键/类型，再把显式提供的键逐键覆盖文件对应键，最后仅对两处都缺少的键补true，不能先给部分参数补true再整份覆盖文件。例如文件四false、参数仅loop=false，最终仍四false；仅loop=true时只开启循环，其余保持false。显式null不是省略。内部父子调用只传完整冻结值，不重新合并文件或默认值。训练及正式算法配置不复制四键；持久任务config中保存已规范化syntax范围和解释版本，由统一归一化器校验。新建入口读取文件一次，传递给准备、各组、正式任务和双场子任务；内部入口不得再次读文件覆盖冻结值。

恢复时参数省略沿用原记录；部分显式参数只逐键与已保存值比较，不为缺键补默认、不从当前文件取值。当前合法文件里的后续变化不改变旧任务。任一显式键与冻结值不同则拒绝，不以日志覆盖方式处理计算配置。缺少新策略身份的旧未完成任务只读、明确提示创建新任务，不自动补true续跑。

范围仅是搜索准入/生成约束，不是模拟器全局语法禁令。第三方导入原样模拟、历史读取及独立爆发不受普通主循环开关误伤。打开开关不放宽其他合法性、长度、重置或职业限制。

## 最小共享实现

1. simulation_config.py负责严格规范化、默认补齐和公共入口投影；不新建配置服务。
2. program.py复用现有搜索程序结构和遍历，提供一个共享语法校验入口，错误含来源/结构位置/禁用能力。源结构先检查，再经过现有角色适配及规范化；不得用展开后的行为身份掩盖禁用结构。
3. search.mutate筛选当前实际可用操作：multi_command_blocks控制block等块内增命令；loop控制loop/repeat_count；wait_clicks控制等待创建与修改；castsequence控制创建、成员与重置编辑。所有定向分支也使用同一可用集合；普通替换/插入/删除/移动/交换仍受长度和技能池限制。没有可用变化如实no_change，不新增无限重试。
4. population_training._cross保留既有代码但限制容器同层兼容，按冻结范围核验父本与生成结果。合法父本不足以保证子代长度/展开/导出上限，最终仍走共享校验和既有编译检查。不合规候选不得评分、缓存或成为可靠种群，保留原正式粗评容错/训练失败契约。
5. 优先在现有Program编译链传入冻结语法上下文；单按钮绑定是唯一必要的执行修正。当前sequence.select把variants展开多命令；严格单技能路径应绑定一个基础按钮命令，复用原生替换机制，并验证导出与执行一致。全开放旧路径、旧导入和固定爆发不暗改。不能证明绑定一致就报错，不能静默退回多命令。
6. 发布、读取来源、恢复和最终再导出都复用相同语法校验，不各写一套规则。独立爆发豁免来自任务冻结定义和调用上下文，不能信任候选metadata自称burst。

### 关键闭合反例

- 四false父本仍可能被当前定向分支插入WaitClicks；必须约束二次选择，不只筛operations初始数组。
- 关闭loop的来源即使可无损展开，也因源结构含Loop拒入；语法策略与行为等价是两回事。
- 多命令关闭且loop开启时，Loop内部普通块仍必须单命令；castsequence开启是单独明确开放成功推进语义，不是靠一条宏命令规避多技能限制。
- 单Loop包装父本与顶层普通父本交叉会有层次差异；不能因为两者都合法就任意交换。
- 行为缓存命中不代表来源结构合规，准入必须先于缓存读取。
- 双场dual_task._export重新compile_program时现未传capabilities，需要补齐可信冻结上下文并再次验真。
- 固定战前前缀在战斗内形成原有空步，不是可搜索WaitClicks；保留其成本，不引入新开场状态机。

## 版本、成果与缓存

- 程序结构不变，不为配置开关引入skill-list-v1平行表示或强推v4。
- 任务/准备身份加入规范化syntax和其解释版本，版本常量随实际兼容变化最小升级。旧结果按旧凭据读，不往旧数据补写字段。
- 本轮沿用外层训练/正式成果契约2，不新建v4。两类成果已有evaluation JSON字段，新增其中的syntax凭据：解释版本1、完整规范化四键、策略摘要；manifest/任务冻结内容同样保存，摘要加入既有条件身份。新任务新发布必须带该凭据，删除/篡改时明确失败；无该凭据的历史完整记录仍按旧契约解释，仅在作为新来源时准入，不补写或冒称新成果。旧v1读取和v2四代表语义保持，已废弃v3不恢复。读写/校验/发布/恢复的严格解析分支需同步覆盖，这属于本轮实现，不留为未决版本选择。
- 新策略训练快照和正式冠军按含策略身份的现有条件键保存，不能覆盖另一语法范围的旧成果。无策略旧快照只读，若作为当前来源则再次准入、适配及评分。
- 任务搜索路径依赖策略；不能借评分可复用证明任务可以换策略恢复。评分仍遵守原完整身份及可靠收据，不新增跨策略复用优化，也不主动清除旧缓存。

## 定向修改边界

保留现有随机及有可信证据的定向能力，不新增目标优化器或概率参数。交叉后不使用父代位置反馈；位置/按钮/输入来源归因不可靠时不得据此删整段。对仅凭相邻事件推断资源消耗者的定向插入，本轮采取窄隔离：保留统计展示和随机插入，不使用未证实因果指挥修改。基础/替换形态归为同一按钮，不能误判为未使用技能。其他算法优化另立项，不扩大到完整反馈重写。
