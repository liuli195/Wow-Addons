# 02：训练从初始种群到四代表全程合规

**What to build（交付行为）:** 训练只接收并生成允许的结构，经原五场景复测发布四条可追溯代表，重读和恢复保持同一范围。

**Blocked by（阻塞任务）:** 01。

**Status（状态）:** ready-for-agent

- [ ] 外部材料、历史最佳、准备缓存和适配结果逐项准入；可选拒入、显式非法、读取失败和无合法材料分别报告，原件保留。
- [ ] 随机与定向操作先筛后选，交叉仅兼容容器；子代合法及上限闭合，不复制凑数、不无限重试。
- [ ] 两技能长度1～4的小空间以及少量复杂混合样例覆盖替换/插入首尾/删除/移动/交换/交叉和禁止结构不出现。
- [ ] 恢复核验种群、档案、待评分、复测及发布意图，范围变化不续跑；旧数据不改。
- [ ] 四代表及五场景计划保持，发布与重读验证策略；不足不覆盖旧成果，同角色不同语法范围快照隔离。
- [ ] 定向反馈不能绕开开关或误用交叉前位置；不可靠资源消费推断不指挥插入，随机修改保留。

## 实施范围与验收入口

seed_training.py、population_training.py、search.mutate及现有result_store/manifest最小身份接缝，复用program共享校验。通过seed_training.run_training及现有内存完整训练夹具验收，真实编译复用统一真实层，不启动生产预训练。

## Comments（讨论）

本票不改选父、评分、停止参数、种群规模或代表数；第一张票据提供配置和绑定，不是只交内部工具。
