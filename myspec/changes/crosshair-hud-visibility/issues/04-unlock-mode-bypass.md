# 04：解锁模式绕过条件

## What to build（要做出什么）

把条件设成「仅战斗中」，人却在主城——打开解锁模式，照样拖得到准星。

- 解锁模式中，**条件判定为隐藏时绕过**：元素照常显示、可拖动。
- 但「这东西不该存在」的情形不绕过：**总开关关着**、或**可见性选了「从不」**，解锁模式里也不出拖动框。

这条规则要的是：让「现在是编辑模式」与「这东西被关掉了」区分开。前者该让你调，后者不该冒出一个空框。

## Acceptance criteria（验收条件）

- [ ] 条件为「仅战斗中」且不在战斗中，进入解锁模式 → 拖动框存在且可用
- [ ] 同场景下关掉总开关 → 拖动框消失
- [ ] 同场景下把可见性设为「从不」→ 拖动框消失
- [ ] 退出解锁模式后行为复原（该隐藏的仍然隐藏）
- [ ] 复用 EUI 现成的解锁中标志，不新造一套判定
- [ ] 离线检查通过
