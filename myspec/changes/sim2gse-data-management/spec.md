# Sim2GSE 统一数据管理框架

Status: ready-for-agent

## Problem Statement

运行数据、缓存和证据分散，缺少统一身份、依赖保护和可恢复维护，妨碍节省空间、训练以及分析比较。本次完整搭建框架，只在隔离合成数据上演练。

## Solution

两个代理共用自包含技能，单一 CLI（命令行入口）管理独立 SQLite 生命周期索引、原始文件和流式分包 tar.gz 无损归档。生产默认禁用；容量、保留、频率等全部待商量，配置不完整拒绝生产变更。

2026-10-02已确认的新归档布局：按稳定来源及原片段顺序，把现成小片段流式共包；不为填缝重新切片，每包有效载荷不超过part_bytes、成员不超过1000、总包不超过1000，空原件仍保留一个0字节成员。格式1及原读取器/CLI/schema不变，预留仍按旧片段数保守计算。旧sealed不重写，旧verified/published核验原产品，reserved/writing续跑先保留残留再重建；仅合成数据验证，不重打历史包或启用生产。

## User Stories

1. 使用者从不同工作目录和中文、空格 Windows 路径调用同一入口。
2. 维护者只读 inventory/status 查看对象、位置、状态、依赖、预留及实际空间口径。
3. 维护者预览旧目录原位 legacy register 和迁移计划，真实历史本次不登记写入。
4. 任务调用者通过稳定 run/artifact ID 分配路径、begin/finish、封口及 resolve。
5. 任务调用者获得并发容量预留，满额拒绝新增长而不偷偷清理。
6. 使用者通过 pins、持久依赖和活动锁/lease 保护数据；过期心跳不能单独证明死亡。
7. 维护者明确批准撤销加速缓存并获知可能重算；未知引用保护。
8. 分析者增量提取事实且幂等，保留失败、未完成、删失、样本数和可用误差。
9. 分析者看到缺失操作、概率和时序标为缺失，不能从DPS编造。
10. 分析者有界 query/compare/export，显式变化轴，其余上下文匹配或分层。
11. 训练者取得不可变 snapshot，固定身份、条件、版本、事实和持久依赖。
12. 维护者流式分片 archive 核验成员及原始字节摘要，先临时后发布。
13. 维护者 restore 原SHA，拒绝绝对路径、..、链接、覆盖及膨胀超限。
14. 维护者取得 SQLite 一致性备份，不遗漏 WAL。
15. 维护者跨卷 migration 先copy/verify再切换，持久阶段中断可重试。
16. 旧消费者仍可读取被引用 native.json 原路径，不能只移目录改索引。
17. 维护者 quarantine 可恢复且知道同卷隔离不释放空间。
18. 维护者 purge 仅执行绑定当前计划摘要的逐项授权清单，身份变化拒绝。
19. 维护者 maintenance 使用同一安全入口，计划任务仅生成预览，不安装启用。
20. 使用者在隔离根完成全部生命周期成功与故障演练，生产保持禁用。
21. 审查者按每票固定起止提交及脱敏测试证据独立复核。
22. 使用者现有三步界面、评分、600秒预算、恢复规则和默认诊断关闭保持既有契约。

## Implementation Decisions

- 运行实现、CLI、模板及必要资源自包含于技能；开发测试位于仓库 `tests/sim2gse-data/`，不随技能分发，运行脚本不反向依赖测试。机器配置/索引/大数据在外部受管根；Claude目录联接共用，显式幂等安装与生产启用分开，不改全局配置、不依赖一次性脚本。
- 自包含指最小可复制运行时：目前仅SKILL.md、scripts/simdata.py和assets/config.default.json。开发验收记录移至docs/sim2gse，不随技能分发；复制到脱离仓库的临时目录仍可完成基本公开CLI运行。
- 一个 Module（模块）及最高公开 Interface（调用接口）：技能脚本的单一CLI。内部按职责组织，避免每命令另造框架。SQLite单生命周期索引独立于TaskStore。
- 稳定ID与位置分开；角色、摘要、schema、封口、应用层last_used、租约/锁、pins、依赖、日志和容量预留完整记录。语义request摘要与原始字节SHA分离。
- 只读 Adapter（适配实现）读取旧 batches/shared.reusable，不调用会建表/提交的TaskStore构造器。未知引用、来源不明缓存默认保护。
- 持久输入/证据/模型/快照/分析/验收与可撤销加速引用分开；批准且无持久依赖才失效缓存并提示可能重算。未接resolver的旧消费者保留原路径，迁移有还原或引用切换协议。
- 规范化路径、统一文件锁、拒绝越界/重解析点；锁文件存在不代表占用；PID复用/过期心跳不能单独解除保护。扫描/哈希/压缩不更新业务last_used。
- 计划固定对象身份/摘要/引用/配置，执行重核；阶段持久、临时校验后发布、可恢复隔离、跨卷copy/verify切换；purge逐项确认绑定当前计划摘要，无万能yes。
- SQLite一致性备份覆盖WAL；恢复拒绝绝对路径、..、链接、覆盖和超限；源变化/锁占用/引用不明/空间不足拒绝。
- 容量、保留天数、维护频率、维护余量和分包目标未定，不采用100GiB。生产禁用且配置不完整拒绝；测试仅显式隔离根和合成值。
- 预算覆盖活动数据、原件/归档共存、staging、quarantine、恢复、查询scratch、DB/WAL及并发预留，预留维护空间；同卷隔离不释放空间。
- 不引入Parquet/DuckDB/PyArrow；不改变搜索/引擎。已有合法结果提取事实，缺失标缺失，不额外模拟或违背默认关闭诊断。
- 比较允许变化轴不同，其余条件匹配或分层，不要求被比较版本相同。

批准归档/恢复/一致性备份在现有写锁内重核当前计划并匹配批准摘要，不缓存锁外清单作为执行证据；同批读取可借用当前索引连接，不能跨操作或持久缓存替代核验。复制读取保留原先直接和传递活动锁/运行/读者租约阻止语义；保护查询、迁移、隔离及删除仍计算完整持久/未知依赖。阶段提交后的产品身份、成员和原始摘要重核不得为性能删除。

隔离合成根覆盖全部命令、不同cwd及两代理共用入口、空格/中文/长路径、链接/越界/覆盖/跨卷；并发锁与预留、持久依赖及加速撤销、PID复用/陈旧lease/runner字节锁；损坏包/穿越/链接/膨胀/恢复SHA、WAL备份、每阶段中断重试幂等、计划后变化、磁盘不足、同卷隔离；事实幂等/缺失/失败/删失/样本/误差、有界查询/变化轴/快照复现。

正式构建与固定基线验证按统一技能，失败、缺依赖、跳过分别报告，不冒充通过。真实历史可只读小样本，不写回；本次不运行游戏验收。

## Further Notes

### 票06实现细化（候选，不应用正式规格）

06独立审查P2细化：活动producer可锁外写/截断其批准载荷；逻辑抵扣必须来自同一完整总量扫描已计入的stat字节，不从后续扫描减旧总量。仅目录栈内保存计量，保持流式有界。物理卷可用量与文件stat非同一快照，活动run保守保留完整批准载荷到finish/release；经过身份/令牌及成员/载荷校验的finish仅核算自身结束的未来载荷，其他运行/操作和元数据/维护空间仍保护，封口成功才事务核销，不暴露外部豁免参数。迁移/归档同锁阶段抵扣保持。Windows计划预览按官方31天上限拒绝超过744小时的整数配置，不静默截断或更新用户策略。

预算每次在同一根写锁内完整流式核算主根和登记卷，未知文件/DB/WAL全部计账，不再因1000目录项截断阻止大根正常增长；内存与同时打开目录数仅随深度增长，最大128层，拒绝非普通对象、链接和目录身份变化。inventory --complete只输出完整合计、不哈希；--incremental每页选中项/名字堆有界，64KiB游标绑定根及未完成目录身份，目录变化拒绝。跨页为实时观察而非冻结快照，超宽目录名字可能重复枚举，明确报告成本，游标不能作为预算或删除证据。每批来源/计划/查询有界限制保留。

maintenance复用同一CLI生命周期实现、计划摘要、逐项确认、配置、保护、锁、预留和中断重试，不按atime/年龄自动清理。schedule-preview仅输出禁用Windows任务XML，动作只运行维护状态页，未定参数及明确含时区开始时间缺失则不生成XML，不安装启用、不创建生产入口。真实历史、生产配置/计划任务及Gate2正式规格应用仍另行授权。本票公开CLI合成验收含2400实体未知文件、1205文件续扫、56万条OS目录边界合成元数据及完整归档隔离删除恢复链；真实历史不扫描。

### 票04实现细化（云端审查前）

云端首轮P2修复补充：元数据峰值不能由payload固定常数代理；实际编码计划、产品和封口记录、阶段/隔离日志及SQLite主库/WAL/索引拆分页分别估算，在首次操作写入前批准并准入，阶段后仅保留未来预算。恢复位置解析有界跳过确认缺失的登记副本，可疑身份、摘要、权限或路径边界异常拒绝，不忽略异常回退。

统一入口archive/restore/backup-sqlite/operation（归档/恢复/一致性备份/操作管理）使用预览清单摘要和独立操作预留，五阶段持久日志支持重试。流式USTAR+确定性gzip按原字节分片，原件留在原路径；包、成员和完整原SHA-256核验，恢复仅到受管根内新目录并登记稳定ID的位置。SQLite源先登记为可变、未封口角色，一致性API映像覆盖WAL已提交视图，再封口登记映像，避免主文件哈希冒充逻辑快照。发布前后保存产品身份/摘要，重试保留未完成产品，不删除原件或隔离内容。限额计共存和并发预留，所有策略值仍未配置、不启用生产。

每批来源/包至多1000、清单1MiB；明确超过时分批，拒绝不完整盘点冒充全根容量。票05/06仍须完成消费读租约、依赖传递和大根增量盘点，以及迁移、具体授权隔离/删除、维护与计划任务预览，才能验收整个框架。真实数据上线须另议参数和具体批准清单，不因技能可发现就启用生产。
