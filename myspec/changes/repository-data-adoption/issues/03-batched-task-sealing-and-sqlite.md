# 03: 大任务封口与一致性映像

**What to build:** 受管任务结束后，普通不可变产物以有界批次登记，任务数据库和共享缓存作为可变来源并获得所需一致性映像；只有登记与映像核验全部完成才发布真实终态并核销未来承诺，失败或中断可以幂等恢复。

**Blocked by:** 02: 原路径任务准入与恢复。

**Status:** ready-for-agent

- [x] SQLite 主库、WAL 和 SHM 不按普通不可变产物封口；可变来源与已提交一致性映像分别登记。
