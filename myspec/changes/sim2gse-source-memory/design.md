## 当前范围与决定树

- 目标：当前真实规模整批同时内存2048兆字节，性能、功能及质量不退化；不能只计主程序或只验训练。
- 范围：来源→准备与初始种群→共用运行→编译模拟报告→检查点恢复→最终复测保存读取，另设整链验收票。先后顺序不代表后续可不做。
- 保真：原并行、起点、随机计划、评分、历史、语法能力、诊断、恢复及证据保持。
- 数据：固定内容引用与小清单，旧数据完整读取，开发先隔离；正式激活与兼容回退在门禁二确认。
- 限制：有损选项另行讨论，不能自行降并行/裁历史；不重写引擎。新目标未达就报告未完成，不用来源收益代替整链完成。
- 待本门禁确认的工程选择：完整分支名、七票串行与每票审查、公开验收接缝、短/完整对照及磁盘预算、同条件临时停止线和正式激活时点。

这是需求访谈与领域建模的本轮复核结果。沿已有来源、原件、修订、准备快照、完整代等术语，六步是流程范围，不新建另一套领域词典。
