# 05：训练与正式搜索检查点保存恢复减少全量中间副本

**What to build（交付内容）：**在原有安全边界生成和核验完整一致恢复文件，恢复时复用一次已核验加载，降低保存及恢复峰值。

**Blocked by（阻塞任务）：**03 共用运行资料；串行实施安排在04之后，04不是本票业务前提。

**Status（状态）：**ready-for-agent

- [ ] 保留原安全保存边界和全部必要历史、种群、随机状态、失败额度，不能通过减恢复能力省内存。
- [ ] 有界逐行编码、写入和核验，不同时保留全历史对象、多份整批文本和重复读回结果。
- [ ] 当前版本字段/候选/请求排序与摘要语义保持；若改变格式须版本化并保留旧恢复读取，损坏不能跳校验。
- [ ] 恢复文件在同一加载范围复用已核验批次和公共资料，避免重复解码，不跨恢复会话信任旧内存。
- [ ] 训练与正式双场分别验证暂停/继续、完整代、复测阶段、损坏、容量和保存读回失败，上一可靠副本不受损。
- [ ] 记录恢复保存与加载的时间、峰值及恢复后完整结果，没有后台移账或额外普通中间写盘。


## 共同验收

本票完成需有训练与正式搜索两侧的等价行为、内存、时间及失败路径记录；公共代码一次实现，两侧分别验证。每票先失败后修复、统一适用验证、独立审查。不得减少起点、评分、历史、并行、诊断、恢复或证据。真实试验共用完整门禁预算，不另加额度；开发不切换正式来源。
