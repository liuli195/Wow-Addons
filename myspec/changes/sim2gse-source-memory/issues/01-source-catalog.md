# 01：来源读取更新在训练和搜索中使用固定原件与完整小清单

**What to build（交付内容）：**登记、修订和查询固定版本原文，通过小清单向训练及正式成果来源消费提供完整资料，不反复搬运停用归档。

**Blocked by（阻塞任务）：**无。

**Status（状态）：**ready-for-agent

- [ ] 消除已有修订字段仍计算默认摘要的重复工作，缺字段时保留原摘要定义。
- [ ] 固定原件与全部状态小清单读写跑通；大原件必要时无损顺序分段并能完整还原。
- [ ] 先原件读回再核对清单旧版本并原子切换，缺失、损坏、暂时不可读、并发和响应丢失不破坏旧资料。
- [ ] 未激活新格式时旧读写仍保全原文，禁止小行覆盖旧库；公开列表及原件查询信息不删减。
- [ ] 训练来源消费和正式训练成果/历史出处消费均验证，不给正式搜索新增整库原文读取。


## 共同验收

本票完成需有训练与正式搜索两侧的等价行为、内存、时间及失败路径记录；公共代码一次实现，两侧分别验证。每票先失败后修复、统一适用验证、独立审查。不得减少起点、评分、历史、并行、诊断、恢复或证据。真实试验共用完整门禁预算，不另加额度；开发不切换正式来源。
