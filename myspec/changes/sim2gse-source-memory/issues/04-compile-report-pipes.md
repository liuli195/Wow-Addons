# 04：训练与正式搜索编译模拟报告减少管道副本

**What to build（交付内容）：**保留原真实编译与模拟，在两条执行链中减少输出缓冲收尾、拼接、全文解码、分割和计长的重复表示。

**Blocked by（阻塞任务）：**03 共用运行资料。

**Status（状态）：**ready-for-agent

- [ ] 复用已有摘要输出和受控运行器，实现有限输出的少复制接收与字节边界解析，不新增引擎或常驻服务。
- [ ] 公共输出字节协议、编码检查、日志/错误内容、重复或缺失报告边界、原合法容量和原真实编译检查保持。
- [ ] 报告转换减少重复遍历和递归副本，完整字段、类型、数值、空值及诊断开启/关闭语义逐项一致。
- [ ] 训练和正式搜索真实编译、模拟报告、评分、动作反馈及导出结果前后一致。
- [ ] 输出超限、坏编码、坏报告、进程失败、超时、取消和子进程持有管道时仍能安全收尾。
- [ ] 现有总在途限制、作业所有权和句柄隔离保持；有实际峰值及速度记录，不声称零拷贝。
- [ ] 若确需改原生协议/引擎源码，返回需求加载引擎升级约束，不能按普通封装改动悄悄扩展。


## 共同验收

本票完成需有训练与正式搜索两侧的等价行为、内存、时间及失败路径记录；公共代码一次实现，两侧分别验证。每票先失败后修复、统一适用验证、独立审查。不得减少起点、评分、历史、并行、诊断、恢复或证据。真实试验共用完整门禁预算，不另加额度；开发不切换正式来源。
