# 01：完成一次无临时文件的真实评分

Status（状态）：ready-for-agent
Blocked by（阻塞任务）：无；须先确认门禁一。

## 交付范围

沿现有训练评分与页面任务调用链，完成资料输入、原生模拟、轻量粗评返回、完整复测返回、脚本编译的内存通信；复用现有编译器与进程保护。提供明确的新程序身份，不改变战斗与评分语义。本票先验证单次调用，连续任务保存策略由02完成。

## 验收

- 通过现有公开评分调用与页面任务测试接缝执行真实子进程；同冻结条件核对分数、样本、方差、技能统计、位置反馈和身份校验。
- 粗评直接返回必需字段，最终复测仍返回完整证据；输入、编译、标准输出与错误输出没有应用临时文件。
- 覆盖双路大量输出、超时、取消、格式错误、输出上限、子进程与句柄清理；不能降低原进程约束。
- 按模拟引擎升级流程锁定来源、构建并验证；保存为报告而增加的原生与解析时间可计量。
- 先写会失败的行为测试，再实施；独立审查通过后进入02。
