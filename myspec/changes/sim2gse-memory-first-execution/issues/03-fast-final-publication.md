# 03：并行保存最终证据并让页面读取新旧成果

Status（状态）：ready-for-agent
Blocked by（阻塞任务）：02。

## 交付范围

任务独立分组批量转换、压缩、保存和核验；共享锁仅保护同一成果最终版本检查及切换。新成果明确引用证据并带新身份版本，训练成果与正式冠军的消费端均兼容旧格式。

## 验收

- 完成真实训练发布，页面加载其种子、按当前角色重新评分、产出并复制正式推荐序列；旧成果也能读取核验。
- 全部入围前八的原有最终复测证据完整保留后再选四；独立文件可并发保存，无反复全目录扫描与逐候选保存。
- 覆盖同时发布、压缩或写入失败、读回损坏、切换前退出、响应丢失重试；失败不替换旧成果，重试不重复污染记录。
- 不改旧共享位置清单机制、不改旧证据；新路径不以解除旧全局锁为优化办法。
- 转换、连接、等锁、写入、读回与尾部耗时全部可核对，不把必要保存放后台后冒报完成。
- 先失败测试、后实现；逐票独立审查。

## Comments（讨论）

先复用现有批量存储能力；只在实测证明不足时增加必要的小适配，不引入通用数据库或队列框架。
实施及聚焦检查完成，待独立审查。完整报告保留原有类型化表，新任务分组直接定位；新增轻量归档表与版本3读取。具体证据见 implementation.md。
