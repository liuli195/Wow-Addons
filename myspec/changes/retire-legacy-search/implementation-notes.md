## 退役配置名称（供开发和操作反查）

- `total_budget_seconds`、`search_budget_seconds`：旧总预算和搜索预算。
- `candidate_limit`、`round_candidate_limit`：旧候选总数和每轮上限。
- `no_improvement_rounds`：旧无改善轮数；新训练不再注入该字段。
- `batch_targets`、`validation_batches`：旧累计评分阶梯与晋级复核。
- `final_batches`、`final_iterations`：旧最终复测设置。
- `trace_search`：旧搜索过程追踪。
- `scenarios`：旧可配置评分场景；当前正常场景及训练五场景仍按各自实际输入检查修饰键重置合法性。

`iterations`仍用于自由选招参考，不是正式遗传算法采样旋钮；并发、随机种子、按键间隔、重置事件和四个日志/曲线设置继续有效。原字段与意义必须保留在旧成果只读验真中，不给旧任务增加执行能力。
