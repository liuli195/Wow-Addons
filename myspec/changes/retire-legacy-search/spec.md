# 完整退役旧正式搜索

**Status:** ready-for-agent
**Flow Level:** Full（完整）
**Development authorization:** 用户在完整退役范围、兼容取舍和90–150分钟预计投入展示后回复“确认”，授权实施到验收结束；不包含合并主干。

## Problem Statement

用户已经通过两轮完整默认对照选择新的正式遗传搜索。旧正式局部搜索虽然不再是产品执行主路，历史基准工具仍能抽取并运行旧源码，失效参数仍被新入口接受，现行说明和正式规格仍包含旧预算、分档晋级及轮转承诺。

## Solution

当前受管产品和工具只执行新的正式遗传搜索。旧执行入口、专用死代码、无效配置和专属测试退役；现行说明统一为遗传自然停止及正常场景独立复测。旧完整成果仍可查看、验真、提取程序并在新任务重新评分；旧未完成任务不再显示可继续。历史测量和原始成果不删除、不重写。

## User Stories

1. As a 正式搜索用户, I want 保留现有单场和双场入口, so that 不需要学习另一套运行方式。
2. As a 正式搜索用户, I want 当前工具不能重新启动旧局部搜索, so that 退役不是仅切换默认值。
3. As a 调用者, I want 已失效的旧参数明确报错, so that 不会误以为预算或候选上限仍有效。
4. As a 正式搜索用户, I want 新任务继续自然停滞并完成正常场景复测, so that 单冠军仍来自可靠的完整入围评价。
5. As a 训练用户, I want 共用变异、报告、缓存及五场景四代表保持, so that 清理不损害新训练。
6. As a 历史成果持有人, I want 旧完整成果和原始报告仍按旧身份只读验真, so that 清理不破坏证据。
7. As a 正式搜索用户, I want 适用历史程序进入新任务重新评分, so that 旧分数不冒充当前成绩。
8. As a 旧任务用户, I want 页面明确旧任务已退役且不能继续, so that 不会遇到按钮暗示可恢复而点击后拒绝。
9. As a 当前GA任务用户, I want 同版本取消、复测及发布恢复保留可靠进度, so that 已成功批次不重算。
10. As a 数据持有人, I want 代码变更仍遵守原有版本保护, so that 未经证明的跨版本任务不混接。
11. As a 文档读者, I want 现行说明和正式规格一致, so that 不再按旧预算或晋级规则操作。
12. As a 历史报告读者, I want 旧资料原地注明失效与替代关系, so that 可以追溯当时结论而不误作当前指引。

## Implementation Decisions

- 删除旧源码抽取与运行工具链，不删除Git历史或原始对照目录。旧专用汇总代码随退役工具移除，现有通用曲线/报告读取继续可用。
- 当前配置拒绝11个退役字段：`total_budget_seconds`、`search_budget_seconds`、`candidate_limit`、`round_candidate_limit`、`no_improvement_rounds`、`batch_targets`、`validation_batches`、`final_batches`、`final_iterations`、`trace_search`、`scenarios`。旧冻结成果凭据按原字段解释，不把旧默认值继续注入新任务。
- 保留有效参考评价迭代数、按键间隔、重置事件、随机种子、并发、日志与曲线设置。修饰键重置须继续符合实际冻结场景及点击对齐约束。
- 删除旧配对区间/筛选死代码、旧冠军新发布及旧未完意图补写分支；只读v1/v2验真及历史程序重新评分不删除。
- 共享评价深模块、存储、变异和原生起点原地保留，不新建策略框架、存储或模拟后端，不为文件名清理大搬迁。
- 旧未完任务明确拒绝且不改写已有结果；新GA按现有完整源码身份保护恢复，清理前的新GA未完任务可能因版本变化拒绝跨版本恢复，不放宽该保护。
- 当前升级后检查按新GA冻结评分计划核验，不再以旧阶梯参数作为新成果证明。

## Testing Decisions

- 复用最高现有公开入口：`task.run_task/resume_task`、双场HTTP创建/读取/恢复、训练公开入口以及已保存成果读取。新旧配置负例应在文件/引擎/数据中心动作前拒绝。
- 先使用最小红绿检查验证公开拒绝和旧任务只读行为；静态可确认的死代码/入口删除以全仓引用反查验收，不追加AB、重训或大模拟。
- 保留新GA完整代、正常复测、同版本取消恢复、旧成果验真重评和通用文件发布可靠性覆盖。旧算法专属测试不能仅改名冒充新覆盖。
- 受影响最小检查与独立限定差异审查完成后，按固定基线通过统一验证；依赖/平台阻塞如实报告，不把未运行记为通过。

## Out of Scope

不改HTTP诊断参数传播或BAV超时配置，不调整GA算法、默认采样、停止阈值或并发，不新跑AB/训练，不构建引擎，不删除正式数据，不放宽历史身份，不合并主干或部署。
