### 实施主线

```mermaid
flowchart LR
    P0["P0 兼容性核实"] --> P1["P1 序列与导出闭环"]
    P1 --> P2["P2 可信执行模型"]
    P2 --> P3["P3 个性化搜索"]
    P3 --> P4["P4 中文终端与运行包"]
```

| 阶段 | 进入下一阶段所需的实际证据 |
| --- | --- |
| P0（兼容性核实） | 版本和角色匹配、原生基线成功、支持范围无隐瞒缺口 |
| P1（序列与导出闭环） | 离线编码与编译顺序一致、可准备导入产物；真实导入等候选模拟结果产出后执行 |
| P2（可信执行模型） | 离线失败步进、队列、当前样本效果及隐藏扫描用例成立，关闭补丁有回归依据；实机差异留到导入阶段校正 |
| P3（个性化搜索） | 合法对照、统一动作搜索、独立复测与节奏扰动证据；分项冻结仅作可选诊断 |
| P4（终端产品化） | 干净环境完整运行、中文操作、取消恢复、手动导入及第 21 节完成定义 |

阶段证据是未来实施验收要求，本次均未代填为通过。离线结果须标明尚未经过游戏验证，真实导入和行为验收后才能标为实机通过。安全输入、版本绑定、日志与失败处理应随首条执行路径建立，不等到 P4 再补。

## Decisions so far（已完成决策索引）

- [确认首轮角色、场景与输入方式](issues/01-first-validation-scope.md)：邪恶样本已收到，单目标、300 毫秒；严格按地图顺序，安装在候选模拟结果产出后的真实导入阶段讨论。
- [核实引擎可复用基础及按键控制入口](issues/02-engine-evidence.md)：已按顺序复核固定程序与源码，补齐额外扫描、队列预选与原生报告复用边界；研究完成不等于战斗模型通过。
- [核实序列编码、编译与按键语义](issues/03-gse-evidence.md)：已按顺序复核固定提交，区分两种导出外壳、有效点击推进及暂停／重置例外；真实导入留到候选结果产出后。
- [确认项目目录与上游补丁维护边界](issues/04-project-boundary.md)：两个项目统一放在 `projects/`（项目目录）下；编译工具等环境可复用，各自的引擎源码、补丁、构建与程序独立，配装器改版不得被序列优化器覆盖或混用。
- [取得目标版本、角色与最小序列样本](issues/05-target-evidence.md)：邪恶角色与独立原版单目标基线核对通过；两条符文模型提示保留给支持范围审查，300 毫秒序列成绩和真实游戏样本尚未验收。

- [确定首版动作与饰品支持范围](issues/06-supported-actions.md)：自动识别规则已确认，具体清单由程序生成，首版药水关闭；三个被动模型疑点交接到执行模型验证，未认定已解决。
- [验证最小序列的导入与编译契约](issues/07-export-prototype.md)：用户确认离线原型结项，12 个样本与 8 个编码向量通过；真实客户端编码及导入未验证，仍后置到候选结果产出后。
- [验证输入控制与饰品的最小执行模型](issues/08-execution-prototype.md)：25 次引擎检查证明离线控制原型可行；被动效果沿用原生模型，保留上游提示；正式执行一致性与客户端验收已交接，不等于实机通过。
- [确定搜索评分、独立复测与停止规则](issues/09-search-contract.md)：用户确认统一动作与多起点局部搜索，采用分批加测、独立复测及节奏验证；无改善保留有效对照，数值预算交给下一票，尚未实现搜索。
- [确定计算预算、缓存与恢复契约](issues/10-runtime-contract.md)：用户确认 10 分钟及双进程单线程、立即取消保留完整结果；24 次测量支持双路试行，缓存与恢复验收已明确，未宣称功能已实现。
- [验证中文操作、诊断与报告流程](issues/11-terminal-prototype.md)：用户验收精简三步原型；初始仅导入与进度，结果就绪才显示复制区，调试留在内部；不代表真实搜索和游戏导入已完成。

## Not yet specified（尚待明确）

- 目标版本导出样本及实际游戏轨迹出现差异后，才可界定的最小修复和进一步实验。
- 输入控制原型的实际耗时瓶颈与扩展点限制；预算契约已有票据，具体性能改造尚无证据可拆。
- 操作原型反馈暴露的具体中文交互细节，以及最终拟分发组件引出的材料与数据准备缺口。

## Out of scope（范围外）

- 首版战斗药水及其选择开关、逐技能／逐饰品配置向导，依据[全自动生成决议](issues/06-supported-actions.md)后置；主动饰品自动识别与优化仍在范围内。
- P5（后续扩展）：固定多目标、手动辅助模式、鲜血及其他专精、多场景分布、复杂饰品、高级动作块；不阻塞本地图的单目标首版目标。固定多目标由[首轮范围决议](issues/01-first-validation-scope.md)移出当前最小闭环。
- 生存最优、装备或天赋推荐、自动按键、游戏进程读取、实时桥接、新游戏插件、在线服务和分享社区。
- 本轮正式产品实现、游戏目录写入、安装依赖、改变现有配装器计算行为、提交推送、合并或发布。用户在当前目录边界票中明确授权的项目搬迁及必要路径引用修正除外。
