# Sim2GSE 第二阶段：报告分组保存与任务状态保存优化

## Problem Statement（问题）

第一阶段已经优化读取。本次只优化完整报告保存和整份任务状态重复保存，不重复实施批量读取，也不实施提前批量核验历史成绩。已有十分钟搜索记录包含586次成功模拟、752次请求、166次本轮内存复用、2039次完整状态保存。该轮没有命中以前任务，历史预取在该轮收益为零。

## Solution（方案）

完整报告每12份一组，满组保存，正常结束、正常取消和预算停止保存尾组。突然崩溃或强制结束允许重算尚未保存的当前组，已保存结果继续复用。任务内部自动减少未变化历史的重复保存，保留累计预算、真实结果、读取能力和旧任务恢复能力。

这改变第二阶段的异常恢复粒度，不降低已保存结果的可靠性，也不把未保存成绩登记为持久化成功。

## User Stories（用户需求）

1. 用户希望同样计算量下减少保存开销，而不是用多算了多少批次替代同等工作量提速。
2. 用户希望普通完整报告的字段、数值、嵌套结构和类型保留，不另存长期完整报告副本。
3. 用户希望12份报告组成一组；正常停止保存不足12份的尾组。
4. 用户接受突然中断后重新计算未保存组，但希望此前已保存组、有效赢家和已消耗预算保留。
5. 用户希望恢复不借用只有摘要、没有完整已保存报告的成绩，也不静默吞掉保存错误。
6. 用户希望单条、多条、指定字段和通用逻辑表读取保持正确，调用方不需要文件路径、文件名或调优参数。
7. 用户希望任务状态变化较小时不重复写入完整历史；归档增长时内部选择适合的保存方式。
8. 用户希望现有任务和历史单报告记录仍能读取、取消和恢复，不进行全历史迁移。
9. 用户希望诊断开关、独立样本、候选身份、评分、随机条件、编译和导出保持原有行为。
10. 用户希望交付前获得优化1单独、优化2单独与两项组合的同等工作量实测，包含额外登记和停止收尾成本。

## Implementation Decisions（实施决定）

- 搜索报告分组隐藏在任务和结果中心适配内部；普通单次模拟不等待组成搜索报告组。组和报告都有稳定逻辑身份，通用存储不绑定游戏业务字段。
- 只通过已安装存储技能写入有类型的完整报告。发布采用先写临时文件、再替换，写入失败不覆盖此前成功组，不新增持久数据库平台。
- 分组内部数据量有明确上限；不用无界队列或额外常驻后台服务。正常取消及预算停止的尾组保存不启动额外模拟，不重置预算。
- 区分运行中计算结果和持久化成功结果。未保存组不能进入成功历史查询索引；含未保存成绩的待处理候选、归档和赢家指针不能形成可被恢复错误使用的持久检查点。
- 保存完整组后再确认持久化成功。文件已发布而身份登记未完成的中断窗口必须有可核验恢复方式，不留下重复逻辑记录，不重算已经可靠保存的组。
- 写组之前在现有任务状态数据库登记写入意图，只含组身份、请求身份及必要的小摘要，不保存完整报告副本；写组成功后一次提交成功摘要、组映射和安全检查点并清除意图。恢复时核验意图对应的组，已保存则复用，缺失才重算，暂时不可读明确报错。
- 历史查询按原请求身份核验完整报告，分组点读在引擎中筛选目标记录，不先向应用返回整组完整报告再筛选。既有单键完整组读取、批量读取、字段读取及全表查询语义保持。
- 自动优化任务状态保存；小变化更新小部分，归档变化不强制采用已证明可能退化的整份顶层归档重写。旧格式保留兼容读取，不删除用户历史任务。
- 存储暂时不可用保留已保存成绩并报告故障；只有缺失、确定损坏或身份不符走既有失效规则。预算和取消不得误判为坏缓存。

## Testing Decisions（验证决定）

- 最高真实用户入口固定为现有本地页面对应的任务创建、状态读取与取消请求；恢复沿用现有公开程序和命令行入口，不新增页面恢复接口。测试实际任务流程与结果中心，不以模拟返回的目标成绩代替生产计算。
- 从该入口覆盖完整组、尾组、正常取消、预算停止、强停恢复、发布与身份登记之间中断、保存失败、旧任务恢复及结果查询。
- 比较完整字段、类型、嵌套报告、统计、样本数量、候选选择及导出；不能通过删报告、改变样本或绕过核验取得提速。
- 第一阶段读取覆盖继续回归，尤其验证分组后的历史单报告和指定字段读取没有成倍退化。固定相同数据和工作量，分别记录准备、读取、保存和完整流程耗时。
- 性能比较包含优化前、优化1单独、优化2单独、组合四组。先在相同历史真实数据重放中验证分项，再以固定输入、随机条件、成功请求和样本数量执行完整任务对照；组合至少三轮交替顺序，计入尾组、登记及诊断成本。
- 保存总耗时和整轮用时分开报告；既有十分钟搜索本身不等于最终独立游戏验收，不提升证据等级。

## Out of Scope（不在范围）

提前批量核验历史成绩、重做第一阶段读取优化、原生引擎和搜索算法改造、样本及随机规则变更、全历史迁移、持久数据库后端切换、报告删减、额外完整报告副本、游戏自动部署、用户配置修改。
