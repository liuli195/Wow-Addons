# Retire the legacy Sim2GSE data tool

**Status:** ready-for-agent

## Problem Statement

用户已经决定弃用旧数据及旧数据工具，要求按现行开发流程移除旧工具。当前产品仍在正常任务入口中接入旧工具的容量准入、登记、租约、封口和数据库备份；只删除工具目录会留下不可运行的调用和过时参数。此次目标是完成这一次退役，保持角色级按键序列搜索与纯序列模拟可用。

## Solution

完整移除旧数据管理技能、其专属检查及产品接入，恢复现有普通任务路径。复用现有任务入口、任务检查点、成功批次缓存、任务互斥锁和取消恢复；不建立新数据中心、兼容层、迁移入口或替代管理框架。

本机旧数据、根标记、管理索引和对应任务回执已由用户另行批准删除，由独立清理任务执行。父任务已核实全部 12 项批准路径均不存在，含旧任务、根标记、管理索引和回执；本次仓库变更不操作任何真实数据目录。

## User Stories

1. 作为用户，我希望正常启动角色搜索无需旧管理配置或载荷预留参数，以继续通过现有中文界面取得搜索选中的导入文本。
2. 作为用户，我希望导入序列仍能经同一任务入口进行纯序列模拟，以取得如实标注的模拟结果。
3. 作为用户，我希望普通任务取消后保留完整批次和已用预算，并能在相同条件下恢复，以免重复计算或重置预算。
4. 作为用户，我希望现有成功批次缓存继续复用并核对原生报告身份，以免移除管理工具时误删搜索必需能力。
5. 作为用户，我希望坏输入、既有输出目录、任务占用和变化的恢复条件仍被拒绝，以保护原始输入、既有结果和并行任务。
6. 作为用户，我希望界面只显示真实产品阶段和结果，不再等待已经退役的登记、备份或封口步骤。
7. 作为维护者，我希望旧工具、专属测试、验证登记、启动参数和当前使用说明同步退役，以免留下断裂调用或仍可使用的假象。
8. 作为维护者，我希望正式规格按现行预览及确认流程同步更新，历史验收证据保持其原始含义，以便核查此次退役与既有产品能力的区别。

## Implementation Decisions

- 采用 Full（完整）流程。此次是数据管理能力退役及公开参数删除，存在破坏性与跨任务前置条件，不满足 Fast（快速）路径的前提。
- 以一个可独立验证的纵向票完成退役；工具删除、调用移除、专属检查清理及当前文档必须一起通过验收，不分成中间状态不可运行的横向票。
- 删除旧数据管理的运行实现、默认配置和技能说明，删除其专属测试及受管产品集成测试。
- 同步移除产品的管理器加载与调用、受管分支、旧配置/预留参数、管理回执读写与管理状态输出。旧命令行参数不再接受，不静默解释为新行为。
- 保留普通任务锁、输入校验、原始输入副本、结果发布、任务检查点、成功批次缓存、预算和恢复身份核对；搜索、模拟、导入与导出算法不变。
- 在精确旧数据清理复核后直接退役，不新增旧根识别守卫、历史兼容或自动迁移；未指定的其他数据根不在本次操作范围。
- 同步清理旧工具专属验证登记、测试发现约束、界面阶段、当前运行说明及已退役的忽略项。保留历史变更和验收记录，不以删历史证据追求全仓关键词为零。
- 正式规格仍要求旧能力，必须在实施、验证和独立审查通过后，按 MySpec（自有规格）流程准备退役预览；本阶段及实施阶段不改正式规格。

## Testing Decisions

- 目标产品是 Sim2GSE 角色级按键序列优化器。最高层级真实用户入口为现有中文三步界面及其启动命令；直接文件任务命令用于启动、取消后的恢复和错误反馈。
- 公开测试接缝沿用真实任务命令与 HTTP（超文本传输协议）服务：提交角色、读取真实进度、取得候选或导入模拟结果；恢复通过同一任务命令执行。不开新测试框架或新生产测试接口。
- 红绿检查从公开入口证明旧参数退役且普通任务不再依赖旧工具；成功路径覆盖普通搜索与导入模拟。检查正常输出中无旧管理阶段或状态，并确认运行时不存在旧管理器调用。
- 保留并复用现有搜索、共享缓存、取消恢复和锁的回归；验证同条件恢复沿用预算与完整批次、重复任务复用成功缓存，不把损坏或部分报告当作成功。
- 失败/恢复路径覆盖坏输入及既有输出目录不被覆盖、活动任务拒绝另一执行者、输入/引擎/规则/模拟配置变化拒绝续跑、取消后恢复；依赖缺失或原生失败仍准确失败，不伪造导出或成绩。
- 现有合成生产替身可用于云端定向诊断，但不能冒充 Windows（视窗系统）锁、固定引擎、浏览器或实际游戏验收。最终按固定基线运行统一验证，只有 status 为 passed 且 checked 非空才算正式通过；当前配置变化会选择全部适用检查。
- 本次云端环境尚无仓库固定 Windows 产品引擎与完整验证依赖。能在云端完成的实现和诊断先在云端完成；原生平台验收按实际可用执行环境另行取得证据，不以跳过、伪造平台或扩大超时替代。

## Out of Scope

- 设计或实现新的数据中心、数据库架构、归档、清理、迁移、后台任务或通用存储接口。
- 修改搜索、评分、模拟、GSE（高级按键序列插件）导入导出、默认预算、成功缓存或检查点策略。
- 删除真实数据、解除其他数据根的保护、改动用户机器配置或修改其他进行中的任务。
- 提前应用正式规格、推送、创建或合并 PR（拉取请求）、发布或部署。
