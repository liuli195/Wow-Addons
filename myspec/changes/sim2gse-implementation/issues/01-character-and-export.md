# 真实角色到最小导出

Status（状态）: open
Triage（分拣）: ready-for-agent
Assignee（领取者）: unassigned

## Parent

[开发需求](../spec.md)

## What to build

从单个真实角色导出进入同一本地任务入口，自动取得角色与可按动作，形成简单合法序列并生成可核查的离线导入文本。输入、动作集合、原生参考和导出结果可由一次任务追溯，不依赖人工白名单或编辑研究脚本。

## Blocked by

无其他实施票；仍需开发流程的干净工作起点、必要工具可调用与“开始开发”授权。

## Acceptance criteria

- [ ] 从声明的任务入口输入用户真实角色，当前装备、天赋、中文和注释保真，背包候选不替换已装备物品。
- [ ] 自动识别统一主动动作，包含已支持的主动物品；被动效果保留原生处理，首版无药剂选择。
- [ ] 多角色、外部引用、输出覆盖、不支持专精与主动动作在模拟前明确报错；不静默删除能力。
- [ ] 固定身份的独立原生引擎产生真实参考结果；简单候选完成真实编码往返和上游编译入口校验，不假称已通过游戏导入。
- [ ] 入口可从中文空格路径读入真实文件，导出报告区分参考成绩与未受控模拟的候选，未通过检查不输出假字符串。
- [ ] 接入本项目必要构建与校验，不安装无关工具，不修改配装器；把原型中的固定样例与生产识别规则分开。

## Testing Decisions

最高入口：拟建的本地任务公开入口，输入角色后返回任务结果及失败原因；本票必须提供可运行调用方法，供后四票原样延伸使用。先从该入口验证缺失行为，再实现；覆盖 T01—T03、T14、T21。底层参考[动作规则](../../../../docs/sim2gse/action-capabilities.md)、[离线导出原型](../../../../docs/sim2gse/export-prototype.md)，不能把历史原型断言当成本票通过。

## Specification coverage

`sim2gse-character-input` 全部需求；`Sim2GSE reveals only available export results` 的编码失败场景。本票仅交付最小离线导出，不实现搜索，也不要求安装游戏插件。

## Completion evidence

待实施后记录入口命令、受检身份、真实输入与产物、失败／成功检查及仍待验收项；当前未实施。
