# 三步界面接入真实计算

Status（状态）: open
Triage（分拣）: ready-for-agent
Assignee（领取者）: unassigned

## Parent

[开发需求](../spec.md)

## What to build

将用户已验收的三步交互接入第三票的同一真实任务入口，用户粘贴角色、点击开始、查看实际进度，结果就绪后复制文本。本票交付可运行界面，不制作安装包或额外发布系统。

## Blocked by

[自动搜索、复测与恢复](03-search-and-validation.md)

## Acceptance criteria

- [ ] 初始只展示角色输入和进度区域，不显示药剂、调试场景、验证明细或资源配置。
- [ ] 真实输入点击开始驱动第三票程序，进度来自真实事件，移除原型定时器和模拟成功事件。
- [ ] 真实结果到达才展示复制区，复制文本与受测候选相符；修改输入或重新运行隐藏并清空旧结果。
- [ ] 空输入、不支持条件、引擎失败和导出失败均以简短中文说明原因；无假字符串，无不实成功状态。
- [ ] 取消与恢复能力仍由已确认内部入口保留并可验收，不把开发按钮重新放回日常页面。
- [ ] 在目标本机含中文、空格路径实际完成输入、计算及输出，不要求管理员权限，不自动上传角色或写入游戏目录。
- [ ] 提供真实启动方法；不以便携包、安装器、自动更新或不依赖任何现有环境作为额外验收要求。

## Testing Decisions

最高入口提升为实际三步界面，贯穿真实引擎到可复制结果；复用前三票同一业务与失败契约，不建立第二份业务逻辑。覆盖 T01—T02、T18、T22，参照[已验收原型](../../../../docs/sim2gse/terminal-flow-prototype.html)的交互顺序，不把原型自身测试当成产品测试。

## Specification coverage

`sim2gse-user-workflow` 中简洁界面、实际进度、按需复制、本地运行要求；验证状态仍分别保存在内部记录。

## Completion evidence

待记录实际启动入口、完整界面操作到原生结果的证据、中文空格路径及失败提示检查；当前未实施，不强制打包。
