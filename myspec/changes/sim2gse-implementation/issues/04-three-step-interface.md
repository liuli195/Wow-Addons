## What to build

将用户已验收的三步交互接入第三票的同一真实任务入口，用户粘贴角色、点击开始、查看实际进度，结果就绪后复制文本。本票交付可运行界面，不制作安装包或额外发布系统。

## Acceptance criteria

- [x] 初始只展示角色输入和进度区域，不显示药剂、调试场景、验证明细或资源配置。
- [x] 真实输入点击开始驱动第三票程序，进度来自真实事件，移除原型定时器和模拟成功事件。
- [x] 真实结果到达才展示复制区，复制文本与受测候选相符；修改输入或重新运行隐藏并清空旧结果。
- [x] 空输入、不支持条件、引擎失败和导出失败均以简短中文说明原因；无假字符串，无不实成功状态。
- [x] 取消与恢复能力仍由已确认内部入口保留并可验收，不把开发按钮重新放回日常页面。
- [x] 在目标本机含中文、空格路径实际完成输入、计算及输出，不要求管理员权限，不自动上传角色或写入游戏目录。
- [x] 提供真实启动方法；不以便携包、安装器、自动更新或不依赖任何现有环境作为额外验收要求。
