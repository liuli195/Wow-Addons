# 数据中心市场安装消费适配

Status: ready-for-agent
执行状态：门禁一已确认，包括真实数据性能回归；当前分支实施及隔离验收已获准。正式规格应用、交付和最终本机迁移仍待门禁二。

## Problem Statement（问题）

Sim2GSE（模拟搜索工具）当前从旧用户技能目录链接加载数据中心。个人技能改由市场安装后，如果先删除旧链接，工具将不能启动数据读写。

## Solution（方案）

保持既有数据中心存储与查询契约。用户先安装市场插件，再让 Agent（代理）从实际技能入口把目标仓库接好：创建一个本机项目稳定目录入口，指向已安装技能。所有接入的工具和命令共用这一连接，正常运行不需要代理在场、用户填路径、启动方传路径或额外定位工具。不是要求每个程序运行时扫描客户端市场。消费者验证通过前保留旧用户技能链接。

## User Stories（使用要求）

1. 用户改用市场安装后仍能从现有搜索工具入口启动并执行逻辑表读写。
2. 代理切换或更新数据中心安装时同时刷新仓库接入记录，新进程使用选定的安装内容，保持数据读写结果一致；未刷新或失效时明确提示重新接入，不能假称自动跟随。
3. 来源缺失、未启用、重复冲突或资源损坏时，工具在模拟开始前提供可操作错误，不偷偷加载过期缓存。
4. 用户旧数据、文件名无关的逻辑表查询、既有批量与性能优化保持。
5. 用户安装插件后让代理接入仓库，所有已对接工具和命令即可使用；接入过程由技能指导，不需要额外安装定位工具或由用户手动设置位置。

## Implementation Decisions（实施决定）

- 安装与接入分开：代理读取技能实际位置、核验所需功能和依赖，在目标仓库被忽略的本机目录创建一级目录联接作为稳定入口。关系由该入口的实际目标表示，不另建 JSON 安装清单；本机位置不提交到共享源码，换机器或新检出时重新接入。
- 项目入口只表示仓库选用的技能，不是第三条插件发行渠道。代理确定唯一选择，冲突先报告；所有已对接程序只使用同一项目入口，不查询客户端、不猜缓存目录。
- 仓库共用入口直达同一安装包的现有脚本，不复制数据中心核心实现、不新增需单独安装的程序、不为每次读写启动进程。普通命令也通过同一入口调用；移除入口只能删除链接本身，必须保留安装目标。
- 技能须包含初次接入、重复接入、依赖核验、更新／切来源重接入及失效诊断步骤；本次通用契约面向所有消费者，Wow 工具为首个完整验收样本。
- 接入薄层由数据中心技能包直接提供，代理按说明调用而非为仓库生成薄层实现。现有消费者一次性改用共用项目入口，运行与接入仍不需另装 NPM 包或外部定位工具。
- 版本切换后的验收针对新进程及新任务启动；已运行进程须重新启动才加载新实现，不要求每次读写查安装路径或即时热加载。数据中心无需像自有规格和构建验证那样在 CI（自动检查流程）自举，保留市场发行。
- 原目录链接仅可作为迁移期兼容入口，最终验收必须证明链接移除后仍可使用市场安装；不以保留永久链接替代迁移。
- 与技能仓库同一变更配套，独立分支与交付记录；消费者通过先于最终清理。

## Testing Decisions（验证决定）

- 最高入口使用搜索工具既有数据中心可用性检查及实际写入／查询路径；隔离数据目录，不修改历史报告。
- 覆盖代理初次／重复接入、多工具共用、独立命令、市场正式与开发重接入、没有旧用户技能链接和运行时位置参数、没有额外定位安装、项目入口缺失或失效、冲突／损坏来源；实际两端安装适配完成后立即冒烟。
- 通过既有构建与验证入口运行受影响检查，不重跑十分钟性能模拟；本次不涉及实际游戏验收。
- 不新增 CI（自动检查流程）安装数据中心市场插件、NPM 包或运行代理接入的要求；保留已有相关源码检查，适配后的隔离测试不得依赖维护者本机链接。
- 用户追加性能回归硬门槛：原已交付实现与新共用入口同环境、同冻结真实数据、同工作量交替重复对比；分别测首次加载、热态进程内读写和独立命令。覆盖写入／替换、单键与多键完整／字段／筛选读取、通用聚合／多表查询、12份嵌套报告及大量平坦记录，核对数量、字段、结果与类型。
- 最终报告每项前后耗时、中位数、离散范围、变化比例、重复次数及样本规模；出现超出重复测量波动的稳定退化须修复重测，通过前不交付，不以减少工作量或其他场景收益抵消。无需再跑与安装接入无关的十分钟 SimC 模拟。

## Out of Scope（范围外）

改变数据存储格式、查询性能策略、搜索算法、SimC（模拟引擎）参数及游戏文件；门禁一前生产修改；门禁二前正式规格应用或交付。
