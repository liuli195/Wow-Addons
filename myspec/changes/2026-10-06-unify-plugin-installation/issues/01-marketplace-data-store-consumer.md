# 01：市场数据中心安装可被搜索工具使用

**What to build（交付内容）：** 代理从已安装数据中心技能入口把仓库接好，所有对接工具和命令共用一个本机项目稳定目录入口；搜索工具通过已有逻辑表读写入口工作，正常运行无需代理传位置或额外安装定位工具。

**Blocked by（前置任务）：** 技能仓库同名变更 01、02；执行前通过门禁一。

**Status（状态）：** ready-for-agent

- [ ] 正式与开发安装均可加载，原链接缺失仍能通过公开入口执行隔离样本写入和查询。
- [ ] 代理初次及重复接入行为明确，使用被忽略的本机项目稳定目录入口，不额外建立安装清单，不提交本机绝对路径、不复制核心源码；所有已对接工具和命令共用同一来源。
- [ ] 仓库连接由技能内现成薄层完成，不由代理临时生成；原消费者仅做一次调用适配，无新 NPM 包或额外安装器。
- [ ] 运行时不要求用户填路径、启动方传路径或额外定位工具；来源明确、可核对，不查客户端缓存或猜版本；缺失与冲突明确拒绝。
- [ ] 代理更新或切来源时刷新连接，独立命令与进程内读写使用新来源；位置失效明确提示重接入，不静默选其他来源。
- [ ] 缺失或损坏技能在模拟开始前报错，不静默回退到过期来源。
- [ ] 原逻辑表契约、文件路径无关的查询、存储格式、搜索策略和原数据保持。
- [ ] 原实现与新入口同数据、同环境、同工作量性能回归通过，冷启动与热态分开记录，覆盖全部既有读写方式并重点核对12份嵌套报告；稳定退化解决后才交付。
- [ ] 受影响统一检查、真实安装冒烟和独立审查通过，记录哪些验收未运行。
