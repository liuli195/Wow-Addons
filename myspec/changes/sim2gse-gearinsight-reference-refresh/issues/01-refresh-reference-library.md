# 01：从插件参考库稳定更新可训练材料

**What to build（交付内容）：**用户通过一个手动命令读取新版邪恶死亡骑士参考库，看到原始和清洗后差异，在隔离数据中心完成四条件准备；检查成功后可整批接替明确管理的旧来源，旧证据及既有成果保留。首轮正式来源切换等待门禁二。

**Blocked by（阻塞任务）：**无前置票据；门禁一待确认。

**Status（状态）：**ready-for-agent

- [ ] 最高公开刷新命令支持明确插件位置、只读主库更新计划与隔离验证，复用已有材料/准备入口。
- [ ] 冻结并核验插件版本、源文件、解析规则、登记基线和真实评价条件；游戏安装只读，源变化立即停止。
- [ ] 保留原始顺序、重复出处、人物、场景和未知字段；统计原始记录、合并数、合法/拒入原因及四组实际输入数。
- [ ] 新版邪DK材料经当前一键一技能配置、动作映射、独立爆发分离、角色适配、合法性与完整行为去重，准备和编译可核验。
- [ ] 首次仅精确接管旧28条参考库来源；另2个人工规则件和其他材料不受影响，原件/修订不一致不猜测匹配。
- [ ] 相同资料重复更新不增条目；新版成功后一次原子切换本接入器管理活动集，旧来源仍可查且不撤回历史成果。
- [ ] 缺文件、未知格式、空或无有效新版、并发变动、解析/存储失败均保留旧活动集，不产生半新半旧状态。
- [ ] 公开命令检查覆盖成功、重复、换版、精确接管、失败及中断，统一验证接入已有测试发现范围。
- [ ] 新版真实材料隔离验证双英雄×实际单目标/五目标四组，整批300秒、1000次请求迭代上限不逐组重置；超限留证。
- [ ] 输出主来源库具体更新清单，核验主库及已发布成果未变；未训练、不发布代表、不跑正式搜索。
- [ ] 主代理串行实施、独立审查和统一验证完成后准备规格及交付门禁；不提前应用正式规格或处理旧预览锁。
