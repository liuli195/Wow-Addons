## What to build（要做出什么）

**把整套改动放进真实战斗环境里验一遍** —— 这一票不写功能，只出证据。目标是回答唯一那个真正重要的问题：

> **在一地 AOE 特效里，我到底能不能一眼看清血弧、符能弧、符文格和准星？**

顺带把既有行为的回归扫一遍：缩放、专精切换、进出本、登录恢复、鼠标穿透、框架层级。

## Acceptance criteria（验收条件）

- [ ] 在**有 AOE 特效的战斗场景**里，三条资源与准星**一眼可辨**（附证据）
- [ ] 在**明亮地面**（雪地／沙漠）与**昏暗地面**（洞穴）上同样可辨
- [ ] 阴影浓淡从最重调到 0 的全程，元素本身**始终不受影响**
- [ ] 缩放 0.5–2.0 全程：阴影与条**对齐**，且**不发糊**
- [ ] 切专精、进出本、登录之后阴影**仍在**
- [ ] 阴影层**不吃鼠标**（按住右键转视角不被挡）
- [ ] 框架层级设置对阴影层同样生效（调到窗口之下时阴影不浮上来）
- [ ] 证据**记录在案**（截图或录像，注明场景与设置）

## 备注

- 本机验收**不进统一验证**（仓库规则：本机验收不得进入 PR 统一验证）。
- 视觉判断由**用户**做 —— 工具链的截图通道不可靠，数值断言归自动化，眼睛归人。

## Comments（讨论）

**2026-09-19 进度：部分完成，本票保持 open。**

已实机确认的：

- 阴影**未引入可见性 bug**（用户原话：基本看起来没有碰到可见性的 bug）
- **缩放 0.8 与 2.0 两档**：边缘锐利且无锯齿（这是本次实机暴露并修掉的主要问题）
- 明亮地面与昏暗地面**未单独验**，但分离度的核心问题（边缘锯齿）已解决

**尚未做的**（本票要求、但还没验）：

- 有 AOE 特效的**真实战斗场景**里三条资源与准星是否一眼可辨
- 阴影浓淡从最重调到 0 的全程，元素本身是否始终不受影响
- 切专精、进出本、登录之后阴影是否仍在
- **框架层级**设置对阴影层是否生效
- 证据按要求**记录在案**（现有的是排查过程中的截图，不是本票要求的场景化证据）

**另外留一条交付时定夺的偏差**：本票所属规格的用户故事 21 要求「阴影不能溢出到框外」，
实测三条阴影贴图的**可见内容**超出 128 单位的拖动框最多 **3 个设计单位**——超出的是
不透明度 ≤12% 的尾巴，可感知的部分在框内。这是设计本身决定的（环半径 54 ＋ 条粗 7.8 ＋
阴影扩散已大于框的半宽 64），软阴影的尾巴不可能既贴合硬框边又不出硬边。
