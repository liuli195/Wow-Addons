# 03：阴影设置：全局一项（颜色 ＋ 浓淡）

Triage（分拣）: ready-for-agent
Status（状态）: ready-for-agent
Assignee（领取者）: 主代理
Parent（来源）: [Crosshair HUD 阴影图层规格](../spec.md)
Blocked by（前置事项）: 02（阴影层得先在游戏里看得见）

## What to build（要做出什么）

**让玩家能自己调阴影的颜色和轻重** —— 默认就已经是最重的一档，只能往轻调。

- 设置页新增**一个全局**阴影项（**不是**每个元素各一套）：一个色块 ＋ 一个自带的不透明度滑杆，与既有的颜色格**同一种形态**（颜色和它自己的浓淡显示在同一格内）。
- **颜色只有自定义色，不提供职业配色来源** —— 与既有的「背景色只有自定义」规则保持一致。
- **浓淡取值 0–100，默认 100（最重）**。游戏中把它作为阴影纹理顶点色的 alpha。
- **配置键写进插件自己的存档**，不写进 EUI 的存档。
- **接进状态表**：由配置解析出阴影色与浓淡，投影到每个元素的阴影色/浓淡上（渲染模块拿到的仍是逐元素的状态表，契约不变）。
- **既有两条「末行留白」的布局断言会因格子数变化而翻面 —— 这是预期的红灯，不是回归**，随本次改动一并更新。

## Acceptance criteria（验收条件）

- [ ] 设置页出现阴影项，**颜色与浓淡同处一格**
- [ ] 改颜色：游戏里阴影**当场**变色
- [ ] 改浓淡：游戏里阴影**当场**变浓变淡
- [ ] 浓淡调到 **0**：阴影消失，而**元素本身毫发无损**
- [ ] 默认装上就是**最重档**，且**无法调得比默认更重**（默认即上限）
- [ ] 配置存进插件自己的存档，EUI 的存档里没有新增键
- [ ] 配置格子清单的测试断言已更新并通过
- [ ] 全局只有**一处**阴影设置，不是每元素一处

## 备注

- 阴影设置是**全局**的，但状态表仍是**逐元素**的 —— 这个不对称是刻意的：配置简单，渲染契约统一。
- 设置页现有结构是「逐元素一组 ＋ 一个非元素的『常规』区」。阴影是全局项，**放进非元素区**，不要把逐元素的结构撑开。
