# 发布已合格的部分训练成果

## Problem Statement
一条路径预算未收敛使整个批次在入选发布前退出，已可靠完成的其他路径不能进入起点代表库。

## Solution
沿用现有发布算法，从同条件completed记录选代表；个别失败不阻断合格成果发布，但原失败记录与整体错误退出码继续保留。

## User Stories
1. 用户可复用已完成且通过复测的训练成果，不必等待所有路径成功。
2. 用户仍能看到失败及未完成状态，不会误认为整批成功。

## Implementation Decisions
调整已有发布与未覆盖报错的顺序；未收敛使用既有 BudgetExceeded，候选完整性 ValueError 保存失败证据后透传既有批次 failure 通道，禁止发布；不新建CLI、存储、调度或筛选机制。取消、持久化异常和完整身份验证失败仍不得绕过，无合格成果不清空旧入选，其他共享范围不变。

## Testing Decisions
公开run/list：两条独立路径一成功一预算未收敛，退出码仍2、失败保留、成功入选；混合成功与损坏检查点必须保持旧入选并返回原完整性错误；清空测试入选后限定成功材料零模拟重建。复用已有全部失败保旧、发布失败恢复、缺身份拒绝测试。

## Out of Scope
不加预算、不重跑成功任务、不改变收敛标准、不改模型或三元共享范围。
