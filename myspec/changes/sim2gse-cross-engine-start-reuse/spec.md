# 跨引擎复用训练起点

## Problem Statement（问题）
引擎升级后，可靠保存的训练代表和最终训练冠军被当前引擎等值筛选拒绝，合法程序无法重新成为起点。

## Solution（方案）
正式移除起点消费处的目标引擎等值门槛。只复用程序，按当前角色适配、检查、编译和重新评分；来源引擎与历史复测凭据继续严格自洽核验。

## User Stories（用户故事）
1. 用户升级引擎后仍可使用已训练的合法起点，避免训练投入丢失。
2. 用户可追溯来源引擎、程序及历史成绩，当前成绩不被旧成绩冒充。
3. 用户获得按当前角色能力适配的程序，不能适配的起点仍明确拒绝。
4. 用户遇到损坏或不一致的来源报告时仍得到排除原因，不静默放行。
5. 用户恢复任务时沿用冻结快照，不因训练库变化重新选择。

## Implementation Decisions（实施决定）
- 训练代表和最终训练冠军统一取消目标引擎相等筛选。
- 冠军读取使用来源清单引擎核验原条件与复测报告，不改训练条件、缓存或语义版本。
- 保留既有单个历史冠军排序；历史DPS只作来源选择参考，不表示跨引擎成绩可直接比较。
- 职业、专精、场景、模板及非引擎兼容条件保持；不新增存储结构或兼容框架。

## Testing Decisions（测试决定）
使用已确认的现有网页双场POST创建及GET结果接缝，覆盖跨引擎代表与冠军进入当前搜索和重评分、来源数据不变；沿用冠军读取接缝覆盖错误来源报告拒绝。定向回归既有适配、损坏凭据和冻结恢复行为。

## Out of Scope（范围外）
不改选择模型、训练算法、缓存身份、历史排序策略、正式角色冠军、模板或其他语义兼容条件；不运行真实训练或自行合并主干。

## Further Notes（备注）
这是用户批准的正式产品修复，不是MVP。现行正式规格关于代表引擎匹配及冠军完整条件的描述需在统一交付阶段更新，本次不修改正式规格。
