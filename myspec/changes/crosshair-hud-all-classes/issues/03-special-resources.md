## 验收条件

- [ ] 核对全部专精资源清单，明确基础工具缺少参照的特殊资源，不按无资源跳过。
- [ ] 从同版本暴雪资料核实特殊资源的读取、上限、显示条件和战斗限制。
- [ ] 在原顶部职业资源区域显示连续条或计数格，沿用职业资源开关、颜色和整体定位，不增加独立元素、设置页或拖动框。
- [ ] 主资源弧继续显示主资源；特殊资源只改变原职业资源区域的画法。
- [ ] 可参考现有原生绑定处理受限数值的方式，但不套用凝固之血量程或读数路径；具体显示方式有目标版本依据。
- [ ] 仅显示适用资源；专精或形态变化后清除旧资源。
- [ ] 暂时读取失败时不显示错误身份或臆造值，复用既有刷新恢复，不新建通用重试系统。
- [ ] 使用有来源的独立参照测试数量、获得消耗、显示条件与往返切换。
- [ ] 本任务行为及真实绘制检查立即接入统一验证执行命令。
- [ ] 单独记录真实游戏验收及尚未覆盖的特殊机制。
