# 搜索能力正式收尾

Status: in-progress（开发门禁已批准，三票已实现；最小收尾中，必要 Windows 验证已完成，待交付门禁及 CI）

2026-10-21 收尾决策：用户接受本次曲线性能观测，明确不再追加性能实验。原严格置信门槛未得到证明，不改写为通过；实际数字和适用边界见 report.md 与 summary.json。主干仅保留正式能力、必要回归和精简证据，实验代码及大型研究材料从候选树排除。正式数据中心、训练成果和运行时规则不清理。

## Problem Statement

既有实验没有证明规则化起点或预训练选择器具有稳定净收益。用户要求保留基础修复，默认使用旧搜索和旧原生起点；两个探索能力各自默认关闭；加入默认关闭的轻量曲线诊断，并将已讨论的新早停正式化。静态快照量化未测出稳定提速收益，用户已确认保留现状，不为其简化或加开关。

## Solution

保留一套共用评分、归档、恢复及训练成果复用能力，在既有配置中提供三个默认关闭的布尔选项。规则起点与选择器可独立组合；新早停与任何探索开关无关。曲线按需记录真实时间下的已知成绩，结束后离线绘制，不增加评分或原生追踪。实验临时实现不进入生产调用路径。

## User Stories

1. 作为用户，我希望缺省走旧起点和旧候选搜索，而不是空模型的新搜索。
2. 作为用户，我希望规则起点和选择器分别可开关，四种组合都可运行。
3. 作为用户，我希望关闭探索能力时不加载模型、不学习、不做选择器专用诊断。
4. 作为用户，我希望预训练遵循同一配置，选择器关闭仍训练起点并保留旧模型。
5. 作为用户，我希望既有按专精、英雄天赋、目标类型保存的成果继续可读可用，不因关闭规则起点丢失训练冠军。
6. 作为用户，我希望规则起点开关不暗中改变正式首次爆发时点。
7. 作为用户，我希望任一分支经验证有效晋升都算进展，避免仍有改善时仅因未胜全局冠军而早停。
8. 作为用户，我希望正式搜索保留按实际有效分支数的全局早停阈值，训练保留两轮无改善和无600秒总硬截断。
9. 作为用户，我希望可按真实秒数比较不同搜索的DPS曲线，而不是扣除诊断开销后的预算时间。
10. 作为用户，我希望曲线默认不产生采集、写盘、绘图及额外模拟成本。
11. 作为用户，我希望战斗伤害曲线复用已有时间桶，缺数据时明确说明，而不是自动额外运行诊断。
12. 作为用户，我希望保留已有训练资产和10×2本机配置，不把实验产物导入正式数据中心。
13. 作为用户，我希望实现保持最小，不复制优化器、不增加引擎变体或依赖实时绘图框架。

## Implementation Decisions

- 工作树沿用云端现有仓库，分支 codex/gse-validation-slim；开发固定基线 65b22c60ea6afe49c769ae3808f859c0644605eb。主干最终交付差异另需依据届时已核验主干审查，不混用两个基线。
- Full 路径，三张纵向票串行实施，全部完成后独立 Standards/Spec 双轴审查。开始实施前展示完整门禁并确认。
- 共用配置载入扩展 [search] 区域：rule_initialization_enabled=false、adaptive_selector_enabled=false、search_timeline=false。显式调用/CLI参数优先于配置，缺省参数不得覆盖配置true；非法类型明确拒绝。物理模拟配置保持独立。
- 两个算法开关进入任务冻结及训练路径身份；曲线选项不进入候选、评分、缓存身份。旧未完成任务不得由新增默认值静默改算法，不能兼容恢复时明确拒绝并保留已存结果可读。
- 共享三条件、规则绑定与原生静态身份上下文独立于生成起点。兼容读取历史上下文，不通过粗暴更改全局算法常量使全部历史训练冠军失效，也不放宽必要评分证明。
- 预训练逐材料保持输入材料本身为训练起点，不因规则起点开关替换材料或额外追加路径。
- 规则起点OFF不调用生成函数；ON仅替换既有一个原生起点名额，不增加额外路径，且不原地修改正式爆发计划。
- 选择器OFF恢复旧随机算子、随机状态和旧反馈生成分支，共用当前评分/筛选/晋级及去重保存修复。旧算法必要的位置修复观察仍保留，不能把它误删为选择器诊断。ON才进入现有规则诊断池和LinUCB及反馈结算。
- 模型依赖延迟加载，并以最小独立依赖清单支持可选安装；未安装时OFF可用，显式ON提示缺依赖，不自动安装或静默降级。
- 新早停直接在共用晋级统计点实现：全局晋升或非起点的有效分支晋升设置本轮有改善；完整无改善轮才累加。正式阈值沿用实际有效分支数，训练阈值沿用两轮。无每分支新计数器、无新早停参数、无源码字符串替换。
- 曲线用独立单调墙钟；在已有归档成绩更新、搜索停止、结果保存等节点记录小事件，不扫描历史、不增加定时线程、不扣除自身耗时。独立模块仅在开启时加载。
- 搜索结束后离线按10秒网格取当时最后已知值，支持多条同口径运行同图。首个结果前留空；分数修订如实保留；停止、失败、截断及恢复分段明确标记，禁止未来回填或伪装持续搜索。
- 有界事件存储采用简单内部上限，达到上限标记截断，不停止业务、不新增用户配置或复杂队列。
- 战斗伤害图优先读取原生已有1秒 timeline_dmg 桶，保留原生统计口径，不另加宠物造成重复，不强行归一为最终评分；缺少时间桶就说明缺失，不自动补模拟。
- 绘图在任务结束后，优先标准库生成可离线查看的简单HTML/SVG；不新增实时前端、通用事件总线、第三方绘图库或生产数据库。
- 原生静态快照及既有引擎构建种类保持不变；不得把临时快照关闭门控、Linux实验适配、固定5秒或清空资产等实验策略加入产品。
- 已有训练清洗去重、三条件范围、部分成功落盘、动态训练停止、跨引擎起点复用及本机10×2配置不回退。

## Testing Decisions

- 最高真实用户 Interface（接口）及 Seam（接缝）：搜索 run_task/read_task/resume_task 与现有页面双场链；预训练 prepare/run/list；配置及CLI公开入口。原生模拟是共用 Module（模块），不为开关增加新引擎 Adapter（适配器）。
- 在公开入口做四组合最小矩阵与CLI配置优先级；OFF检测无generate/模型访问/选择器诊断旁路，ON保留已有真实集成测试，不以仅mock分支代替产品验证。
- 验证三条件成果和4条代表/冠军复用、训练无600秒总截断/连续两轮、部分成功保存不回退；模型文件在OFF前后不变。
- 新早停覆盖分支晋升但未超过全局、全局晋升、晋级统计失败、初始起点、未完成轮、阈值及训练两轮，不把新增计数替代原定义。
- 曲线测试包括真实时钟、默认无文件/事件/额外仿真、配置覆盖、历史不回填、成绩修订、停止/取消/恢复/截断、多图口径；诊断异常不能破坏有效业务结果。
- 性能三臂同算法比较：变更前可比旧路径基线、变更后全关、变更后仅曲线开。先固定输入和工作量交错配对，后代表性真实限时搜索。无诊断基线只做外层计时与完成后必要证据，完整曲线另做对称观察，不能暗开采集。
- 默认关闭以无可测退化为目标。建议同算法默认关闭增量耗时的配对单侧95%上界不超过0.5%，曲线开启相对关闭不超过1%，并报告相对基线总影响、吞吐、尾部与噪声；这是门禁待冻结的预算，证据不足不得记为通过，也不承诺数学零开销。首批性能计时总预算10分钟，先固定工作量，再至多60秒级代表性限时冒烟；不自动扩为多小时或完整600秒矩阵。若检测能力不足，报告不确定并另作取舍。
- 云端开发与可行验证优先；真实Windows调用、硬件性能及平台验证需要本机或匹配CI时明确其证据范围。本机只做必要验证，不把云端环境失败标成通过。

## Out of Scope

首次爆发时点联合搜索/自动调参、重新设计4条代表选路、删除训练资产、跨专精共享、静态快照简化/缓存、新并发策略、全量重训、任意主干直推或正式发布。

## Further Notes

正式规格当前把 diagnostic_logging 定义为所有诊断的总开关，与独立轻量曲线冲突；需要形成明确规格候选，说明旧总开关仅控制详细诊断，轻量曲线单独显式授权。开发阶段不提前修改 myspec/specs。

实验记录不删除。最终合并清单应排除临时原生门控、实验适配与大产物；必要简短结论、正式测试和正式功能实现可纳入。具体合并与发布仍在验证及交付门禁后处理。
