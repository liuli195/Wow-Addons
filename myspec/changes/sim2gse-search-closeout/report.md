## 研究结论

### 旧搜索、新搜索、预训练选择器

36次运行覆盖两英雄、单体/5目标、每场景3种子，共12个配对条件。三组都不带训练起点、冠军或历史评分缓存。
A=旧搜索，B=新搜索冷模型，C=新搜索加预训练选择器。场景均值 DPS：

| 场景 | A | B | C |
| --- | ---: | ---: | ---: |
| 天启骑士单体 | 101675.70 | 101855.40 | 101797.61 |
| 天启骑士5目标 | 313328.16 | 307782.16 | 298261.09 |
| 萨莱因单体 | 95417.39 | 93544.70 | 93016.21 |
| 萨莱因5目标 | 310397.78 | 297068.50 | 298030.24 |

旧搜索在四场景中三场更好，预训练选择器没有展示稳定净收益。因此旧方案默认，新能力仅供显式探索。每场景只有3种子，未独立复测最终冠军，不构成跨角色总体优劣证明，也不否定训练起点本身的价值。

### 首次爆发 MVP

144个固定评分单元，测试0/2/4/5/6/8秒；72对旧/新原生评分完全相同。四起点受测最佳时点为6/5/6/4秒，但最终赢家仍为第2起点、最佳仍5秒，没有提高总体冠军。只保留结论，不固化首爆联合搜索或强制5秒。

### 静态快照

48对、96次评分逐对等价。ON−OFF耗时均值−2.91毫秒，描述性95%区间[-11.98,+4.69]毫秒；关闭每报告约少26,106字节。没有稳定关闭提速证据，故保留现状，不加快照开关/缓存。内存观测没有区分度，不能宣称零内存成本；该结果仅为云端Linux原生评分。
