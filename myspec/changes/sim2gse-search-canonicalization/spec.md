# Sim2GSE 搜索候选标准化与约束

Triage（分拣）: ready-for-agent
Status（状态）: ready-for-agent
Parent（上级事项）: [实施第一阶段标准化与搜索约束](../sim2gse-search-optimization/issues/02a-canonicalization-implementation.md)

## Problem Statement（问题说明）

Sim2GSE 当前直接散列候选的原始结构作为 `program_key`（程序身份）。执行行为相同但写法不同的普通动作、Sequential Loop（顺序循环）和 WaitClicks（等待点击）会占用不同候选名额并重复进入 SimC（战斗模拟器）；非法结构主要到编译时才被发现。用户无法确认固定搜索预算是否花在真正不同且可执行的候选上。

## Solution（解决方案）

在角色动作已映射后，通过一个小接口生成不含来源和展示信息的 canonical form（标准形式）。搜索去重、归档、缓存请求和编译一致性检查统一使用该行为身份；非法、无效和重复候选在调用 SimC 前拒绝。保留原始可导出程序树及来源信息，避免标准化破坏 GSE（高级按键序列插件）导出和诊断。

## User Stories（用户故事）

1. 作为搜索用户，我希望相同点击行为只评估一次，从而把固定时间用于真正不同的序列。
2. 作为搜索用户，我希望不同起始位置、动作顺序、动作块和重置语义保持分离，从而避免错误合并候选。
3. 作为搜索用户，我希望非法或无法执行的候选在调用 SimC 前被拒绝，从而减少无效计算。
4. 作为搜索用户，我希望标准化不降低相同预算下的最佳 DPS（每秒伤害），从而确认效率优化没有损害结果质量。
5. 作为维护者，我希望候选身份、批次缓存和实际编译点击计划能够互相核对，从而避免同一候选在不同层拥有不同身份。
6. 作为维护者，我希望来源路径和调试信息继续可追溯，但不影响行为身份，从而兼顾诊断与去重。
7. 作为维护者，我希望身份规则带有版本，旧检查点不能静默使用新键续跑，从而避免缓存和恢复状态混用。
8. 作为验证者，我希望从完整搜索任务和公开任务入口观察 SimC 调用、导出、缓存和恢复，从而验证真实用户路径。

## Implementation Decisions（实施决策）

- 标准化 Module（模块）的 Seam（接缝）位于动作映射完成之后、SimC 调用之前；Interface（接口）接收搜索程序及角色能力，返回行为身份、规范行为计划和保留来源的可导出程序。
- 行为身份包含逐次点击的动作及块内顺序、动作块边界、空点击位置、`/castsequence` 成员与 Reset（重置）规则、起始规则和序列重置规则。
- 来源路径、显示名称、备注和调试信息不参与身份。重复来源可作为诊断信息保存。
- 顺序循环与完全相同的展开行为、重复一次与普通动作、相邻等待点击合并。动作顺序、次数、块边界、起始位置、随机／优先级循环及不同宏重置语义不合并。
- 不强制把可导出程序树永久展开；规范行为计划负责身份，可导出树继续满足顶层节点限制。
- 至少含一个可映射且可执行动作即不是空候选；主动饰品属于有效动作。仅有空点击、注释或无法映射动作的候选无效。
- 重复减少的主口径为实际启动的、未命中缓存的 SimC 批次调用数；候选请求数、缓存命中数和标准化去重数同时报告。
- 身份规则具有明确版本。旧任务的 `seen`、归档、锁定候选键或导出目录不得原地重算；版本不匹配时拒绝恢复并建立新任务。
- 第一阶段不改变局部变异策略、分批淘汰策略或候选评分。

## Testing Decisions（测试决策）

- 最高层公开测试接缝是完整 `run_task`（运行任务）和 `/api/tasks`（公开任务入口）：观察导出、点击计划、实际 SimC 调用次数、缓存及恢复结果。
- 标准形式接口补充固定等价、非等价和非法样本测试；测试外部行为身份和拒绝结果，不绑定内部辅助函数。
- 等价集必须 100% 合并，非等价集必须 100% 分离，非法集必须 100% 在 SimC 前拒绝。
- 使用已冻结三套 Benchmark（基准测试）运行 A/B：实际 SimC 重复调用至少减少 20%，每分钟新候选检查量至少提高 10%，任何配置最终最佳 DPS 中位数下降不超过 0.5%。
- 旧检查点、身份版本不匹配、损坏缓存及最终复测数据隔离属于恢复测试。

## Out of Scope（范围外）

- 不新增或调整 Local Search（局部搜索）变异算子。
- 不实施 Successive Halving（逐级淘汰）。
- 不实施 Adaptive Mutation（自适应变异）、Warm Start（热启动）或预训练。
- 不修改 GSE 本体、游戏目录或职业专用技能规则。
- 不把游戏实测 DPS 混入模拟 Benchmark 成绩。
