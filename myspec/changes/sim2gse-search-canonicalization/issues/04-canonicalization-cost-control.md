## What to build（交付内容）

保留标准化、约束、统一身份和恢复检查，把分析期统计改为默认关闭且不触发额外完整保存，并在判断重复后复用已有编译结果，使生产搜索不再长期承担详细分析成本。

## Acceptance criteria（验收条件）

- [x] 修正 Benchmark（基准测试）的重置超时字段口径，后续 A/B 使用同一统计定义。
- [x] 诊断统计支持关闭、汇总和完整三种模式，默认关闭；关闭时不创建或保存详细追踪，其他模式只随现有检查点或任务结束持久化。
- [x] 统计计数变化不再单独触发完整任务状态保存，固定轨迹中的完整保存次数降到现有业务检查点数量级。
- [x] 相同行为身份复用已成功编译结果，首次候选仍完成编译和一致性校验；重复候选不重复启动 Lua 编译进程。
- [x] 当前版、统计收缩版、编译复用版及完整方案在固定候选轨迹中具有相同的行为身份、接受和拒绝结果、候选分数、DPS 与最终候选。
- [x] 使用一套当前角色配置和 3 个配对种子报告 SimC 调用、总 iterations（迭代次数）、候选处理速度、总时间、编译次数、Lua 启动次数、完整保存次数和最终 DPS 中位数。
- [x] 最终 DPS 无实质下降，候选处理速度稳定恢复或不再明显低于固定基线；若仍稳定变慢，则保留证据并停止，不进入 Local Search（局部搜索）。
- [x] 验证后重新判定 20% SimC 调用减少门槛；不得用标准化约 0.214% 的真实新增重复率虚构达标。
