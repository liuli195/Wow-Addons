# 将候选行为身份接入搜索、缓存与恢复

Triage（分拣）: ready-for-agent
Status（状态）: in-progress
Assignee（领取者）: Codex
Parent（所属变更）: [Sim2GSE 搜索候选标准化与约束](../spec.md)
Blocked by（前置事项）: [建立候选行为身份与搜索约束](01-canonical-identity.md)

## What to build（交付内容）

让初始候选和变异候选经过同一标准化入口，使搜索去重、归档、导出目录、批次缓存和检查点恢复使用一致的行为身份；身份版本变化时拒绝旧任务静默续跑。

## Acceptance criteria（验收条件）

- [ ] 初始候选和变异候选都在统一入口完成映射、约束检查和去重。
- [ ] 候选归档、锁定候选、批次请求和导出产物能追溯到同一行为身份。
- [ ] 来源路径、显示名称及调试信息保留，但不改变缓存身份。
- [ ] 旧身份版本的 `seen`、归档和锁定候选状态不能按新规则原地恢复。
- [ ] 最终复测样本仍与搜索及验证样本隔离。
- [ ] `run_task` 和 `/api/tasks`（公开任务入口）回归覆盖重复候选、缓存命中、取消／恢复和最终导出。

## Comments（讨论）

只接入第一阶段身份与约束，不改变候选生成、评分或分批淘汰策略。
