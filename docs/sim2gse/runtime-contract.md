# 计算预算、缓存与恢复契约

对应[确定计算预算、缓存与恢复契约](../../myspec/changes/sim2gse-wayfinder/issues/10-runtime-contract.md)。2026-09-12。本文件确定首版试行规则，不代表调度器、缓存和恢复功能已经实现。

## 预算与测量依据

用户确认一次优化最多 10 分钟，包含初始化、基线、搜索、验证、最终复测及结果整理。按累计实际运行墙钟时间计费，暂停／程序退出期间不计入；恢复不会自动重置预算。搜索最迟在累计第 7 分钟停止，至少预留剩余 3 分钟给最终复测和报告，提前停止则把剩余时间用于复测。在总截止时间前停止计算；终止进程与保存状态可能需要额外的短暂收尾时间，界面必须显示仍在收尾而非假称完成。

沿用角色原始装备与天赋、单目标、每场 180 秒、名义输入间隔 300 毫秒。首版不提供药水或逐动作选择，不缩短战斗来加速初筛。

任务 8 的固定序列测量为每组请求 100 次战斗约 0.567 秒。任务 10 另以同一输入、程序和种子完成 24 次进程运行，每种并发度三轮、每轮四组；轮次交替顺序，单路四组中位数 2.485 秒，双路 1.365 秒，吞吐量约为单路的 1.82 倍，全部完整角色报告与原始参考一致。计时包含启动、报告输出与本次检查解析，不是纯引擎内核耗时；没有测内存峰值或整机使用率，也没有运行搜索。

证据：[可重跑测量脚本](../../.local/sim2gse/task-10-budget/benchmark.py)、[完整测量记录](../../.local/sim2gse/task-10-budget/summary.json)。脚本仅使用现有程序，新增输出在独立目录，不修改任务 8 的证据。用现有可用的 Python（解释器）运行脚本即可；依赖固定程序、输入与原始报告。

## 首版试行参数

除用户确认的 10 分钟上限外，下列是可依据实测调整的工程初值，不是用户习惯、速度或精度保证。运行前写入清单，运行中不根据成绩临时改规则。

| 项目 | 试行规则 |
| --- | --- |
| 并行 | 最多两个独立引擎进程，每个一个模拟线程；每组独立目录。未测的机器可选择单路，不能自动占满所有核心。两个进程不等于整机固定使用率保证。 |
| 批量能力 | 首版可直接用本次验证的独立进程方式。原生配置批量模拟尚未验证，不作为前置依赖；后续替换须重新做结果一致性与性能检查。 |
| 候选数 | 搜索阶段最多评估 1,000 个去重后的合法候选；重复缓存命中不消耗新候选额度，但仍计耗时。时间或数量先达到者停止。 |
| 分批评估 | 搜索阶段请求累计 32、128、512 次战斗作为加测档位；只补缺少的独立批次，按实际有效样本数计算。明显落后停止追加，边界接近则追加，无法确定即保留不确定性。验证集另分配种子，不复用搜索样本。 |
| 无改善停止 | 一轮最多生成并处理 16 个新的合法候选，预算不足则记部分轮。至少覆盖两个不同合法起点，连续 5 个完整轮次没有经验证集证实的改善时停止；不足两个不同合法起点的受限空间遍历完也可停止。生成器长时间只产生重复／非法候选时按搜索空间停滞结束，不死循环。 |
| 近似平局 | 不把差异不显著当作已证明等效；展示未证实改善，短序列及稳定性仅用于选取保留候选。旧 0.5% 示例不作为强制阈值。 |
| 单批超时 | 初值 30 秒，实际允许时间取单批上限与阶段剩余时间的较小值。超时标为失败，不自动反复重跑同一失败批次，不记零分。 |
| 总期限 | 搜索截止前不派发预计无法在搜索窗口内结束的批次；最终窗口不足时同理。估时错误不能突破总期限继续模拟，部分结果不能入成功缓存。 |
| 日志 | 搜索和复测默认保留摘要、身份及错误日志；轨迹仅用于受限诊断样本，不能全量记录每个候选的全部按键。 |

### 最终复测与节奏情景

先锁定一个候选，再使用未参与搜索或验证的批次，与同约束的初始序列比较；标准原生基线另保留并明确其自由选招性质。首轮目标为每个情景、每个对象 20 个独立种子批次，每批请求 100 次完整战斗；记录真实有效样本数（已有固定版本请求 100 次时统计样本为 99，不能虚报为 100）。这些次数是预算内目标，不能为凑数自动延长 10 分钟。

情景在查看最终成绩前固定：

- 名义：从 0 毫秒开始，每 300 毫秒一次输入。
- 小幅扰动：每个输入间隔从 270—330 毫秒均匀采样，输入随机数与战斗随机数分开；相同情景的候选与对照共用输入时间流。
- 慢按：每 400 毫秒一次输入。
- 暂停恢复：在名义输入流中去掉战斗时间区间 [60, 62) 秒和 [120, 122) 秒内的输入；没有输入就不推进序列，区间结束后恢复原时间网格，不因暂停重置步骤。
- 起始相位：每 300 毫秒一次，首次输入为 150 毫秒；其余初始状态与名义情景一致。

以上是工程压力情景，不宣称测得用户实际按键习惯。分别报告情景下的均值、相对初始序列差异与区间，不事后选有利情景；不能只测试名义节奏就标为稳定。没有足够独立批次、区间仍不确定或任一必需情景未完成，报告“证据不足／验证未完成”及缺少部分。根据最终结果改候选必须使用新的最终样本，且不得自动重置当前预算。

## 缓存与可复现性

原始输入原样留存；语义解析后才生成任务身份，不通过排序宏命令或覆盖配置来规范化。展示备注可不参与成绩缓存，但仍保留原文。缓存分为条件身份与采样批次身份：

| 身份 | 必须覆盖的内容 |
| --- | --- |
| 条件 | 角色等级、专精、种族、天赋、已装备物品与修饰数据、附魔与被动效果、数据版本；上游提交、补丁及引擎程序散列；解析／动作映射／编译规则版本；完整编译命令顺序与动作块；战前准备、消耗品、目标、战斗时长；输入分布、暂停与重置规则、起始相位；每进程线程数和全部会影响模拟的选项。 |
| 批次 | 搜索／验证／最终集合用途、战斗种子、输入流种子、请求迭代数及统计规则版本；实际有效样本数写入结果，不能按请求数假定。 |
| 搜索恢复 | 算法及参数版本、候选生成随机数状态、已处理轮次、候选稳定编号、按编号消费结果的位置、待派发批次、已完成批次、剩余预算和阶段。 |

只有完整成功且解析、身份、有限数值及有效样本数校验通过的批次可入库。追加批次不能重叠，损坏或未完成报告不命中；相同编译文本但角色或场景不同不复用。循环旋转、起始位置变化不自动视为相同序列。

并发结果按预先分配的稳定批次顺序用于更新搜索，不能按谁先返回谁先选优；不同进程完成顺序不应改变候选生成随机数消耗。时间截止可能使完成范围不同，因此同清单只保证固定已完成批次的可复现，不承诺墙钟限时搜索每次得到相同赢家。改变每引擎线程数、任何模拟身份或统计规则使相关缓存失效；改变外层进程数须建立新的运行清单，不原地假装同一次运行。

## 取消、失败与恢复

用户确认首版采用“取消立即停止计算”：立即停止派发，对本次任务拥有的进程及其子进程发出终止并等待退出；不按进程名称终止其他项目或用户的模拟。退出清理目标为 2 秒内，尚未实测；若未退出，显示仍在停止并继续收尾，不能提前标记已停止。

结果存储使用标准库提供的 SQLite（本地数据库）事务；原始报告先写独立临时文件，完整校验后原子替换，再在事务中登记完成身份、摘要与任务状态。不创建第二套消息服务。中断导致的未登记文件不当成功记录，下次恢复可校验后收录或重跑；已登记记录若文件丢失／损坏，标明失效并重新计算，不相信半份文件。

启动批次前持久化批次身份、待执行状态和该批次时间额度。阶段转换、候选锁定、完整批次入库及取消时保存检查点，运行中至少每秒更新一次累计已用时间。异常退出时若无法恢复最后活动区间的准确耗时，按已派发批次剩余时间额度的最大值保守扣除（并行批次不相加），上限为单批 30 秒及当时剩余总预算的较小值；不得把整个离线等待计入。该扣除与恢复标记在同一事务完成，防止重复扣除；不因重启赠送预算。子进程所有权必须保证主程序异常退出后也能清理所属模拟进程。

恢复只接收同一版本与配置的清单，核对已完成结果，不重复汇总样本；原先运行中的未完成批次回到待执行状态，使用原批次种子。最终候选已锁定则只能继续该候选的独立复测，不能偷偷返回搜索阶段。预算已耗尽只能查看结果；增加预算必须显式形成新的运行修订记录，不能清零历史耗时。

版本、配置或输入变化时创建新任务，拒绝原地续跑；仅完全匹配身份的已完成评估可按用途复用。先前被看过或参与选优的样本不得在新任务冒充未见过的最终测试。原生回归、数据解析或全局兼容性错误停止整个任务；单个合法候选运行失败保留具体诊断，不进入有效排名。

## 输入和正式实施验收

只接收单角色文本，拒绝外部文件引用、远程导入、额外执行命令、自定义输出路径及未经允许的模拟覆盖。使用结构化参数启动引擎，不把角色文本拼成命令；工作路径由工具在任务目录内生成。未知或不支持的主动动作明确诊断，被动效果按任务 8 决议沿用原生模型。

| 测试 | 实施时必须核对 |
| --- | --- |
| T01：输入保真 | 中文、注释和背包装备保留，注释不替换当前已装备物品；同语义输入按规则复用。 |
| T02：输入安全 | 外部文件、输出路径覆盖和命令注入样本明确拒绝，不能越出任务输出目录。 |
| T16：重置和相位 | 改起始相位、暂停规则或重置策略使相应缓存失效；暂停不擅自推进或重置。 |
| T17：随机数和线程 | 同批次身份复跑一致；线程、种子、程序或输入模型变化不能命中原批次；不同完成顺序按稳定顺序消费。 |
| T18：失败、取消与恢复 | 在写报告、提交前后、阶段转换和最终候选锁定后分别中断；已完成批次不重复计算／计数，未完成批次不当成功，无孤儿模拟进程；预算不因恢复归零。 |
| 预算与超时 | 搜索预留复测窗口；总期限到达停止模拟；部分复测或损坏报告不产生“已验证”成绩，清理未完成不显示已停止。 |

上述为未来实现的检查协议，当前只实际完成固定序列的并发测量，不能把取消、恢复或上述压力情景写成已通过。
