# 魔兽世界项目领域术语

此处记录项目讨论中需要区分的领域概念。按主题分节，当前包含角色级按键序列优化器与准星 HUD 两部分。

## 术语

**可按动作**：玩家通过一次游戏命令主动尝试的能力，例如施放技能、使用主动饰品或开始攻击。其实际效果可以包含多个伤害、治疗或召唤事件。

**替换形态**：同一个基础按钮随天赋或角色状态呈现的另一种能力形态。它不是可绕开当前状态任意选择的第二个按钮。

**派生效果**：由主动动作、装备、天赋或召唤物机制产生，且不要求额外玩家按键的后续效果。避免将它与可按动作混称为“一个技能”。

**按键动作块**：一次有效输入依次尝试的命令集合；一个块可以含多个合法动作，动作数量不等于按键次数。

**导入序列**：从外部 GSE（高级按键序列插件）字符串还原的完整序列，包括版本、动作、控制块和来源位置；解码成功不等于其中每一步都能准确进行伤害模拟。

**空点击**：GSE 序列在一次按键上推进步骤但不尝试可按动作，例如暂停块展开的步骤。它占用按键次数，不是可按动作。

**尝试频率**：序列在重复输入下尝试某动作的频率；冷却、资源和其他执行条件会使成功执行频率与它不同。

**暂定锁定**：某次技能输入出现了可能成功的反馈，暂时不再允许后续输入替换，但在反馈被否定时仍可回滚。它区别于尚可替换的排队输入和已经确认的队列承诺。

**队列承诺**：某次暂定锁定已通过反馈与执行条件确认，不再允许替换或回滚。它区别于暂定锁定，也区别于技能已经成功执行。

**纯序列模拟**：只以已选序列、冻结的角色资料和预先设定的运行条件产生模拟结果；“纯”指不读取实机战斗过程中的点击、冷却、失败、资源或成功记录，不表示无需角色资料。

**按键时序独立回放**：同一已选序列分别使用对应场次探针记录的按键时刻驱动模拟；除按键时刻外，不读取该场实测冷却、失败、资源或成功状态。模拟输出固定后才与该场成功动作比较。它不同于纯序列模拟，也不同于带实测状态反馈的诊断回放。

**事后对照**：纯序列模拟结果固定后，才与实机成功动作序列比较；实机记录只用于评分，不反向改变模拟过程。

## 准星 HUD（Crosshair HUD）

**准星 HUD**：以屏幕中心准星为锚点的玩家自身资源显示，保留血弧、符能弧、符文格与准星四个基础元素，另有凝固之血监控条、沸点循环监控条与灵打消耗刻度三个可选功能。它只显示玩家自己，不含任何其他单位的资源。

**元素**：准星 HUD 中可独立开关的组成单元——血弧、符能弧、符文格、准星各是一个基础元素；凝固之血监控条、沸点循环监控条与灵打消耗刻度也各有独立开关。

**中心定位点**：准星正中那个白点。它是**准星的一部分**，不单独成元素——跟着准星一起显示、一起染色、一起开关。它没有单独的开关。

**阴影**：四个基础元素底图**之下**的柔和外围层，主体覆盖区域透明、**不随填充比例变化**。凝固之血监控条、沸点循环监控条与灵打消耗刻度没有阴影。它的颜色与浓淡是**一处全局设置**，不按元素分别配置；颜色只有自定义色。

**元素开关**：决定准星 HUD **包含哪几个元素**的开关。它与**可见性**是两根不同的轴：元素开关管 HUD 里有什么，可见性管整条 HUD 在什么情况下出现。

**可见性**：决定整条准星 HUD **在什么情况下出现**的条件。它作用于整条 HUD，不按元素分别设置；元素的取舍归**元素开关**负责。

**弧线填充**：把一段圆弧按比例显示为“已填充”，填充边界是过圆心的径向线。区别于矩形进度条沿单轴裁切；圆弧的填充是角度方向的，两者不可互相替代。

**符文格**：死亡骑士 6 个符文各自的显示单元。每格显示该符文**自己的充能比例**，而不是“就绪／未就绪”两态——这是它区别于其他离散职业资源（如神圣能量、连击点）的地方。

**填充色**：元素填满部分的颜色。基础元素可选共享来源配色或自定义颜色；凝固之血监控条与灵打消耗刻度只有自定义颜色，默认白色；沸点循环监控条也只有自定义颜色，默认RGB(0.77,0.12,0.23)。

**背景色**：元素未填充部分的颜色，对应设计稿上的深灰段。它只有自定义，没有职业配色选项。

**职业配色**：把元素的填充色取为当前职业颜色的模式，与自定义颜色互斥二选一。本版只面向死亡骑士。

**拖动框**：EllesmereUI 解锁模式中浮在元素上、供调整位置与尺寸的框。准星 HUD 报告隐藏时它一并收起，不留可拖动的空框。

**凝固之血条**：配置项目显示名为“凝固之血监控条”，仅鲜血专精250可用、不判断天赋点选。它是玩家自身法术463730的原始层数显示；默认最大显示层数100，不代表技能真实上限。采用确认的完整半粗弧，增益消失或开关关闭时整条隐藏，不依赖暴雪默认增益监控。

**灵打消耗刻度**：能量弧上的径向直线，表示当前实际灵界打击最低符能费用占当前最大符能的比例；粗细、颜色、透明度可调，费用变化时位置与方向一起变化。

**沸点循环监控条**：仅鲜血专精250可用的右侧预测细弧，不判断天赋点选。50842玩家施放成功与发光消失在0.30秒内配对后，从该次施放起算三秒；触发发光本身不启动或重置当前轮。期间新触发只待续一轮，到期从旧截止加三秒；新的有效手动消费重设为该次施放加三秒。它表示推断窗口，不是读取真实回声施法或增益到期。
