# 获取真实角色属性对照并核实剩余面板差异

Type: task
Label: wayfinder:task
Status: resolved
Assignee: none
Parent: ../map.md
Blocked by: none

## 问题

提供同一版本、同一角色条件的可核验面板参考，解决原生模拟器输出与真实游戏之间尚未确认的口径差异，尤其是平均物品等级、护甲取整及常驻效果。该事项是取得决策依据，不是部署或制作网站。

## 已有证据

原版 12.1.0.69587 模拟器的装备解析、七个战前属性快照和五个递减阈值输入已在本机验证；计算源码及主要换算数据已固定。尚未取得用户真实角色的导入文本和面板读数，不能以模拟器自洽证明真实游戏一致。

## 所需输入与执行边界

1. 用户提供 90 级鲜血死亡骑士 `/simc nobags` 原始导出，可删角色名、公会和服务器；保留天赋、种族、装备及其他属性相关字段。
2. 同一角色、同一装备与天赋下，脱战且无临时增益时的力量、敏捷、智力、耐力、护甲、副属性等级及百分比、已装备平均物品等级。记录实际游戏版本、取样条件和仍存在的常驻效果。
3. 如平均装等或护甲存在差异，再按最小必要范围补取一次单槽更换或空槽对照，不先要求大量游戏操作。

主代理负责解析、对照与定位差异；不自动部署插件，不更改用户游戏装备或配置。尚无可用手段替用户取得游戏内读数，缺失读数不自行编造。

## 已取得的角色导出

2026-09-08：用户提供 15:51 的 90 级至高岭牛头人鲜血角色导出，版本 12.1.0.69587，导出插件 12.1.0-03。主代理将聊天文本中的下划线转义恢复，省略姓名和服务器等身份信息，保留实际生效天赋、额外系统配置及全部装备字段；另一套注释内天赋没有启用。输入和运行输出只存本地忽略目录。

原生计算成功；15 个属性槽的解析装等全部匹配导出注释，战袍输入保留但不计入属性槽输出。制作自选属性、镶嵌附魔和两件重定向基础属性装备均被接受。程序仍提示一个额外系统触发效果未经充分验证；解析成功不表示所有效果的游戏准确性已通过。

用户随后提供对应属性截图：力量、耐力、护甲、四项副属性等级及百分比均与原生快照按显示精度匹配。护甲 3398.307 对应截图 3398，但本例不能区分截断与四舍五入。用户再补充已装备平均装等 315.75，与完整装备、双手武器计两槽的计算完全吻合。详细输出与可运行对照检查见[属性计算研究](../research-stat-rules.md)。

## 结论

2026-09-08：已取得真实角色导出、面板截图及平均装等，完成当前样本对照，并定位原生平均装等与游戏槽位平均的差异。本前置任务完成，属性研究可以继续。敏捷、智力尚无面板读数，护甲取整边界、空槽及其他武器布局仍是[属性研究](02-stat-rules.md)的明确缺口，不将取得参考样本等同于全部准确性验收。

## 完成标准

参考数据身份与条件可核实，差异被解释或明确定位到独立的规则缺口；不能仅以收到了文本作为准确性验收通过。原始角色数据默认只存本地报告目录，不自动进入版本管理或外部服务。
