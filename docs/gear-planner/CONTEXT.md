# 装备规划器领域术语

本领域描述角色装备配置及其面板属性，不描述战斗模拟结果。

## 术语

**配装方案**：一份角色条件与各槽位装备配置的组合，是保存、导出和比较的单位。

**角色条件**：影响属性计算的角色等级、职业、专精、种族及天赋。当前原型角色为 90 级鲜血死亡骑士，种族与天赋来自 `/simc` 导入。原型通过后，正式版本必须适配目标版本全部职业、专精和合法种族组合，详见[正式版本全角色适配任务](issues/09-all-characters-production.md)。

**装备配置**：某槽位装备及其物品等级、宝石、附魔和适用的制作自选属性等实际变体。

**可搜索装备目录**：用户在页面主动搜索和选择的装备范围，第一阶段限定为 12.1 第二赛季大秘境、团本及制作三类中全部可用于毕业配装的史诗装备，不是每槽推荐短名单。

**导入解析范围**：导入器尽可能识别的目标版本装备范围，不受可搜索装备目录的来源限制。

**最终属性**：给定角色条件与装备配置下，脱战且无临时增益时的角色面板属性。

**计算版本**：用于解释同一配装的一组确定的游戏构建、热修复、计算规则及装备属性数据；不同计算版本可能使相同配装产生不同结果。

**名称资料**：装备的中文、英文等显示名称，与决定装备属性和计算结果的数据区分；名称补全不代表计算版本变化。

**属性等级**：装备等来源提供的副属性数值，区别于其经换算、递减与其他适用规则处理后的百分比。

**来源拆分**：说明某项属性由角色基础、装备、宝石、附魔及其他适用的常驻效果如何形成；其具体计算展示方式尚待核实。

**未能完整计算**：存在尚未解析或核实的输入或规则，不能将已有部分合计宣称为最终属性的状态。

**过期结果**：基于先前装备配置、角色条件或计算版本得到的结果，不能代表当前方案的最终属性；不等同于方案本身丢失或无效。
