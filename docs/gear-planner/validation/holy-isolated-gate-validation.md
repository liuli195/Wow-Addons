日期：2026-09-11，用户明确授权。本次结论：**最小入口放行能使固定源码的神圣专精生成静态属性快照，装备变化测试通过；不等于已证明全部游戏属性正确，也未接入现用配装器。**

## 修改和隔离

复制固定官方提交 b845947a34429874433d8e9362326894650dd20a 到 `.local/gear-planner-holy-isolated/source`（独立源码）。只修改 engine/class_modules/paladin/sc_paladin.cpp 的一处校验条件：实验性开关关闭时继续拒绝神圣，打开时放行。不修改属性公式、数据或其他职业代码。

对全部 cpp/hpp/h/inc（源码及数据）逐文件检查，仅该文件有差异。另建 control-source（未修改对照源码），用相同工具和参数构建；复用同来源中间文件，仅重编译发生变化的圣骑士模块及链接，未将此过程称为全量干净重编译。

构建命令为 mingw32-make（构建工具）在各自 engine 目录执行 `-j2 SC_NO_NETWORKING=1 CXX=g++ MODULE=simc-holy-isolated.exe`；对照输出名为 simc-holy-control.exe。保留该构建的断言设置，未额外关闭断言。

隔离程序 SHA256（文件校验摘要）：`7fc6a54acd4fa247fc4e1703619c03da3368ecb4f853a880a427ffdc7a87f6ae`。原版程序、源码及配装器未替换。

## 样本与结果

使用当前合法装备池中不同的神圣适配候选，90 级人类，全板甲，单手加盾牌，关闭消耗品与临时附魔。无天赋基础样本用于拆分检查；另加入已有公开 12.1 神圣天赋的变体。没有冒充玩家导出或远端独立验证。

| 场景 | 观察结果 |
| --- | --- |
| 未修改对照，开实验开关 | 神圣仍被拒绝，快照属性为空 |
| 放行副本，关实验开关 | 快照属性为空；退出码为 0，不能因此算通过 |
| 放行副本，开实验开关 | 快照完整；智力 3129，耐力 42963，护甲 3771 |
| 显式法术角色 | 与默认角色快照完全一致 |
| 胸甲 334 升至 337 | 智力 3134，耐力 43100，护甲 3780，暴击等级不变 |
| 卸披风 | 耐力精确减少披风的 2199，暴击、急速等级不变 |
| 卸胸甲 | 智力 2791；加回胸甲 189 并应用全板甲 5% 后截断为 3129，与基线吻合 |
| 加入神圣天赋 | 快照完整，智力 3254；此项只确认可执行及数值有变化，不宣称全部天赋倍率独立验真 |
| 防护、惩戒既有样本 | 放行与未修改对照的完整快照相同 |

基线四副属性等级：暴击 742、急速 867、精通 803、全能 642。所有检查以实际非空快照为准；本构建可能在校验拒绝后仍返回 0。未用退出码代替数值验收。
