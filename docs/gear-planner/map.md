# 国服装备规划器实施路线

Label: wayfinder:map
Status: open

## 目标

形成经过真实数据与计算依据核实、可直接实施的正式服 12.1 装备规划器方案。第一阶段面向 90 级鲜血死亡骑士，规划选择装备、修改装等和镶嵌附魔、实时属性、保存及比较方案的完整闭环。本次仅规划与研究，不交付网站实现。

## 约定与已确认边界

- 2026-09-08 续研要求：优先复用现成数据集、接口和计算能力，避免重复实现已有装备解析、天赋解码或属性计算。

- 2026-09-08 用户确认：沿用本仓库，以独立目录管理网站；首阶段仅本地使用，不要求公网部署。
- 配装方案保存在当前浏览器，以文件导入、导出实现备份和转移；无账号系统。
- 种族与天赋从 SimulationCraft（模拟器）的 `/simc` 文本读取，首阶段以导入作为角色基础，复制已有方案继续配装；不做复杂选择器，不擅自默认种族或天赋。
- 最终属性指脱战、无临时增益时的面板属性，包含适用的种族、常驻专精及天赋效果；具体条件与取整顺序须依据真实规则核实。
- 2026-09-08 用户进一步收窄：可主动搜索的装备仅覆盖 12.1 第二赛季大秘境、团本、制作三类的毕业史诗装备；不再采用此前包含稀有和玩家对战制作的 570 项宽候选集。用户已确认保留三类来源全部可用于毕业配装的史诗装备及搭配选择，不缩成鲜血专精推荐短名单。按最终物品变体品质筛选，不能用基础记录品质误删大秘境装备。导入装备不受搜索目录限制，尽可能解析目标游戏版本可识别的全部装备。
- 数据缺失时保留原始装备及配置，逐项标明缺失与受影响属性，显示“未能完整计算”；不得把缺失贡献当作零，也不得伪造装备或规则。
- 简体中文为默认语言，装备优先国服中文名称并保留英文名称。
- 全部原始功能要求仍有效：支持职业、专精，完整装备槽位自由配装，各槽位可搜索装备、调整物品等级、宝石、附魔及制作自选属性。当前原型准确支持鲜血死亡骑士；2026-09-08 用户确认：原型通过后，正式版本必须完成全职业、全专精与全种族合法组合适配，作为正式交付验收条件，详见[正式版本全角色适配任务](issues/09-all-characters-production.md)。
- 显示力量、敏捷、智力、耐力、护甲、暴击、急速、精通、全能和平均物品等级。副属性同时显示属性等级和百分比；每项属性可查看来源拆分，包括装备、宝石和附魔贡献。
- 更换装备、物品等级、宝石、附魔后属性立即更新，支持保存多个配装方案、两个方案属性差异比较及方案文件导入导出。如何计量“立即”和如何显示不完整结果在验收事项中明确。
- 属性准确性高于界面完成度。版本、公式、数据与测试证据必须可追溯，未验证不得报告准确。
- 使用 wayfinder（路线规划）、grilling（决策问答）、domain-modeling（领域建模）及 research（资料研究）技能；研究委派遵循 subagent-policy（子代理策略），只读并行、主代理统一记录。
- 本地文件事项跟踪沿用技能约定；为遵守仓库文档统一放在 `docs/` 的要求，地图与事项位于本目录，替代技能默认的 `.scratch/`。每项独立文件，以 `Type`（类型）、`Status`（状态）、`Assignee`（领取者）、`Blocked by`（前置事项）记录状态；无前置未完成项且未领取的开放事项为当前可处理事项。决议追加到事项的“结论”部分。
- 所有研究在 `codex/research/gear-planner-plan` 分支记录（以仓库要求的 `codex/` 前缀承载技能研究分支），初始基线为 `8627cf324a4a5c4895d5864804ad6971ad2b74ec`。不创建远端事项，不修改现有插件、素材、游戏安装或发布配置。

## 已完成的决策索引

- [核实目标版本装备数据、中文名称与导入解析来源](issues/01-equipment-data.md) — 已实测现成数据与原生解析组合；完整覆盖和游戏一致性不冒充已验收。
- [获取真实角色属性对照并核实剩余面板差异](issues/06-game-reference.md) — 已取得导出、截图及平均装等；当前可见属性匹配，双手武器平均装等差异已解释，边界覆盖留在属性研究。
- [核实九十级鲜血死亡骑士面板属性计算规则](issues/02-stat-rules.md) — 复用固定原生引擎；常驻效果已定位，制作字段冲突已重现并验证最小适配，未验收边界交准确性事项。
- [确定三类毕业史诗装备目录与合法变体](issues/07-epic-catalog.md) — 现成数据形成 471 个基础成品及 52 个关联转化形态，KeystoneLoot 用于交叉核对，保留普通轨道与特殊团本终点差异。
- [确定本地运行与数据更新方案](issues/03-local-delivery.md) — 仓库内双击启动，仅本机访问；首次下载和缺失公共资料自动补充，启动检查后手动更新，方案统一新版且重算前提示。
- [确定准确性验收与不完整数据的支持边界](issues/04-accuracy-contract.md) — 不完整方案保留且只比较已确认项目，允许名称回退，缓存正常编辑以 1 秒内更新为目标；标准确定不等于实际验收通过。

- [验证配装编辑、属性拆分与方案比较流程](issues/05-workflow-prototype.md) — 用户已确认当前交互原型通过；准确性缺口及正式版本全角色适配仍须独立完成。

- [补齐真实面板与取整边界证据](issues/08-panel-boundaries.md) — 敏捷、智力已配套核对；卸披风护甲支持当前样本截断候选，正式适配须修正显示与比较并验证跨角色边界。

## 尚待明确

- 在原型中确定来源拆分、部分导入失败、天赋缺失、旧结果及统一版本重算的具体表达；已有事项承载验证，不重复创建。
- 核心交互确认后，细化小屏布局、装备搜索筛选及比较展示细节；真实面板剩余证据已有独立前置任务，不因原型完成而视为通过。

## 范围外

- 初始地图只做规划。2026-09-09 用户已授权提交当前研究、原型及测试，创建拉取请求并合并主干；该交付不等于正式版本开发完成，不包含公网部署。
- 第一阶段不做伤害、坦克、循环模拟，天赋树模拟器，战斗日志分析或账号系统。
- 不依赖 Battle.net Armory（战网英雄榜）导入国服角色。
- 第一阶段搜索目录不包含指定赛季三类来源以外的装备；此限制不适用于导入解析。
