# 本地任务跟踪

- 每项变更使用 `myspec/changes/<change-name>/`。
- 需求保存为 `spec.md`。
- 任务分别保存为 `issues/NN-<slug>.md`，从 01 开始按依赖顺序编号。
- 每张任务记录 `Status`（状态）、`Blocked by`（阻塞任务）和验收条件。分拣状态使用 [任务分拣标签](triage-labels.md) 中的标签。
- 技能要求“发布到任务跟踪系统”时，写入上述本地文件；要求读取任务时，读取对应文件及其追加讨论。
- 讨论追加在任务文件的 `Comments`（讨论）章节。
- 开发流程按已确认票据顺序实施，并在验收后记录完成证据。
- GitHub（代码托管平台）继续用于拉取请求交付。
- 既有任务文档保持原位置，引用时读取原文件。
