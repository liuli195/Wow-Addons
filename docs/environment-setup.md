# 开发环境使用说明

部署日期：2026-09-07。公有仓库：[liuli195/Wow-Addons](https://github.com/liuli195/Wow-Addons)。

## 环境与范围

本机游戏可执行文件和安装版本记录均为正式服 12.1.0.69587。工具和接口资料的具体版本以 `tools/versions.json` 为准；本机使用仓库内 `.venv`（独立 Python 环境），无需启动编辑器。

- LuaLS（语言服务器）3.19.1：对自制插件进行语言诊断。
- Luacheck（静态检查器）1.2.0：检查 Lua 5.1 语法、合法全局量等。
- Lua（脚本解释器）5.1.5：从官方源码经现有微软编译器构建；当前用于加载清单的语法校验，后续可执行真实运行测试。
- NumPy（数组库）与 Pillow（图像库）：在独立环境内复用现有素材验证。
- Build and Verify（构建与验证）与 PR Flow（拉取请求流程）：复用本机已安装工具，不改其用户级安装。

初次使用需要 Git（版本管理）、Git LFS（大文件存储）、PowerShell 7（命令环境）、Python 3.12（解释器）以及微软 C++（编译语言）工具。远端采用 Windows 2025（运行环境）并准备相同依赖。

~~~powershell
pwsh -NoProfile -File tools/setup.ps1
build-and-verify verify --project .
~~~

安装脚本只写 `.tools`（工具缓存）与 `.venv`（独立环境），不改变系统搜索路径或游戏文件；可重复运行。下载前后核对摘要；Lua 和语言服务器摘要来自官方源站或发行接口，静态检查器摘要为本次上游下载实测值。若版本记录升级导致旧缓存校验失败，保留现场并明确处理对应缓存，不跳过校验。

## 验证入口

`.build-and-verify/config.json`（构建与验证配置）包含六个独立检查：语言诊断、静态检查、加载清单与 Lua 5.1 语法、13 个素材及代码约束、文档结构、检查器正反样例。构建列表为空，因为当前没有必要执行的构建任务。

默认快速验证只选中相关改动；没有变更时可能跳过。正式提交后在干净工作树中使用固定基线验证。完整验证用于拉取请求的远端工作流及已授权的热修复直推。

语言报告保存在 `.local/luals/run-*/check.json`，每次使用新目录。固定版本明确使用 `--check_format=json`（结构化报告格式）；空报告可以是空数组，缺报告或格式错误必须失败。检查器正反样例已覆盖正确代码、错误接口名、错误参数、语法错误和缺失加载文件。

目前没有插件完整游戏行为的自动测试，检查器自测不能冒充插件功能测试。第三方插件、副本、素材生成器、模拟器和游戏部署均不属于这六项检查。

## 接口资料

资料保存在 `.tools/wow-ui-source`（暴雪源码）、`.tools/wow-resources`（接口清单）和 `.tools/wow-api`（类型注解）。源码与资源清单固定到本机匹配的 12.1.0.69587 提交。

注解候选仍有版本限制：上游更新记录只明确到 12.0.1。本次核对了实际使用的 `C_Timer.After`（延迟回调）参数及相关全局入口；没有宣称整份注解已转换为 12.1。项目扩展全局 `EllesmereUI`（界面插件）单独声明，动态依赖内部字段没有完整类型检查。界面源码注解子模块已按父仓库固定版本下载，但未作为当前语言检查库加载，以免将旧界面实现误当成 12.1 定义。

修改游戏接口时，按协作指南先查目标版本文档与调用源码。静态工具不模拟受限值、战斗保护和真实界面。

## 远端交付

业务工作流 `.github/workflows/verify.yml`（完整验证）准备工具及大文件对象，再运行统一入口的完整验证。工具链身份由 PR Flow 生成的 `.pr-flow/toolchain.json` 管理；本机目前使用开发版实现，远端按同一精确提交恢复，不能替换成版本号相同但实现不同的包。

PR Flow 当前受管工作流还会检查 MySpec（规格工具）的安装身份；这只是工具链依赖，没有为本插件初始化规格库。

主分支使用拉取请求、真实状态检查和 CodeQL（安全扫描）结果门禁。普通合并，不强制另一个账号批准；热修复授权复用本机既有短语的摘要，原文不写入仓库。管理员的远端绕过权限本身无法识别授权短语，必须通过 PR Flow 的热修复入口执行验证与短语校验；不能把远端绕过权限误称为平台强制的短语保护。

首次公开使用新建基线。旧提交保存在本地 `archive/local-before-public-20260907`（历史备份分支）；不要使用推送全部分支或镜像推送，否则会把旧整合包历史公开。

## 游戏验收与回退

本次没有启动客户端、复制插件或修改账号配置。游戏验收需在实际客户端检查依赖加载、重载界面、战斗前后和单位切换；通过后单独记录结果。

环境配置可通过版本管理回退。工具目录均为本地缓存，旧游戏文件和保存变量未被改变。不要通过重置或删除备份分支来清理旧历史。
